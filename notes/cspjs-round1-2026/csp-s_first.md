## 一、单项选择题（每题 2 分，共 30 分）

**1.** 以下复杂度包含关系正确的是：  
A. $O(n^2) \subset O(n^3)$  B. $O(n\log n) \subset O(n)$  C. $O(2^n) \subset O(n^3)$  D. $O(n) \subset O(\log n)$

> **答案 A** — $n^2$ 增长慢于 $n^3$；B、C、D 均方向错误。

**2.** 含 1000 个结点的完全二叉树，其高度（根结点高度记为 1）为：  
A. 9  B. 10  C. 11  D. 不确定

> **答案 B** — $2^9 = 512 \le 1000 < 1024 = 2^{10}$，故高度 $= \lfloor \log_2 1000 \rfloor + 1 = 9 + 1 = 10$。

**3.** $n$ 个顶点的无向图要保证连通，至少需要多少条边？  
A. $n$  B. $n+1$  C. $n-1$  D. $n(n-1)/2$

> **答案 C** — 树的定义即 $n-1$ 条边的极小连通图。

**4.** 下列哪种结构**不支持** $O(1)$ 随机访问？  
A. 数组  B. 链表  C. `vector`  D. `deque`

> **答案 B** — 链表按下标访问需从头遍历，$O(n)$。

**5.** 执行 `int x = 3; x <<= 2;` 后 x 的值是：  
A. 6  B. 9  C. 12  D. 15

> **答案 C** — 左移 2 位等价乘 4：$3 \times 4 = 12$。

**6.** 用数字 1、2、3 组成无重复数字的三位数，共能组成几个？  
A. 3  B. 6  C. 9  D. 27

> **答案 B** — 全排列 $3! = 6$。

**7.** 设 $f(1) = 1$，$f(n) = 2f(n/2) + 1$，则 $f(8) = ?$  
A. 7  B. 12  C. 15  D. 16

> **答案 C** — $f(2)=3$，$f(4)=7$，$f(8)=15$；通项 $f(2^k) = 2^k - 1$。

**8.** 以下排序算法中**不稳定**的是：  
A. 冒泡排序  B. 插入排序  C. 快速排序  D. 归并排序

> **答案 C** — 快排 partition 会打乱相等元素的相对次序。

**9.** $n$ 个顶点的无向完全图共有多少条边？  
A. $n^2$  B. $n(n-1)$  C. $n(n-1)/2$  D. $n(n+1)/2$

> **答案 C** — 每对顶点连一条边，$\binom{n}{2}$。

**10.** C++ 中 `priority_queue<int>` 默认是：  
A. 最小堆  B. 最大堆  C. 二叉搜索树  D. 哈希表

> **答案 B** — 默认 `less<int>`，堆顶为最大值。

**11.** 1 到 100 中，是 3 或 5 的倍数的整数共有几个？  
A. 40  B. 46  C. 47  D. 53

> **答案 C** — 容斥原理：$\lfloor 100/3 \rfloor + \lfloor 100/5 \rfloor - \lfloor 100/15 \rfloor = 33 + 20 - 6 = 47$。

**12.** 判断正整数 n 是否为 2 的幂，下列 C++ 表达式正确的是：  
A. `n % 2 == 0`  B. `(n & (n - 1)) == 0`  C. `n / 2 * 2 == n`  D. `n > 0 && (n & (n - 1)) == 0`

> **答案 D** — B 对 n=0 也成立（0 不是 2 的幂），必须加 `n > 0` 前置条件。

**13.** KMP 字符串匹配算法的最坏时间复杂度是（文本串长 n，模式串长 m）：  
A. $O(n)$  B. $O(nm)$  C. $O(n+m)$  D. $O(n\log n)$

> **答案 C** — 主串指针不回退，next 数组预处理 $O(m)$，匹配 $O(n)$。

**14.** 并查集同时使用路径压缩和按秩合并，单次操作的均摊复杂度为：  
A. $O(1)$  B. $O(\log n)$  C. $O(\alpha(n))$  D. $O(n)$

> **答案 C** — $\alpha$ 为反 Ackermann 函数，实际不超过 4。

**15.** 从网格 $(0,0)$ 走到 $(m,n)$，每步只能向右或向上，不同路径数为：  
A. $m+n$  B. $\binom{m+n}{m}$  C. $m! \cdot n!$  D. $2^{m+n}$

> **答案 B** — 共需 $m+n$ 步，其中选 $m$ 步向右。

### 程序 S-1：lowbit 拆位

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 2026, cnt = 0, s = 0;
    while (n > 0) {
        int lb = n & (-n);   // 取出最低位的 1（lowbit）
        ++cnt;               // 已剥离的 1 位个数
        s += lb;             // 已剥离位的权值之和
        n -= lb;             // 删掉最低位的 1
    }
    cout << cnt << " " << s << "\n";
    return 0;
}
```

#### 判断（每题 1.5 分）

**1-1.** 程序输出为 `8 2026`。（ ）  
> **✓** — 见下方追踪表，共 8 个二进制 1 位，权值和恰为原数 2026。

**1-2.** `n & (-n)` 的结果等于 n 的二进制表示中最低位那个 1 所对应的权值。（ ）  
> **✓** — 补码性质：$-n = \sim n + 1$，两者相与后只保留最低位的 1。

**1-3.** 若初始 `n = 0`，则输出为 `0 0`。（ ）  
> **✓** — `while (n > 0)` 一次都不进入，cnt 与 s 保持初值 0。

#### 选择（每题 3 分）

**1-4.** `cnt` 的最终值等于？  
A. n 的十进制位数  B. 原 n 的二进制中 1 的个数  C. 原 n 的二进制位数  D. n 的最小质因数

> **答案 B** — 每次循环恰好剥掉一个 1 位，`cnt` 即 popcount。

**1-5.** 若初始 `n = 16`，输出为？  
A. `1 16`  B. `2 16`  C. `4 16`  D. `16 16`

> **答案 A** — $16 = 10000_2$ 只有 1 个 1 位，`lb = 16`，一次循环结束。

**1-6.** 本程序循环次数的精确表达是？  
A. $O(\log n)$  B. $n/2$  C. $n$ 的二进制中 1 的个数  D. $n$ 的二进制位数

> **答案 C** — 循环次数 = popcount(n)，上界才是 $\log n$；题目问"精确"，选 C。

#### 逐轮执行追踪

$2026 = 11111101010_2$（11 位，其中 8 个 1）

| 轮次 | 进入时 n | n 的二进制 | lb = n&(-n) | cnt | s | 退出时 n |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 2026 | 11111101010 | 2 | 1 | 2 | 2024 |
| 2 | 2024 | 11111101000 | 8 | 2 | 10 | 2016 |
| 3 | 2016 | 11111100000 | 32 | 3 | 42 | 1984 |
| 4 | 1984 | 11111000000 | 64 | 4 | 106 | 1920 |
| 5 | 1920 | 11110000000 | 128 | 5 | 234 | 1792 |
| 6 | 1792 | 11100000000 | 256 | 6 | 490 | 1536 |
| 7 | 1536 | 11000000000 | 512 | 7 | 1002 | 1024 |
| 8 | 1024 | 10000000000 | 1024 | 8 | **2026** | 0 |

输出：`8 2026`

> **循环不变量（讲课重点）**：设原始值为 $n_0$。每一步 $n \mathrel{-}= lb$ 删掉一个二进制 1 位，$s$ 累加该位权值，故**始终有 $s + n = n_0$**。当 $n = 0$ 退出时 $s = n_0$。这是判断 1-1、选择 1-4 的严格依据。

### 程序 S-2：组合数递归与调用次数

```cpp
#include <iostream>
using namespace std;

int calls = 0;

int C(int n, int m) {
    ++calls;
    if (m == 0 || n == m) return 1;             // 叶子/基线
    return C(n - 1, m) + C(n - 1, m - 1);
}

int main() {
    int ans = C(6, 3);
    cout << ans << " " << calls << "\n";
    return 0;
}
```

#### 判断（每题 1.5 分）

**2-1.** `ans` 的值为 20。（ ）  
> **✓** — $\binom{6}{3} = \frac{6 \times 5 \times 4}{3 \times 2 \times 1} = 20$。

**2-2.** `calls` 的值为 39。（ ）  
> **✓** — 推导见下方"调用次数公式"。本地运行实测输出 `20 39`。

**2-3.** 若给函数加记忆化数组 `memo`（每个不同状态只真正计算一次），`calls` 的值保持不变。（ ）  
> **✗** — 记忆化剪掉重复子树，`calls` 减少。实测变为 **19**。

#### 选择（每题 3 分）

**2-4.** 未加记忆化时，总调用次数 $T(n,m)$ 满足？  
A. $\binom{n}{m}$  B. $2\binom{n}{m} - 1$  C. $n \cdot m$  D. $2^{n+m}$

> **答案 B** — 见推导。$2 \times 20 - 1 = 39$。

**2-5.** 加记忆化后 `calls` 的值是？  
A. 15  B. 19  C. 20  D. 39

> **答案 B** — 实测 `20 19`。推导：$1 + 2 \times 9 = 19$（9 个内部状态，每个发起 2 次子调用）。

**2-6.** 若改用递推填杨辉三角求 $\binom{n}{m}$，时间复杂度为？  
A. $O(n!)$  B. $O(2^n)$  C. $O(n \cdot m)$  D. $O(n + m)$

> **答案 C** — 需填 $n \times m$ 个格子，每格 $O(1)$。

#### 推导：为什么 calls = 39（重点讲）

递归调用构成一棵**二叉树**。把每个调用结点分两类：

- **叶子**：满足 `m == 0 || n == m`，返回 1，不再产生子调用；
- **内部结点**：恰好产生 2 个子调用。

关键观察：每个叶子返回值恒为 1，而每个内部结点的返回值 = 左右子树之和。由加法原理，根结点的返回值 = **叶子个数**（每片叶子对结果贡献 1）。

$$\text{叶子数} = \binom{6}{3} = 20$$

对任意满二叉树（每个结点 0 或 2 个子结点）有 $\text{内部结点数} = \text{叶子数} - 1$：

$$\text{总调用次数} = \text{叶子} + \text{内部} = 20 + 19 = 39 = 2\binom{6}{3} - 1$$

> 一般地 $T(n,m) = 2\binom{n}{m} - 1$。这解释了"无记忆化的组合数递归是指数级"的本质：**它显式枚举了每一条从根到叶子的路径**，正好是 $\binom{n}{m}$ 条。

#### 推导：记忆化后为什么是 19

记忆化后每个**不同状态**只展开一次，但被父结点调用的次数仍会 `++calls`。

从 $(6,3)$ 出发可达的**内部**状态（$0 < m < n$）共 9 个：

```
(6,3) (5,3) (5,2) (4,3) (4,2) (4,1) (3,2) (3,1) (2,1)
```

可达的**基线**状态（$m=0$ 或 $n=m$）共 6 个：

```
(3,3) (3,0) (2,2) (2,0) (1,1) (1,0)
```

每个内部结点恰好发起 2 次子调用，根结点是唯一"不被调用而存在"的：

$$\text{calls} = 1 + 2 \times 9 = 19$$

等价地说：$\text{calls} = $ 去重后的状态总数 15 + 被 memo 命中的重复调用 4 = 19。

> **讲课要点**：记忆化把"路径计数"（指数）降为"状态计数"（多项式）。这两道题 2-2 与 2-5 对比，就是 DP 的本质。

### 程序 S-3：单调栈求下一个更大元素

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    int a[7] = {5, 3, 8, 1, 6, 2, 4};
    int n = 7, res[7];
    stack<int> st;                    // 存下标，栈内对应值自底向上递减

    for (int i = 0; i < n; ++i) {
        while (!st.empty() && a[st.top()] < a[i]) {
            res[st.top()] = a[i];     // a[i] 就是栈顶元素的下一个更大值
            st.pop();
        }
        st.push(i);
    }
    while (!st.empty()) {             // 右侧不存在更大元素
        res[st.top()] = -1;
        st.pop();
    }
    for (int i = 0; i < n; ++i) cout << res[i] << " ";
    cout << "\n";
    return 0;
}
```

#### 判断（每题 1.5 分）

**3-1.** `res[3]` 的值为 6。（ ）  
> **✓** — $a[3] = 1$，其右侧第一个大于 1 的是 $a[4] = 6$。

**3-2.** 栈 `st` 中保存的是数组元素的**值**。（ ）  
> **✗** — 保存的是**下标**；这样才能把结果写回 `res[st.top()]` 对应的位置。

**3-3.** 将条件 `a[st.top()] < a[i]` 改为 `<=` 后，程序仍输出正确答案（数组元素互异时）。（ ）  
> **✓** — 元素互异时 `<=` 与 `<` 的判定结果完全相同，因为相等的情况不会出现。

#### 选择（每题 3 分）

**3-4.** `res[4]` 的值为？  
A. 8  B. -1  C. 6  D. 2

> **答案 B** — $a[4] = 6$，其右侧只有 2 和 4，均小于 6，故为 -1。

**3-5.** 本算法的总时间复杂度是？  
A. $O(n\log n)$  B. $O(n^2)$  C. $O(n)$  D. $O(n\sqrt{n})$

> **答案 C** — 每个下标最多入栈一次、出栈一次，总操作 $2n$，均摊 $O(n)$。

**3-6.** 整个执行过程中栈的最大长度是？  
A. 2  B. 3  C. 4  D. 7

> **答案 B** — 见追踪表，$i = 5$ 结束时栈为 `[2, 4, 5]`，长度 3 为峰值。

#### 逐元素栈状态追踪

| i | a[i] | while 弹出（谁被赋值） | 弹出后栈 | push 后栈 | res 更新 |
| --- | --- | --- | --- | --- | --- |
| 0 | 5 | — | `[]` | `[0]` | |
| 1 | 3 | —（5 > 3） | `[0]` | `[0,1]` | |
| 2 | 8 | 1(res[1]=8)、0(res[0]=8) | `[]` | `[2]` | res[0]=8, res[1]=8 |
| 3 | 1 | —（8 > 1） | `[2]` | `[2,3]` | |
| 4 | 6 | 3(res[3]=6) | `[2]` | `[2,4]` | res[3]=6 |
| 5 | 2 | —（6 > 2） | `[2,4]` | `[2,4,5]` | **栈长 3** |
| 6 | 4 | 5(res[5]=4) | `[2,4]` | `[2,4,6]` | res[5]=4 |
| 收尾 | — | 6→-1, 4→-1, 2→-1 | `[]` | — | res[2]=res[4]=res[6]=-1 |

最终 `res[0..6]` = `8 8 -1 6 -1 4 -1`（本地实测一致）。

#### 正确性论证（讲课重点）

**不变量**：任一时刻，栈中下标对应的 `a` 值自栈底到栈顶**严格递减**，且这些下标右侧尚未出现过比它更大的元素。

**归纳**：处理 $i$ 时，凡是栈顶值 $< a[i]$ 的下标 $j$，其右侧第一个大于 $a[j]$ 的元素必是 $a[i]$ —— 因为 $j$ 仍在栈中说明 $j+1 \dots i-1$ 都不大于 $a[j]$，而 $a[i] > a[j]$。于是赋值 $res[j] = a[i]$ 正确且不可再改进。弹出后栈底仍满足递减性。

**复杂度**：每个下标至多入栈 1 次、出栈 1 次，总 $O(n)$，优于暴力 $O(n^2)$。

> **一句话提炼**：单调栈的本质是"**用一次弹出动作，为一个元素确定它的下一个更大（或更小）边界**"；判断"谁在等谁"决定了栈里存值还是存下标。

### 完善程序 1：快速幂

```cpp

    long long res = /* 空① */;
    a %= mod;
    while (b > 0) {
        if (/* 空② */)
            res = res * a % mod;
        a = /* 空③ */;
        b = /* 空④ */;
    }
    return /* 空⑤ */;
}

int main() {
    cout << qpow(3, 13, 1000000007) << "\n";   // 3^13 = 1594323
    return 0;
}
```

| 空号 | 答案 | 推导说明 |
| --- | --- | --- |
| ① | `1` | 乘法单位元；$b=0$ 时 $a^0 = 1$ |
| ② | `b & 1` | 判断 b 的当前最低位是否为 1（即本轮二进制位需要计入）；也可写 `b % 2 == 1` |
| ③ | `a * a % mod` | 底数自平方，对应二进制位权 $a^{2^k}$ 逐位上升 |
| ④ | `b >> 1` | 右移一位，处理下一个二进制位；也可写 `b /= 2` |
| ⑤ | `res` | 循环结束时 res 即所求 |

**手推 $3^{13} \bmod 1000000007$**：$13 = 1101_2$

| 轮次 | b（进入） | b&1 | a（进入） | res |
| --- | --- | --- | --- | --- |
| 1 | 13 (`1101`) | 1 | 3 | 3 |
| 2 | 6 (`110`) | 0 | 9 | 3 |
| 3 | 3 (`11`) | 1 | 81 | 243 |
| 4 | 1 (`1`) | 1 | 6561 | **1594323** |
| 5 | 0 | 结束 | | |

> $3 \times 81 \times 6561 = 1594323 = 3^{13}$，验证 ②③④ 的配合关系。

> **坑点**：`a * a % mod` 在 `mod` 接近 $10^9$ 时 $a^2$ 会溢出 `int`，必须 `long long`；`res * a` 同理。

### 完善程序 2：区间 DP · 石子合并

**题意**：$n$ 堆石子排成**一排**，每次合并相邻两堆，代价为两堆总数之和，求把所有石子合并成一堆的**最小**总代价。

```cpp

#include <algorithm>
#include <climits>

const int N = 305;
int n, a[N], pre[N], dp[N][N];

int main() {
    cin >> n;
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];
    }
    for (int len = 2; len <= n; ++len) {
        for (int i = 1; /* 空① */; ++i) {
            int j = /* 空② */;
            dp[i][j] = /* 空③ */;
            for (int k = i; k < j; ++k) {
                dp[i][j] = min(dp[i][j], /* 空④ */);
            }
        }
    }
    cout << /* 空⑤ */ << "\n";
    return 0;
}
```

| 空号 | 答案 | 推导说明 |
| --- | --- | --- |
| ① | `i + len - 1 <= n` | 区间 $[i, i+len-1]$ 不能越界；等价写法 `i <= n - len + 1` |
| ② | `i + len - 1` | 由长度反推右端点 |
| ③ | `INT_MAX` | 求 min，初值必须置为无穷大；单堆 `dp[i][i] = 0`（全局数组默认 0）正是基线 |
| ④ | `dp[i][k] + dp[k + 1][j] + pre[j] - pre[i - 1]` | 枚举最后一次合并的分界点 $k$；两部分内部代价 + 本次合并代价（区间总和，用前缀和 $O(1)$ 求得） |
| ⑤ | `dp[1][n]` | 合并整段的最小代价 |

#### 小数据手推（$n = 3$，$a = \{1, 2, 3\}$）

前缀和 `pre = [0, 1, 3, 6]`

| len | i | j | dp[i][j] | 计算 |
| --- | --- | --- | --- | --- |
| 2 | 1 | 2 | 3 | dp[1][1]+dp[2][2]+(3−0)=0+0+3 |
| 2 | 2 | 3 | 5 | 0+0+(6−1)=5 |
| 3 | 1 | 3 | 11 | k=1: 0+5+6=11；k=2: 3+0+6=9 → **取 min 应为 9** |

> 上表最后一行需说明：$k=2$ 时 $dp[1][2] + dp[3][3] + pre[3] - pre[0] = 3 + 0 + 6 = 9$，故 `dp[1][3] = 9`。  
> 验证两种合并顺序：先合 1+2 再合 3 → 代价 $3 + 6 = 9$；先合 2+3 再合 1 → 代价 $5 + 6 = 11$。取最小 **9** ✓

> **讲课要点**：区间 DP 的枚举顺序必须**按区间长度从小到大**，因为 $dp[i][j]$ 依赖更短的 $dp[i][k]$ 和 $dp[k+1][j]$。这是很多同学在初赛填空题上丢分的地方——写 `for (int i = 1..n)` 再 `for (int j = i+1..n)` 是错的。
