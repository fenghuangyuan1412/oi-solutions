## 一、单项选择题（每题 2 分，共 30 分）

**1.** 计算机中 1 GB 等于：  
A. 1024 KB  B. 1024 MB  C. 1000 MB  D. 1024 GB

> **答案 B**  
> 1 GB = 1024 MB；换算关系：1 KB = 1024 B，1 MB = 1024 KB，1 GB = 1024 MB。

**2.** 二进制数 `1101` 转换为十进制是：  
A. 11  B. 12  C. 13  D. 14

> **答案 C**  
> $1 \times 2^3 + 1 \times 2^2 + 0 \times 2^1 + 1 \times 2^0 = 8 + 4 + 0 + 1 = 13$

**3.** 以下哪个**不是** C++ 关键字？  
A. `const`  B. `static`  C. `string`  D. `void`

> **答案 C**  
> `string` 是标准库类型 `std::string`，不是语言关键字。其余三个均为 C++ 关键字。

**4.** 若有 `int a = 5; int *p = &a;`，则 `*p` 的值是：  
A. a 的地址  B. 5  C. 未定义  D. 编译错误

> **答案 B**  
> `p` 指向 `a`，`*p` 解引用得到 `a` 的值，即 5。

**5.** 表达式 `5 / 2` 在 C++ 整数除法中的值是：  
A. 2.5  B. 2  C. 3  D. 编译错误

> **答案 B**  
> 两个 `int` 相除，向零截断，`5 / 2 = 2`（不是 2.5）。

**6.** 表达式 `5 % 2` 的值是：  
A. 0  B. 1  C. 2  D. 2.5

> **答案 B**  
> 5 除以 2 余 1，`5 % 2 = 1`。

**7.** 栈的特点是：  
A. 先进先出  B. 后进先出  C. 随机访问  D. 按优先级出队

> **答案 B**  
> 栈（Stack）是 LIFO 结构，最后压入的元素最先弹出。

**8.** 声明 `int a[5]` 后，访问 `a[5]` 的结果是：  
A. 第 5 个元素  B. 越界访问  C. 第 6 个元素  D. 最后一个元素

> **答案 B**  
> C++ 数组下标从 0 开始，`a[0]` 到 `a[4]` 是合法的 5 个元素；`a[5]` 越界，属于未定义行为。

**9.** 十六进制 `0x1F` 转换为十进制是：  
A. 15  B. 30  C. 31  D. 32

> **答案 C**  
> $1 \times 16 + 15 = 31$

**10.** 循环 `for(int i=1; i<=10; i+=3)` 共执行了几次循环体？  
A. 3  B. 4  C. 10  D. 13

> **答案 B**  
> i 依次取 1、4、7、10，共 4 次进入循环体（10 ≤ 10 时进入，13 > 10 时停止）。

**11.** 以下哪种排序算法的**平均**时间复杂度最优？  
A. 冒泡排序  B. 选择排序  C. 快速排序  D. 插入排序

> **答案 C**  
> 快排平均 $O(n \log n)$；冒泡、选择、插入平均均为 $O(n^2)$。

**12.** 递归函数**必须**具有的是：  
A. 循环语句  B. 终止条件（基线情形）  C. 全局变量  D. 数组参数

> **答案 B**  
> 没有终止条件会无限递归，最终栈溢出崩溃。

**13.** 若 `n = 6`，则 `n & (n - 1)` 的值是：  
A. 4  B. 5  C. 6  D. 2

> **答案 A**  
> 6 = `110₂`，5 = `101₂`，`110 & 101 = 100 = 4`。  
> `n & (n-1)` 的效果是去掉 n 的二进制最低位的 1。

**14.** 10 个人站成一排，甲**不在**首位的排法共有多少种？  
A. $9!$  B. $10! - 9!$  C. $9 \times 9!$  D. B 和 C 都正确

> **答案 D**  
> 全排减去甲在首位（其余 9 人任意排）= $10! - 9!$；等价地，首位有 9 种选择（非甲），剩余 9 人任意排 = $9 \times 9!$；两式均等于 $9 \times 9!$。

**15.** 函数声明 `void f(int &x)` 的参数传递方式是：  
A. 传值  B. 传指针  C. 引用传参  D. 编译错误

> **答案 C**  
> `int &x` 是引用参数，函数内对 `x` 的修改会直接影响实参。

### 程序 J-1：约数统计

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 12, cnt = 0, s = 0;
    for (int i = 1; i <= n; ++i) {
        if (n % i == 0) {   // i 是 n 的约数
            ++cnt;
            s += i;
        }
    }
    cout << cnt << " " << s << "\n";
    return 0;
}
```

#### 判断（每题 1.5 分）

**1-1.** 程序输出 `cnt` 的值为 6。（ ）  
> **✓** — 12 的约数为 1,2,3,4,6,12，共 6 个。

**1-2.** 若将 `n = 12` 改为 `n = 7`，则输出 `s = 8`。（ ）  
> **✓** — 7 为质数，约数只有 1 和 7，`s = 1 + 7 = 8`。

**1-3.** 若将循环条件改为 `i < n`，`s` 的输出值不变。（ ）  
> **✗** — 改为 `i < n` 则不包含约数 12 本身，`s = 1+2+3+4+6 = 16 ≠ 28`。

#### 选择（每题 3 分）

**1-4.** 程序输出是？  
A. `5 27`  B. `6 28`  C. `6 16`  D. `7 28`

> **答案 B**  
> 12 的约数之和 = $1+2+3+4+6+12 = 28$，约数个数 = 6。

**1-5.** 若 `n = 1`，程序输出是？  
A. `0 0`  B. `1 1`  C. `1 0`  D. `0 1`

> **答案 B**  
> $1 \% 1 = 0$，循环进入一次：`cnt=1, s=1`，之后 `i=2>1` 退出。

**1-6.** 本程序的时间复杂度是？  
A. $O(\log n)$  B. $O(\sqrt{n})$  C. $O(n)$  D. $O(n^2)$

> **答案 C**  
> 外层循环 `i = 1..n`，每次做一次取余判断，共 $n$ 次。

#### 执行追踪表（n = 12）

| 轮次 i | 12 % i == 0? | cnt | s |
| --- | --- | --- | --- |
| 1 | ✓ | 1 | 1 |
| 2 | ✓ | 2 | 3 |
| 3 | ✓ | 3 | 6 |
| 4 | ✓ | 4 | 10 |
| 5 | ✗ | 4 | 10 |
| 6 | ✓ | 5 | 16 |
| 7–11 | ✗ | 5 | 16 |
| 12 | ✓ | 6 | **28** |

输出：`6 28`

### 程序 J-2：冒泡排序交换次数

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[6] = {5, 3, 8, 1, 6, 2};
    int cnt = 0;
    for (int i = 1; i <= 5; ++i) {
        for (int j = 5; j >= i; --j) {
            if (a[j] < a[j - 1]) {
                int t = a[j];
                a[j] = a[j - 1];
                a[j - 1] = t;
                ++cnt;
            }
        }
    }
    cout << cnt << "\n";
    for (int i = 0; i < 6; ++i) cout << a[i] << " ";
    cout << "\n";
    return 0;
}
```

#### 判断（每题 1.5 分）

**2-1.** 程序第一行输出（`cnt` 的值）为 9。（ ）  
> **✓** — `cnt` 恰好统计所有逆序对的个数。初始 `{5,3,8,1,6,2}` 的逆序对共 9 对：(5,3),(5,1),(5,2),(3,1),(3,2),(8,1),(8,6),(8,2),(6,2)。

**2-2.** 若初始数组改为 `{1,2,3,4,5,6}`，则 `cnt = 0`。（ ）  
> **✓** — 升序数组逆序对为 0，不触发任何交换。

**2-3.** 若将 `a[j] < a[j-1]` 改为 `a[j] <= a[j-1]`，程序仍可正常终止且 `cnt` 不变。（ ）  
> **✗** — 相等时也会交换，`cnt` 会偏大（若数组含重复元素）；且相同元素反复交换，虽然不会死循环，但逻辑改变了排序稳定性。

#### 选择（每题 3 分）

**2-4.** 程序第二行输出是？  
A. `1 2 3 5 6 8`  B. `2 1 3 5 6 8`  C. `8 6 5 3 2 1`  D. `5 3 8 1 6 2`

> **答案 A** — 冒泡排序最终将数组排为升序 `1 2 3 5 6 8`。

**2-5.** `cnt` 的值等于初始数组的？  
A. 最大值  B. 逆序对数  C. 不同元素个数  D. 循环总次数

> **答案 B** — 每次交换恰好消除一个逆序对，且不会创造新逆序对，所以总交换次数 = 初始逆序对数 = 9。

**2-6.** 若初始数组改为 `{6,5,4,3,2,1}`，则 `cnt = ?`  
A. 10  B. 15  C. 20  D. 25

> **答案 B** — 完全逆序时逆序对数最大 = $\binom{6}{2} = 15$。

#### 每轮外层执行追踪

初始：`a = {5, 3, 8, 1, 6, 2}`，`cnt = 0`

| 外层 i | 内层 j 扫描方向 | 本轮结束后 a 的状态 | cnt |
| --- | --- | --- | --- |
| 1 | j: 5→1 | `{1, 5, 3, 8, 2, 6}` | 4 |
| 2 | j: 5→2 | `{1, 2, 5, 3, 8, 6}` | 7 |
| 3 | j: 5→3 | `{1, 2, 3, 5, 6, 8}` | 9 |
| 4 | j: 5→4 | `{1, 2, 3, 5, 6, 8}` | 9 |
| 5 | j: 5→5 | `{1, 2, 3, 5, 6, 8}` | 9 |

> **讲课要点**：内层循环从右往左扫描，相当于把本轮最小值"冒泡"到左端位置 `i-1`。每轮结束后可确定 `a[0..i-1]` 已就位。

### 程序 J-3：十进制转二进制（递归）

```cpp
#include <iostream>
using namespace std;

int cnt = 0;

void f(int n) {
    if (n <= 0) return;    // 递归出口
    f(n / 2);              // 先递归处理更高位
    ++cnt;
    cout << n % 2;         // 回溯时输出当前最低位
}

int main() {
    f(13);
    cout << " " << cnt << "\n";
    return 0;
}
```

#### 判断（每题 1.5 分）

**3-1.** 程序输出为 `1101 4`。（ ）  
> **✓** — $13 = 1101_2$，共输出 4 位，`cnt = 4`。

**3-2.** 调用 `f(0)` 会使 `cnt` 增加 1。（ ）  
> **✗** — `f(0)` 中 `n <= 0` 为真，直接 return，不执行 `++cnt`。

**3-3.** 若把 `f(n/2)` 移到 `cout << n%2` 之后（即先输出再递归），程序输出变为 `1011 4`。（ ）  
> **✓** — 顺序变为：先输出当前位再递归，f(13) 输出 13%2=1，然后 f(6) 输出 0，f(3) 输出 1，f(1) 输出 1 → `1011`，cnt 仍为 4。

#### 选择（每题 3 分）

**3-4.** `f(13)` 的递归调用链（函数嵌套深度）为几层？  
A. 3  B. 4  C. 5  D. 13

> **答案 B** — 调用链：f(13) → f(6) → f(3) → f(1) → f(0)（f(0) 立即返回，不计入 cnt），最深有效递归 4 层。

**3-5.** `f(n)`（n ≥ 1）输出的二进制位数等价于？  
A. $\lfloor \log_2 n \rfloor + 1$  B. $n \% 2$  C. $\lceil \log_2 n \rceil - 1$  D. $n / 2$

> **答案 A** — n 的二进制位数即最高有效位位置加 1，等于 $\lfloor \log_2 n \rfloor + 1$。

**3-6.** `f(1)` 调用返回时 `cnt` 的值是？  
A. 0  B. 1  C. 2  D. 3

> **答案 B** — f(1)：先调用 f(0) 返回；然后 `++cnt`（cnt=1），输出 `1%2=1`。

#### 递归展开追踪

```
f(13)
  f(6)
    f(3)
      f(1)
        f(0) → return
      cnt=1, 输出 1
    cnt=2, 输出 1
  cnt=3, 输出 0
cnt=4, 输出 1
```

回溯输出顺序：`1 1 0 1` → 拼接为 `1101`，最后输出 ` 4`。

> **关键观察**：`cout << n%2` 在递归调用**之后**执行，这是"先处理高位再输出当前位"的实现方式，递归天然给出从高位到低位的输出顺序。

### 完善程序 1：二分查找

**题意**：给定长度为 n 的**升序**整数数组 a[]，编写函数查找 target，返回其下标；找不到则返回 -1。

```cpp
#include <iostream>
using namespace std;

const int MAXN = 1005;
int a[MAXN];

int bsearch(int n, int target) {
    int l = 0, r = n - 1;
    while (/* 空① */) {
        int mid = /* 空② */;
        if (a[mid] == target)
            return mid;
        else if (a[mid] < target)
            /* 空③ */;
        else
            /* 空④ */;
    }
    return /* 空⑤ */;
}

int main() {
    int n, target;
    cin >> n;
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> target;
    cout << bsearch(n, target) << "\n";
    return 0;
}
```

| 空号 | 答案 | 推导说明 |
| --- | --- | --- |
| ① | `l <= r` | 搜索区间 $[l, r]$ 非空的条件；若为 `l < r` 会漏掉单元素情况 |
| ② | `l + (r - l) / 2` | 等价于 `(l+r)/2`，但防止 `l+r` 整型溢出 |
| ③ | `l = mid + 1` | 当前中点偏小，目标在右半部分，排除 mid |
| ④ | `r = mid - 1` | 当前中点偏大，目标在左半部分，排除 mid |
| ⑤ | `-1` | 区间为空仍未找到，按题意返回 -1 |

> **讲课要点**：二分的核心不变量是"若目标存在，则必在 $[l, r]$ 内"。每次循环将区间折半，因此最多 $\lceil \log_2 n \rceil$ 次迭代。

### 完善程序 2：求最大值与第二大值

**题意**：输入 n 个整数，找出最大值 `mx1` 和**严格小于最大值**的第二大值 `mx2`。

```cpp
#include <iostream>
#include <climits>
using namespace std;

int main() {
    int n;
    cin >> n;
    int mx1 = /* 空① */, mx2 = /* 空② */;
    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        if (x > mx1) {
            mx2 = /* 空③ */;
            mx1 = x;
        } else if (/* 空④ */) {
            mx2 = x;
        }
    }
    cout << mx1 << " " << /* 空5 */ << "\n";
    return 0;
}
```

| 空号 | 答案 | 推导说明 |
| --- | --- | --- |
| ① | `INT_MIN` | 初始值取最小可能整数，保证第一个输入元素能进入 `x > mx1` 分支 |
| ② | `INT_MIN` | 第二大同理初始化 |
| ③ | `mx1` | 发现新最大值时，原最大值降级为第二大，赋给 mx2 |
| ④ | `x > mx2 && x < mx1` | x 既不大于 mx1，但严格大于 mx2 时更新 mx2；`x < mx1` 保证"严格小于最大值" |
| ⑤ | `mx2` | 输出第二大值 |

> **坑点**：若数组所有元素相同（如 `{5,5,5}`），则 `mx2` 始终为 `INT_MIN`，输出错误。题目保证至少有两个不同元素，否则需特殊判断。
