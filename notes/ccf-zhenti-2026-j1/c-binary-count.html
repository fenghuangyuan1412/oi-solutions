⑤ 这段程序到底在数什么（页面语义说明）

  
    
    
  • n % 2 取的是 n 的二进制最后一位（偶数→0，奇数→1）；n = n / 2 是整数除法，效果是把二进制最后一位削掉（右移一位）。循环每转一轮 x 必 +1（第 9 行或第 11 行有一行会执行），只有奇数轮 y 才 +1（第 12 行）。
    • 
    
  • 于是 x = 1 + n 的二进制位数，y = 1 + n 的二进制里 1 的个数（n = 0 时循环一次都不转，x = y = 1）。
    •

⑥ 等价性核对（RESULTS.md §2.3 机器实测原文）

  
等价性核对 0..16777215：不一致 0 个
题18  0..16777215 中 x<y 的反例 0 个
题21  0..2^31-1 中 y==2 共 31 次

  
    
    
  • 题 18（√）：x = 1 + 位数，y = 1 + 1 的个数。每一位最多贡献一个 1，所以「1 的个数」永远不会超过「位数」，即 x ≥ y 恒成立。等号当且仅当每一位全是 1（n = 2ᵏ−1，如 1、3、7、1023）。实测在 0..2²⁴ 上用卷面原循环逐个查 x<y，反例 0 个。
    • 
    
  • 题 21（C，31）：第二个数 y = 2 即「1 的个数恰为 1」——二进制里只有一个 1 的数就是 2 的整数次幂 2⁰, 2¹, …, 2ᵏ。范围上限 2³¹−1，所以 k 最大 30（2³⁰ ≤ 2³¹−1 < 2³¹），k = 0..30 共 31 个。实测对 0..2³¹−1 全范围统计：y==2 共 31 次。
    • 
    
  • 方法：先在 0..2²⁴ 上把「x = 位数+1、y = popcount+1」这个等价式和卷面循环逐个对拍（不一致 0 个），确认翻译没错，才敢用等价式跑 21 亿的全范围（原循环 21 亿 × 31 层本机跑不完）。

n=0     -> （3 秒无任何输出）[退出码 124]
