⑧ 这一题带走的三句话

  
1. 求 min 的初值给 +∞、求 max 的初值给 −∞。卷面第 12 行的 double ans = 1e100; 和 ⑤ 里的
  1e100 / -1e100 不是"一个很大的数"这么随便 —— 1e100 是当作正无穷用的大 double（第一次取 min 就一定会被真实值替换掉），
  -1e100 是当作负无穷用的大 double（第一次取 max 一定会被替换）。反过来，如果初值给反了，min 永远是那个负的、max 永远是那个正的，极差就成了垃圾值。

  
2. int / int 会截断，要 * 1.0。见上面 ③ 的截断演示：同一个 17/3，写 sum * 1.0 / (r - l + 1) 得 5.666667，写 sum / (r - l + 1) 得 5。

  
3. 计数变量数的是什么，出口就判什么。本题 cnt 数的是切刀数 k（不是段数），
  所以 cnt == 0 恰好等于"一刀没切"。要是把 ④ 填成 cnt + 1，cnt 就变成段数，
  "不切"那一种分法的 cnt = 1 顺利通过拦截混进答案 —— 实测 ④C 在 300 组里错 285 组，⑤B（cnt 从 1 起步）错 285 组，错的都是这一个原因。
