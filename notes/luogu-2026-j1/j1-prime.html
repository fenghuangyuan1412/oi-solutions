⑦ 三个必考陷阱（本页各自是一个独立步骤）

  
    
    
  • 陷阱 1：`(2,3)` 永远打不出来。外层枚举的是 (i, i+2)，两数相差固定是 2；从 i=2 起，第一对候选是 (2,4)，而 isPrime(4) 为假。相差 1 的 (2,3) 根本不是候选。
    • 
    
  • 陷阱 2：循环条件是 `i + 2 <= n`，不是 `i <= n`。n=20 时 i 最大只能取到 18（18+2=20 ≤ 20），i=19 时条件为假就退出，所以最后一组候选永远是 i = n-2。
    • 
    
  • 陷阱 3：`isPrime(0)` 和 `isPrime(1)` 都返回 true（机器实测，RESULTS.md §1.3）。因为 for(int i=2; i<n; ++i) 一次都不执行，直接落到 return true;。本程序从 i=2 起枚举才没出事；第 17 题把 int i=2 改成 int i=1 就凭空多打一行 1 3（n=14 的和从 44 变 48）。
    • 
  






  
⑧ 与讲义 / 机器实测（RESULTS.md §1）的对照

  
    
    
  • 题 16（n=14）：输出 3 5 / 5 7 / 11 13，全部整数之和 44 → T（实测一致）。
    • 
    
  • 题 17（第 16 行改成 int i = 1）：多打一行 1 3，和 44→48、224→228 → "输出不变"为 F。
    • 
    
  • 题 18（输出是否全为奇数）：n 从 5 扫到 1000，输出中出现偶数的次数 = 0 → T。偶数里只有 2 是质数，而 (2,4) 需要 isPrime(4)，为假。
    • 
    
  • 题 19（n=50）：6 对 (3,5)(5,7)(11,13)(17,19)(29,31)(41,43)，和 = 224 → B（220/227/230 都是干扰）。
    • 
    
  • 题 20（改第 5 行循环条件）：只有 i * i <= n 与原程序在 5≤n≤1000 输出逐个相同 → C。i*i < n 会把 4/9/25/49 这类完全平方数误判成质数。
