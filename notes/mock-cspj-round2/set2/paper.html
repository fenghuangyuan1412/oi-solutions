T1　角色图鉴

程序文件名：codex.cpp　输入文件名：codex.in　输出文件名：codex.out

满分 100 分时间限制 1000ms　空间限制 512MB

【题目描述】

小 B 在玩一款抽卡游戏，她的角色图鉴里一共有 m 个角色，编号 1 到 m。

她已经抽了 n 次，第 i 次抽到的角色编号是 c_i。同一个角色可能被抽到很多次——多出来的那些只能当"复数"，图鉴里那个角色依然只算"已拥有"。

问：她至少还要再抽多少次，才能让图鉴里的每一个角色都至少被拥有 1 次？

（可以把运气假设成最好：以后每次抽卡都能精准抽到她目前还缺的角色。）

【输入格式】

第一行两个整数 n、m。

第二行 n 个整数 c_1, c_2, …, c_n。

【输出格式】

一行一个整数，表示最少还需要抽的次数。

【输入输出样例 1】

5 8
1 2 2 3 1
5

【样例 1 说明】

已经拥有的角色是 1, 2, 3，共 3 个不同的角色，还缺 8 - 3 = 5 个。

【输入输出样例 2】

3 3
1 2 3
0

【数据范围与子任务】

对于 100% 的数据，1 ≤ n ≤ 10^6，1 ≤ m ≤ 10^6，1 ≤ c_i ≤ m。

子任务编号分数特殊性质
1—315n ≤ 10
4—825c_i 两两不同
9—1325m ≤ 100
14—2035无特殊限制

T2　谷仓机器人

程序文件名：robot.cpp　输入文件名：robot.in　输出文件名：robot.out

满分 100 分时间限制 1000ms　空间限制 512MB

【题目描述】

一个存放谷子的仓库是 n 行 m 列的网格。有些格子里立着货架（记作 x），机器人进不去；其余是空地（记作 .）。

一台送谷子的机器人站在某个空格上，初始朝向为 d0。朝向用整数表示：0 东（列 +1）、1 南（行 +1）、2 西（列 -1）、3 北（行 -1）。

机器人依次执行长度为 k 的指令串，指令只有两种：

  • R：原地右转 90°（东 → 南 → 西 → 北 → 东）。
  • F：尝试向当前朝向前进一格。若目标格在网格内且不是货架，就走过去；否则原地右转 90°，这一步不移动。

机器人出发时所在的格子也算"走过"。问全部指令执行完之后：

  • 它停在第几行第几列，朝向是什么；
  • 它一共走过多少个不同的格子（同一个格子走多次只算一次）。

【输入格式】

第一行三个整数 n、m、k。

接下来 n 行，每行一个长度为 m 的字符串，只含 . 和 x，描述地图。

接下来一行三个整数 r0、c0、d0，表示出发位置与初始朝向，保证该格是空地。

最后一行一个长度为 k 的字符串，只含 F 和 R。

【输出格式】

一行四个整数 r、c、d、s，依次表示最终行、最终列、最终朝向、走过的不同格子数。

【输入输出样例 1】

3 3 5
...
.x.
...
1 1 0
FFFRF
1 2 2 3

【样例 1 说明】

从 (1,1) 朝东出发：F 到 (1,2)，F 到 (1,3)；第三条 F 前面已经出界，于是原地右转成朝南（不移动）；R 再右转成朝西；F 回到 (1,2)。最终朝向 2（西），走过的不同格子是 (1,1)(1,2)(1,3) 共 3 个。

【输入输出样例 2】

3 3 6
..x
...
x..
1 1 0
FFFFFF
3 2 3 4

【数据范围与子任务】

对于 100% 的数据，1 ≤ n, m ≤ 1000，1 ≤ k ≤ 10^6，地图中至少有一个空格。

子任务编号分数特殊性质
1—315n = 1
4—720地图中没有货架
8—1120k ≤ 1000
12—1415指令串中只有 F
15—2030无特殊限制

T3　应援灯牌

程序文件名：light.cpp　输入文件名：light.in　输出文件名：light.out

满分 100 分时间限制 1000ms　空间限制 512MB

【题目描述】

小 Y 要给演唱会做一块数字应援灯牌。灯牌上每一位数字都要用 LED 拼成"七段数码管"的形状，各数字需要的 LED 数量如下表：

数字0123456789
LED 数6255456376

她手上正好有 n 颗 LED，要求全部用完（不多也不少），拼出一个没有前导零的正整数。

请帮她拼出能表示的最小的正整数。如果无论怎么拼都不可能恰好用完 n 颗 LED，输出 -1。

【输入格式】

一行一个整数 n。

【输出格式】

一行，一个正整数（答案可能很长，请按字符串输出），或 -1。

【输入输出样例 1】

5
2

【样例 1 说明】

恰好用 5 颗 LED 的一位数有 2、3、5；两位数也能恰好用 5 颗（例如 17，2+3 = 5），但两位数一定比一位数大，所以答案是 2。

【输入输出样例 2】

8
10

【样例 2 说明】

最少要 2 位（因为一位最多用 7 颗）。第一位选 1（2 颗），第二位就还剩 6 颗，能拼出的最小数字是 0，于是答案是 10。注意 16 也正好用 8 颗，但比 10 大。

【输入输出样例 3】

1
-1

【数据范围与子任务】

对于 100% 的数据，1 ≤ n ≤ 10^5。

子任务编号分数特殊性质
1—420n ≤ 10
5—925答案只有一位数
10—1425n ≤ 100
15—2030无特殊限制

T4　总选打投

程序文件名：vote.cpp　输入文件名：vote.in　输出文件名：vote.out

满分 100 分时间限制 1000ms　空间限制 512MB

【题目描述】

一场总选投票一共持续 m 天。第 i 天开放 k_i 个应援项目供小 N 选择，第 j 个项目投一票能带来热度 v_{i,j}。同一天里可能有两个项目热度相同，但它们是不同的项目，选它们算作不同的方案。

规则：

  • 每天必须投票，而且只能投 1 个项目。
  • 平台防刷：相邻两天投出的项目热度值不能相同（即第 i 天与第 i-1 天的热度值必须不同）。

小 N 想知道：m 天结束后总热度恰好等于 S 的投票方案数是多少。答案对 998244353 取模。

【输入格式】

第一行两个整数 m、S。

接下来 m 行，第 i 行先是一个整数 k_i，随后是 k_i 个整数，表示第 i 天各项目的热度值。

【输出格式】

一行一个整数，表示方案数对 998244353 取模的结果。

【输入输出样例 1】

3 6
2 1 2
2 2 3
1 3
1

【样例 1 说明】

第 3 天只能投热度 3。要凑出 6，前两天必须凑出 3，只有 (1,2) 一种，且满足相邻两天热度不同。(1,3) 与第 3 天的 3 冲突，不合法。

【输入输出样例 2】

2 4
2 1 3
2 1 3
2

【样例 2 说明】

(第1天, 第2天) 取 (1,3) 或 (3,1) 都能凑出 4，且相邻两天热度不同，共 2 种。

【输入输出样例 3】

1 5
3 5 5 2
2

【样例 3 说明】

只有 1 天，没有"相邻"限制。热度 5 的项目有 2 个，选哪个都不同，故 2 种。

【数据范围与子任务】

对于 100% 的数据，1 ≤ m ≤ 100，1 ≤ S ≤ 5000，1 ≤ k_i ≤ 100，1 ≤ v_{i,j} ≤ 100。

子任务编号分数数据规模与特殊性质
1—315m ≤ 8，S ≤ 50
4—720k_i = 1（每天只有唯一选择）
8—1120同一天内各项目的热度值两两不同
12—1515m ≤ 20，S ≤ 500
16—2030无特殊限制
