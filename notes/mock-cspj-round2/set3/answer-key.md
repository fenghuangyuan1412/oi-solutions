## T1 无料排队 / lineup

**核心思路一句话**：$10^9$ 人的队伍存也存不下，所以从头到尾不存队伍——每轮取走位置 $1,4,7,\dots$ 共 $\lceil t/3\rceil = (t+2)/3$ 人，人数递推 $t \mathrel{-}= (t+2)/3$ 数出总轮数；编号 $x$ 只追踪它的**本轮位置** $p$，$p \bmod 3 == 1$ 即本轮被取走，否则 $p \mathrel{-}= (p+2)/3$ 换成下一轮的新位置。

核心代码（摘自 [`t1-lineup/solution.cpp`](t1-lineup/solution.cpp)）：

```cpp
long long t = n, rounds = 0;
while (t > 0) { rounds++; t -= (t + 2) / 3; }   // (t+2)/3 = ceil(t/3) = 本轮出列人数
long long p = x, mine = 0;
while (true) {
    mine++;
    if (p % 3 == 1) break;      // 本轮位置是 1、4、7…，被取走
    p -= (p + 2) / 3;           // 否则换成下一轮的新位置（前面出列的人数）
}
```

**样例正确答案**（与 README、`brute.cpp` 均一致）：`6 1` → `4 1`；`6 5` → `4 4`；`1 1` → `1 1`。

**部分分怎么给**（子任务见 `problem.txt` 第 54—60 行）：

| 子任务 | 分值 | 能过的做法 | 判分提示 |
| --- | --- | --- | --- |
| 1—2 | 10 | $n \le 10$：`brute.cpp` 的 `vector` 真模拟，每轮 `i % 3 == 0` 出列 | 数据太小，暴力满分 |
| 3—5 | 15 | $n \le 1000$：同上，模拟仍是 $O(n)$ 空间 | 这一档别急着讲递推 |
| 6—9 | 20 | $n \le 10^6$：`brute.cpp` 真模拟实测 0.023 s（输出 `33 1`）跑得动 | 这一档是"模拟够用"的上限，正解同样满分 |
| 10—13 | 20 | $x = 1$：位置 1 永远**首轮**被取走，第二个数直接写 `1` | 但总轮数仍要 $O(\log n)$ 递推，这一档不许模拟队伍 |
| 14—20 | 35 | 两条独立递推（人数 + 位置） | 见下方扣分点 |

**常见扣分点**：① **把编号当位置**（首轮两者相同，第二轮起分家；`x=5` 样例 2 是第 4 轮不是第 5 轮）；② 向上取整写成 `p / 3`，$p=2$ 时算成"前面走 0 人"→ **死循环**；③ 把两条循环合成一条（`while(t--)` 之类），轮数和位置互相污染；④ `break` 前忘 `mine++`，首轮就被取走的人输出 0 轮；⑤ `int` 存 `n`（$10^9$ 勉强够，`t+2` 再参与乘法即越界），统一 `long long` + `%lld`；⑥ 真开数组模拟：$10^9$ 个 `int` 是 3.7 GB，先 MLE 再 TLE。

## T2 体力药水 / potion

**核心思路一句话**：题目保证 $d \mid v_i$，所以第 $i$ 段要几瓶是定死的 $v_i/d$；人只能往前走 ⇒ 第 $i$ 段只能在点 $1 \dots i$ 买，背包无限大 ⇒ 各段互不干扰，逐段取**前缀最小值**即全局最优。注意 $a_n$ 永远用不上（终点不走路）。

核心代码（摘自 [`t2-potion/solution.cpp`](t2-potion/solution.cpp)）：

```cpp
long long ans = 0;
int cheapest = a[1];                      // 历史最低价，起点先垫上
for (int i = 1; i < n; i++) {
    cheapest = min(cheapest, a[i]);       // 先并入本站价格（本站可以买药）
    ans += 1LL * (v[i] / d) * cheapest;   // 1LL 把 int 乘法提升成 long long
}
```

**样例正确答案**（与 README、`brute.cpp` 均一致）：`5 10 / 10 10 10 10 / 9 8 9 6 5` → `31`（$m=(9,8,8,6)$）；`3 5 / 10 5 / 3 10 2` → `9`。

**部分分怎么给**（子任务见 `problem.txt` 第 109—115 行）：

| 子任务 | 分值 | 能过的做法 | 判分提示 |
| --- | --- | --- | --- |
| 1—3 | 15 | $n \le 10$：`brute.cpp` 每段回头重扫 $1 \dots i$ 找最小 | 双重循环 $O(n^2)$，此档正确且快 |
| 4—7 | 20 | $a_1$ 全局最小：前缀最小值恒为 $a_1$，一行公式 $a_1 \cdot \sum v_i / d$ | 不必真会维护 `cheapest` |
| 8—11 | 20 | 所有 $v_i = d$：每段恰好 1 瓶，$\text{ans} = \sum m_i$ | 只剩前缀最小值，瓶数那步白送 |
| 12—14 | 15 | $a_i$ 单调不升：每段都在自己起点买，`min` 可以省掉 | 写不出完整贪心的抢分档 |
| 15—20 | 30 | 完整 $O(n)$ 前缀最小值 | 见下方扣分点 |

**常见扣分点**：① `int` 存答案——满数据 `999990000000000`（$10^{15}$），`int` 上限 $2.1\times10^9$ 必爆，且 `v[i]/d*cheapest` 整体要先转 `long long`；② **两行顺序写反**（先 `ans +=` 再 `cheapest = min`）：实测样例 1 输出 `34`（正确 `31`），**但样例 2 照样输出 `9`，抓不出这个 bug**，批改时要单独问一句；③ 自己写 `(v[i]+d-1)/d` 向上取整（$d \mid v_i$ 是题目保证，画蛇添足）；④ 循环写成 `i <= n` 把 $a_n$ 也算进去；⑤ 想 $O(1)$ 空间边读边算——输入是先读完 $v$ 一整行才给 $a$，做不到；⑥ `scanf` 的 `%lld` 与 `%d` 混用。

**详解**：[t2-potion/README.md](t2-potion/README.md) ｜ 演示：[t2-potion/visualization.html](t2-potion/visualization.html)

## T3 暴击阈值 / dmg

**核心思路一句话**：难点不在解方程而在**精确输出**。先按 $\Delta$ 分支（$<0 \to$ `NO`；完全平方 $\to$ 有理；否则无理）；较大根要按 $a$ 的符号定支（实现上先把分母变正 `A = absll(2 * a)`、常数项取 `P = (a > 0 ? -b : b)`）；提干净平方因子 $\Delta = r k^2$；然后 $\gcd(\lvert P\rvert, Q, A)$ **三者同除**；最后照 $p=0 / q=1 / s=1$ 三个开关拼串。

核心代码（摘自 [`t3-dmg/solution.cpp`](t3-dmg/solution.cpp)）：

```cpp
ll D = b * b - 4 * a * c;
if (D < 0) { puts("NO"); continue; }
ll k = 1, r = D;                                   // √D = k·√r
for (ll t = 2; t * t <= r; t++)
    while (r % (t * t) == 0) { r /= t * t; k *= t; }   // while：同一因子可能提两次
ll A = absll(2 * a), P = (a > 0 ? -b : b), Q = k;
ll h = gcdll(gcdll(P, Q), A);  P /= h; Q /= h; ll S = A / h;   // 三个量一起约，r 不参与
string root = (Q == 1 ? "" : to_string(Q)) + "√" + to_string(r);   // 省略规则全在这 4 行
if (P == 0) return S == 1 ? root : root + "/" + to_string(S);   // p=0：不加括号
string body = to_string(P) + "+" + root;
return S == 1 ? body : "(" + body + ")/" + to_string(S);        // s>1 且 p≠0 才加括号
```

**样例正确答案**（README 实测与题面**逐字符一致**，`brute.cpp` 亦一致）：样例 1 八行 `√2`、`(-1+√5)/2`、`(3+√5)/2`、`1+√2`、`2`、`NO`、`(1+√5)/2`、`0`；样例 2 四行 `2√3`、`-1+√2`、`(3+√6)/3`、`√2/2`。第 7 行 `-1 1 1` → `(1+√5)/2` 专考 $a<0$ 换支。

**五种格式必须逐个核对**（$T=5000$ 全值域实测形态分布）：`NO` 1846 行、整数 `p` 4 行、`p/q` 21 行、`p+q√r`（$s=1$）3 行、`(p+q√r)/s` 3126 行。**漏一个分支就是成片扣分**，改卷时按这五种各挑一份代码手工比对。

**部分分怎么给**（子任务见 `problem.txt` 第 192—199 行）：

| 子任务 | 分值 | 能过的做法 | 判分提示 |
| --- | --- | --- | --- |
| 1—3 | 15 | $b = 0$：$t^2 = -c/a$，只需提平方因子，天然走 $p=0$ 拼串支 | 括号规则在这一档最容易看穿（$p=0$ 不加括号） |
| 4—6 | 15 | $c = 0$：一根为 0、一根 $-b/a$，较大根必是有理数甚至整数 | 只练到"整数 / `p/q`"两种格式 |
| 7—10 | 20 | 全部有有理根（$\Delta$ 完全平方或 $\Delta=0$）：只走有理分支 | 根式那套可以整段不写 |
| 11—13 | 15 | 全部无实根：`D < 0 → NO` 一行 | 最白送的一档，但别把 `NO` 打成 `No`/`0` |
| 14—16 | 15 | $a>0$、$\Delta>0$ 且 $s=1$：输出 `p+q√r` 或 `q√r` | 定支方向不用纠结（$a>0$ 取 $+$） |
| 17—20 | 20 | 完整五格式 + 三量约分 | 见下方扣分点 |

**常见扣分点**：① **输出小数**（`printf("%f")` 一行即 0 分，且浮点误差把整数根打成 `1.9999999999`）；② $a<0$ 忘换支，`-1 1 1` 给出较小根；③ 约分只约两个量（必须 $h = \gcd(\gcd(\lvert P\rvert,Q),A)$，$r$ 不参与）；④ 提平方因子写成 `if`：$\Delta = 72$ 时 $t=2$ 要连除两次，写成 `if` 会剩 $r=18$（仍含平方因子 9）；⑤ **括号规则**：$s>1$ **且** $p \ne 0$ 才加括号——`√2/2` 不加、`(-2+√6)/2` 要加；⑥ $q=1$ 还印系数（`1√2` 错，应 `√2`；$q>1$ 照写 `2√3`）；⑦ `√` 必须是 U+221A 单字符（UTF-8 三字节），写成 `sqrt(2)`/`v2` 全 0 分，源文件编码也要是 UTF-8；⑧ 整数开方直接用 `(ll)sqrt(x)`（差 1，`isqrt` 里前后两个 `while` 校正是必须的）；⑨ 负号跑到分母上（分母恒正）。

## T4 漫展通勤 / expo

**核心思路一句话**："时刻必须是 $k$ 的倍数才许上路"把边权变成**现算的** $\text{depart} = \text{round\_up}(\max(t, a))$、到达 $= \text{depart}+1$，等待 $[0, k-1]$ 使边权恒正；因为 $\max$ 与 round_up 都对 $t$ 单调不减（早到永远不亏），每个路口只保留一个最早时刻 `dist[u]` 即可，标准 Dijkstra 照跑。到达终点**不再等**。

核心代码（摘自 [`t4-expo/solution.cpp`](t4-expo/solution.cpp)）：

```cpp
inline ll round_up(ll x) { return (x + k - 1) / k * k; }   // 不小于 x 的第一个 k 倍数
PLI cur = pq.top(); pq.pop();  int u = cur.second;
if (cur.first != dist[u]) continue;                        // 堆里的旧记录必须跳
int v = e[u][i].first, a = e[u][i].second;
ll depart = round_up(max(cur.first, (ll)a));               // 先等开通，再等 k 的倍数
ll nd = depart + 1;
if (nd < dist[v]) { dist[v] = nd; pq.push(make_pair(nd, v)); }
```
最后输出 `dist[n] == INF ? -1 : dist[n]`，**不要**对答案再 round_up（README 观察 D：到达终点就结束）。

**样例正确答案**（与 README、`brute.cpp` 均一致）：样例 1（`3 3 2`，边 `1 2 0 / 2 3 1 / 1 3 5`）→ `3`；样例 2（`2 1 3`，边 `1 2 1`）→ `4`；样例 3（`4 2 2`，终点无入边）→ `-1`。

**"等到 $k$ 的倍数"这一处的四种错法**（README 实测，样例 3 **谁都过**，起不到检查作用）：忽略 $a_i$ 和 $k$ 直接 BFS → `1 1 -1`；只等 $k$ 的倍数忘了开通时刻 → `1 1 -1`；只等到开通时刻忘了 $k$ 的倍数 → `2 2 -1`；round_up 写成向下取整 → `1 1 -1`；正解 `3 4 -1`。改卷时先拿样例 1、2 卡这四种。

**部分分怎么给**（子任务见 `problem.txt` 第 259—265 行）：

| 子任务 | 分值 | 能过的做法 | 判分提示 |
| --- | --- | --- | --- |
| 1—3 | 15 | $n \le 10$、$a_i = 0$：DFS/状压枚举路径即可 | 只剩 round_up 一处要写对 |
| 4—7 | 20 | $k = 2$：完整 Dijkstra 本身就过；按奇偶时刻手推也能对 | 检查有没有把"到达时刻"也要求成 $k$ 的倍数（README 观察 C：只在**上路那一刻**查） |
| 8—11 | 20 | 每个路口出边 $\le 1$（图退化成链）：沿链模拟一遍 $O(n)$，不特判也能过（完整 Dijkstra 链式满数据 0.036 s） | 链上没有分支，最短路框架可以整段省掉 |
| 12—15 | 15 | $a_i \le 100$：把时刻当图的一层做 BFS（即 `brute.cpp` 思路） | 状态 $n \times 10^3$ 才跑得动，$a_i$ 到 $10^6$ 即崩 |
| 16—20 | 30 | 完整 Dijkstra + `round_up(max(t,a))` + 跳旧记录 | 见上方四种错法与下方扣分点 |

**常见扣分点**：① `max(t, a)` 与 round_up **少任何一个**（见上表）；② round_up 写成 `x / k * k`（向下取整＝"等到过去"）或 `(x + k) / k * k`（$x$ 恰为倍数时白等一整轮 $k$）；③ 忘 `if (cur.first != dist[u]) continue;`——答案仍对但复杂度失去保证，README 构造数据实测 0.034 s → 0.619 s；④ 给 `dist[n]` 再 round_up 一次，最多亏 $k-1$ 分钟；⑤ 多开 `dist[u][t % k]` 分层图（$10^4 \times 100$ 状态，观察 B 已证明不需要，容易写崩）；⑥ 重边用 `bool`/去丢掉边（本题只留 $a$ 最小那条恰好安全，但思路不通用）；⑦ `-1` 判成 `dist[n] == -1`（初值不是 -1，应判 `== INF`）；⑧ `max(cur.first, a)` 漏 `(ll)` 导致 `std::max` 类型不一致编译报错。

## 批改时的三个通用提醒

1. **对齐关系**：本套 4 题分别对齐 CSP-J 2023 第二轮 T1—T4（P9748 小苹果 / P9749 公路 / P9750 一元二次方程 / P9751 旅游巴士）的考点，`problem.txt` 第 5 行已注明，但**都是自编模拟卷，不是任何一年的真题原题**。学生整段背真题代码会在这几处直接错：T1（本题每轮取走整支队伍约 $1/3$ 的人并问"编号 $x$ 第几轮被取走"，不是"每轮吃队首 1 个、问第几轮 + 谁在队首"）、T3（真题要**较小**根且有"两根相等"的输出约定，本题要**较大**根 + 五种格式串）、T4（本题问最早到达时刻且到达终点不再等，真题问的是等车口径）。
2. **`brute.cpp` 只用于对拍**：T1 的 `vector` 真模拟 $n = 10^9$ 实测 27.031 s 且需 3.7 GB；T2 的双重循环满数据 3.442 s；T3 的是"猜答案反验"，枚举上界写死 $s \le 2000$、$r \le 5000$，实测 `824 0 -590`（真答案 `√30385/206`）与 `1000 999 1` 都输出 `BUG`，只能在 $|a|,|b|,|c| \le 6$ 用；T4 的把时刻当一层、数组写死 `N = 12`、`B = 400`，输入 `3 2 2 / 1 2 0 / 2 3 500` 输出 `-1`（正确 `501`）。它们本身就是"部分分实现"，别当满分参考。
3. **本卷按标准输入输出练习**（`problem.txt` 第 4 行注明，正式复赛要求 `freopen` 文件读写）。两处纯实现细节按提醒处理、不必判死：T3 的 `√` 依赖源文件存成 UTF-8，环境不匹配时可能显示为乱码但思路正确；T4 的 `long long` 只是省心（答案上界约 $10^6 + 10^4 \times 100 \approx 2\times 10^6$，本机最坏链式 `1999801`，`int` 放得下），而 T2 的 `long long` 是**硬要求**（$10^{15}$）。
