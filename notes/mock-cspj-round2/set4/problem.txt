== T1 伤害溢出 / power ==
【题目描述】
某个技能的伤害倍率是 `a^b`（`a` 是攻击力，`b` 是叠层数）。服务器的存档字段最多只能存下 `10^9`，一旦倍率**严格大于** `10^9` 就会溢出，程序必须输出 `over` 而不是硬算出来。

给定正整数 `a` 和非负整数 `b`，如果 `a^b ≤ 10^9`，输出它的值；否则输出 `over`。

（约定 `b = 0` 时 `a^b = 1`。）

【输入格式】
一行两个整数 `a`、`b`。

【输出格式】
一行，一个整数表示 `a^b` 的值，或者字符串 `over`。

【输入输出样例 1】
```
10 9
```
```
1000000000
```

【输入输出样例 2】
```
10 10
```
```
over
```

【输入输出样例 3】
```
2 29
```
```
536870912
```

【输入输出样例 4】
```
1 1000000000
```
```
1
```

【数据范围与子任务】
对于 100% 的数据，1 ≤ a ≤ 10^9，0 ≤ b ≤ 10^9。

| 子任务编号 | 分数 | 数据规模与特殊性质 |
| --- | --- | --- |
| 1—3 | 15 | `b ≤ 3` |
| 4—7 | 20 | `b ≤ 20` 且 `a ≤ 100` |
| 8—11 | 20 | `a = 2` |
| 12—14 | 15 | 保证答案不超过 `10^9` |
| 15—20 | 30 | 无特殊限制 |

== T2 暗号解码 / decode ==
【题目描述】
群里流传一种"暗号"写法：把一个正整数 `x` 写成 `x + S(x)`，其中 `S(x)` 是 `x` 的十进制数位之和。例如 `x = 12` 的暗号是 `12 + 1 + 2 = 15`。

现在小 Q 看到了一个暗号值 `N`，想知道**最小**的正整数 `x`，使得 `x` 的暗号恰好等于 `N`。如果这样的 `x` 根本不存在，输出 `-1`。

【输入格式】
一行一个整数 `N`。

【输出格式】
一行一个整数，表示最小的 `x`，或 `-1`。

【输入输出样例 1】
```
8
```
```
4
```

【样例 1 说明】
`4 + 4 = 8`。比 4 小的正整数里，`1→2`、`2→4`、`3→6`，都凑不出 8。

【输入输出样例 2】
```
100
```
```
86
```

【输入输出样例 3】
```
1
```
```
-1
```

【数据范围与子任务】
对于 100% 的数据，1 ≤ N ≤ 10^9。

| 子任务编号 | 分数 | 数据规模与特殊性质 |
| --- | --- | --- |
| 1—3 | 15 | `N ≤ 100` |
| 4—7 | 20 | `N ≤ 10^5` |
| 8—11 | 20 | 保证解存在 |
| 12—14 | 15 | 解恰好是 `N - 10` |
| 15—20 | 30 | 无特殊限制 |

== T3 连招公式 / expr ==
【题目描述】
一份连招伤害公式是一个字符串，由**非负整数**、加号 `+`、乘号 `*`、左括号 `(`、右括号 `)` 组成，不含空格。运算规则是平常的四则运算：括号优先，`*` 优先于 `+`。

由于公式里的数字可能非常巨大，所有运算都要对 `998244353` 取模（也就是说，中间结果和最终答案都只保留除以 `998244353` 的余数）。

小 L 想知道：

1. 这个公式的值（对 `998244353` 取模）；
2. 公式里括号的**最大嵌套深度**（即最多有多少层左括号是套在一起的）。

【输入格式】
一行一个字符串，表示合法的公式，长度不超过 10^5。保证公式中每个数字都不超过 10^9，且不会出现连续的运算符或空的括号。

【输出格式】
第一行一个整数，表示公式的值；
第二行一个整数，表示括号的最大嵌套深度。

【输入输出样例 1】
```
1+2*3
```
```
7
0
```

【输入输出样例 2】
```
(1+2)*3
```
```
9
1
```

【输入输出样例 3】
```
((1+2)*(3+4))*2
```
```
42
2
```

【输入输出样例 4】
```
1+(2+3*(4+(5+6)))*7
```
```
330
3
```

【样例 4 说明】
从里往外算：`5+6 = 11`，`4+11 = 15`，`3*15 = 45`，`2+45 = 47`，`47*7 = 329`，`1+329 = 330`。

【数据范围与子任务】
对于 100% 的数据，公式长度不超过 10^5，公式合法，每个数字 ≤ 10^9，最大嵌套深度不超过 10^5。

| 子任务编号 | 分数 | 特殊性质 |
| --- | --- | --- |
| 1—3 | 15 | 没有括号 |
| 4—7 | 20 | 只有 `+`，没有 `*` |
| 8—11 | 20 | 长度 ≤ 100 |
| 12—14 | 15 | 所有数字都是个位数 |
| 15—20 | 30 | 无特殊限制 |

== T4 谷价走势 / trend ==
【题目描述】
某热门谷子（周边）连续 `n` 天的交易均价依次是 `p_1, p_2, …, p_n`。

小 F 想发一条"涨价实录"帖子，从这 `n` 天里选出若干天 `i_1 < i_2 < … < i_m`，要求：

- 均价**严格上升**：`p_{i_1} < p_{i_2} < … < p_{i_m}`；
- 为了"热度不断档"，相邻两次选取**最多间隔 `d` 天**，即 `i_{j+1} - i_j ≤ d`。

求 `m` 的最大值，以及能取到最大 `m` 的**选取方案数**。方案数对 `998244353` 取模。

（只选 1 天也是合法的，此时 `m = 1`。）

【输入格式】
第一行两个整数 `n`、`d`。
第二行 `n` 个整数 `p_1, p_2, …, p_n`。

【输出格式】
一行两个整数，依次表示最大的 `m` 和对应的方案数（对 `998244353` 取模）。

【输入输出样例 1】
```
6 2
3 1 2 1 3 4
```
```
4 1
```

【样例 1 说明】
只能选第 `2, 3, 5, 6` 天（价格 `1 < 2 < 3 < 4`，间隔分别是 1、2、1，都不超过 2），共 1 种方案。

【输入输出样例 2】
```
5 5
1 1 2 2 3
```
```
3 4
```

【样例 2 说明】
`d = 5` 相当于没有间隔限制。长度为 3 的严格上升子序列有 `(1,3,5)`、`(2,3,5)`、`(1,4,5)`、`(2,4,5)` 共 4 种。

【输入输出样例 3】
```
5 1
1 5 2 3 4
```
```
3 1
```

【样例 3 说明】
`d = 1` 意味着必须选连续的日子。最长的连续严格上升段是第 `3, 4, 5` 天（`2 < 3 < 4`）。

【数据范围与子任务】
对于 100% 的数据，1 ≤ n ≤ 5000，1 ≤ d ≤ 5000，1 ≤ p_i ≤ 10^9。

| 子任务编号 | 分数 | 数据规模与特殊性质 |
| --- | --- | --- |
| 1—3 | 15 | `n ≤ 18` |
| 4—7 | 20 | `d = 1` |
| 8—11 | 20 | `d ≥ n`（即没有间隔限制） |
| 12—14 | 15 | `p_i` 互不相同且 `n ≤ 500` |
| 15—20 | 30 | 无特殊限制 |
