## T1 痛车车牌 / plate

**核心思路一句话**：位数被"必须用完所有数字"钉死了，所以最小 = 首位取最小的非零数字 + 其余位升序；数字只有 10 种，用 10 个桶计数即可，不必排序。

```cpp
for (char c : s) if (c >= '0' && c <= '9') cnt[c - '0']++;      // 过滤字母
int first = 1; while (!cnt[first]) first++;                      // 最小非零数字
putchar('0' + first); cnt[first]--;
for (int i = 0; i < cnt[0]; i++) putchar('0');                   // 0 紧跟首位
for (int d = 1; d <= 9; d++) for (int i = 0; i < cnt[d]; i++) putchar('0' + d);
```

**部分分怎么给**（子任务见题面表）：

| 子任务 | 分值 | 能过的做法 | 判分提示 |
| --- | --- | --- | --- |
| 1—3 | 15 | 数字个数 ≤ 10：全排列取最小（`brute.cpp`） | 只写排序不给这 15 分的额外分，排序本身也能过 |
| 4—8 | 25 | 仅含数字：`sort` 升序输出，再手工把首个非零换到前面 | 忘记处理前导零 → 样例 2 `x000y5` 会输出 `0005`，此处必错 |
| 9—13 | 25 | 数字 ≤ 10^3：$O(D\log D)$ 排序 + 首位特殊处理 | 与上一档同一份代码，能过 |
| 14—20 | 35 | 计数桶 $O(\|s\|)$ | 用 `long long` 存答案 → 这一档全灭，前面也可能灭 |

**常见扣分点**：① 没过滤字母，直接 `cnt[c-'0']++`（越界写，未定义行为，可能碰巧对也可能 RE）；② 把 0 排在最前（前导零）；③ 把 0 留在末尾（那是拼**最大**数的写法，真题 P14357 的套路，学生最容易混）；④ 用整数存答案；⑤ `endl` 输出 $10^6$ 次导致 TLE。

**详解**：[t1-plate/README.md](t1-plate/README.md) ｜ 演示：[t1-plate/visualization.html](t1-plate/visualization.html)

## T2 吧唧墙 / badge

**核心思路一句话**：只问喜爱度为 $x$ 的那一枚，所以先数"比 $x$ 大的有几个"得到名次（$+1$），再让螺旋只走到第 rank 格就 `return`——不用排序、不用存数组、不用铺满整面墙。

```cpp
long long rank = 1;
for (int i = 1; i <= n * m; i++) { scanf("%lld", &a); if (a > x) rank++; }   // 只要名次
int top = 1, bot = n, lft = 1, rgt = m, step = 0;
while (top <= bot && lft <= rgt) {
    for (int j = lft; j <= rgt; j++) if (++step == rank) { printf("%d %d\n", top, j); return 0; }
    top++;
    for (int i = top; i <= bot; i++) if (++step == rank) { printf("%d %d\n", i, rgt); return 0; }
    rgt--;
    if (top <= bot) { /* 下边向左 */ bot--; }        // 这两个 if 是全部坑
    if (lft <= rgt) { /* 左边向上 */ lft++; }
}
```

**部分分怎么给**：

| 子任务 | 分值 | 能过的做法 | 判分提示 |
| --- | --- | --- | --- |
| 1—4 | 20 | $n = 1$ 或 $m = 1$：螺旋退化成直线，答案 $(1, rank)$ 或 $(rank, 1)$ | 实测 `1 5 1`→`1 5`、`5 1 1`→`5 1` |
| 5—9 | 25 | $a_i = i$：名次 $= nm - x + 1$，直接算，不必读第二行 | 仍要螺旋走格子正确 |
| 10—14 | 25 | $nm \le 100$：完整模拟（`brute.cpp` 的"笔走 + 撞墙右转"） | 这份代码在 $30 \times 30$ 也只有 0.052 s，**不会超时**，只是难写对 |
| 15—20 | 30 | 边界收缩 + 只数名次 | 缺 `if (top <= bot)` / `if (lft <= rgt)` 会在只剩一行/一列时重复计数 |

**常见扣分点**：① 把 $(a_i, i)$ 存下来排序（能做对，但多写且易错）；② 转向条件只判"越界"忘了"已放过"；③ 输出 0 起下标；④ 以为 $a_i$ 的下标就是位置（位置由喜爱度决定，与输入顺序无关）；⑤ $a_i$ 到 $10^9$，用 `int` 存能过但比较时别混 `long long` 读入格式符写错（`%lld` 配 `int` 是 UB）。

**详解**：[t2-badge/README.md](t2-badge/README.md) ｜ 演示：[t2-badge/visualization.html](t2-badge/visualization.html)

## T3 深渊连击 / combo

**核心思路一句话**：血量全为正 ⇒ 窗口和随左端点右移严格变小，可以尺取；又因为以 $r$ 结尾的合法段至多一个，所以从左往右第一次凑出 $k$ 就立刻收割（最早结束贪心），并把 $l$ 跳到 $r+1$。

```cpp
long long ans = 0, sum = 0; int l = 1;
for (int r = 1; r <= n; r++) {
    sum += a[r];
    while (l <= r && sum > k) { sum -= a[l]; l++; }   // 全正才敢只前进
    if (sum == k) { ans++; sum = 0; l = r + 1; }      // 收割 = 这段作废
}
```

**部分分怎么给**：

| 子任务 | 分值 | 能过的做法 | 判分提示 |
| --- | --- | --- | --- |
| 1—3 | 15 | $n \le 20$：枚举区间 + 判重叠，或状压 | 直接数区间个数在这一档就可能对（数据太小），别在这档手软 |
| 4—7 | 20 | $n \le 2000$：$O(n^2)$ DP `f[i]=max(f[i-1], f[j-1]+1)`（`brute.cpp`） | 注意仓库里的 `brute.cpp` 数组只开到 305，$n > 300$ 会越界，学生版若开到 2005 才能拿这 20 分 |
| 8—11 | 20 | $a_i \equiv 1$：答案 $= n / k$（整除） | 实测 $n=10^6, k=1000$ → `1000`，与 $n/k$ 一致 |
| 12—15 | 15 | $k \le 10^3$：合法区间长度 $\le k$，$O(nk)$ 枚举 | $10^6 \times 10^3$ 仍偏大，实际靠 `sum > k` 提前 break，能拿分 |
| 16—20 | 30 | 尺取 + 最早结束贪心 | 见下方"最典型的错解" |

**最典型的错解（务必单独看一眼）**：用前缀和 + 哈希表**数出所有和为 $k$ 的区间个数**，忽略"互不重叠"。本机实测：样例 3（`8 3 / 1 2 1 2 1 1 1 3`）区间个数是 **6**，正解是 **4**，所以这份代码样例就过不去；小反例 `3 3 / 1 2 1` 个数 2、正解 1。判分时给 0～15 分（视其是否另有部分实现）。

**其他扣分点**：① 收割后忘记 `sum = 0; l = r + 1`；② `while` 缺 `l <= r`（$a_r > k$ 时会错）；③ `sum` 用 `int`（$k$ 到 $10^9$，$n \cdot a_i$ 最大 $10^9$，贴边）；④ 想用"排序后取前缀"等与本题无关的做法。

**详解**：[t3-combo/README.md](t3-combo/README.md) ｜ 演示：[t3-combo/visualization.html](t3-combo/visualization.html)

## T4 二创投稿 / clip

**核心思路一句话**："严格大于 $S$" 的方案数不好直接数，先数反面：答案 $= 2^n - |\{\text{子集：和} \le S\}|$，后者是**计数型 01 背包**（$f[s]$ = 和恰好为 $s$ 的方案数，一维倒序转移），背包只需开到 $\lim = \min(S, sum)$。

```cpp
if (S >= sum) { puts("0"); return 0; }                 // 子任务 12—14 白送
int lim = min(S, sum);  f[0] = 1;
for (int i = 1; i <= n; i++)
    for (int s = lim; s >= a[i]; s--) {                // 倒序：每段只能用一次
        f[s] += f[s - a[i]]; if (f[s] >= MOD) f[s] -= MOD;
    }
long long le = 0; for (int s = 0; s <= lim; s++) { le += f[s]; if (le >= MOD) le -= MOD; }
long long all = 1; for (int i = 1; i <= n; i++) all = all * 2 % MOD;
printf("%lld\n", (all - le + MOD) % MOD);
```

**部分分怎么给**：

| 子任务 | 分值 | 能过的做法 | 判分提示 |
| --- | --- | --- | --- |
| 1—3 | 15 | $n \le 20$：状压枚举 $2^n$（`brute.cpp`） | 实测 $n=25$ 已要 1.853 s，$n$ 每 +1 翻倍 |
| 4—7 | 20 | $sum \le 5000$：背包开到 $sum$，$O(n \cdot sum)$ | 与满分解同一份代码，只是 $\lim$ 上界不同 |
| 8—11 | 20 | $a_i$ 全部相同：设每段长 $v$，答案 $= \sum_{j > S/v} \binom{n}{j}$，需要组合数递推 | 实测 $n=300, v=300, S=45000$ → `559632968`，与闭合式 $(2^{300} - \binom{300}{150})/2 \bmod$ 一致 |
| 12—14 | 15 | $S \ge sum$：直接输出 `0` | 实测 $S = 90000 = sum$ → `0`；不判也能算对，只是慢 |
| 15—20 | 30 | 完整补集 + 背包 | 见下方扣分点 |

**常见扣分点**：① 把"严格大于"实现成"大于等于"（样例 1 会多数 $\{3\}$ 与 $\{1,2\}$，输出 5 而不是 3）；② 内层正序枚举 $s$（变成完全背包，同一段素材用多次）；③ 忘 $f[0] = 1$；④ 最后减法没 `+ MOD` 出现负数；⑤ `f` 数组开不到 90005 越界；⑥ 把 $2^n$ 用 `1 << n` 算（$n = 300$ 直接爆）。
