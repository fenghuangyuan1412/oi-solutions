== T1 痛车车牌 / plate ==
【题目描述】
小 Q 给自己的痛车定制了一块车牌。喷涂机出了故障，屏幕上只剩下一串混乱的字符 `s`，里面既有小写字母（故障产生的噪声），也有数字。

小 Q 决定把 `s` 中的**所有数字字符**各用一次，重新排列成一个**没有前导零**的正整数，作为车牌号码。她希望这个数尽可能**小**——因为数字越短越小，越好记。

` s ` 中至少含有一个 `1`—`9` 的数字，因此答案一定存在。

注意：车牌可能非常长（最多 10^6 位），它已经超出了 `long long` 的范围，请把它当成**字符串**输出。

【输入格式】
一行，一个只由小写字母和数字组成的字符串 `s`。

【输出格式】
一行，一个不含前导零的正整数，表示能拼出的最小车牌号。

【输入输出样例 1】
```
a1b0c2
```
```
102
```

【样例 1 说明】
数字依次是 `1`、`0`、`2`。把它们全部用上，能拼出的数里最小的是 `102`（`012` 有前导零，不合法）。

【输入输出样例 2】
```
x000y5
```
```
5000
```

【输入输出样例 3】
```
9z8k7
```
```
789
```

【数据范围与子任务】
对于 100% 的数据，1 ≤ |s| ≤ 10^6，`s` 仅由小写英文字母和数字组成，且至少含一个 `1`—`9` 的数字。

| 子任务编号 | 分数 | 特殊性质 |
| --- | --- | --- |
| 1—3 | 15 | `s` 中仅含数字，且 \|s\| ≤ 10 |
| 4—8 | 25 | `s` 中仅含数字 |
| 9—13 | 25 | `s` 中至多有 10^3 个数字 |
| 14—20 | 35 | 无特殊限制 |

== T2 吧唧墙 / badge ==
【题目描述】
小 M 有一面展示墙，墙上有 `n` 行 `m` 列共 `n × m` 个格子。她一共 `n × m` 枚吧唧（徽章），第 `i` 枚吧唧的"喜爱度"是一个整数 `a_i`，所有喜爱度**互不相同**。

摆放规则如下：

- 按喜爱度**从大到小**依次摆放吧唧，喜爱度最高的第一枚先上墙。
- 摆放位置从第 `1` 行第 `1` 列的格子开始，沿着**顺时针螺旋**一圈一圈向内推进：一直向右，撞到边界或已放过的格子就向下，然后向左、向上、再向右……
- 每枚吧唧恰好占一个格子，且所有格子最终都会被填满。

例如 `3 × 3` 的墙，摆放顺序（括号内是"第几枚上墙"）为：

```
(1,1)→(1,2)→(1,3)    即  1 2 3
                      6 9 4
                      5 8 7   ← 注意 (2,2) 是第 9 枚
```

↑ 上表中的数字表示"第几枚吧唧"，即喜爱度排名第几。

现在小 M 想知道：喜爱度为 `x` 的那枚吧唧，最后被摆在了第几行第几列？

【输入格式】
第一行三个整数 `n`、`m`、`x`。
第二行 `n × m` 个整数 `a_1, a_2, …, a_{n×m}`，表示第 `i` 枚吧唧的喜爱度。保证 `x` 一定在 `a` 中出现过。

【输出格式】
输出一行两个整数 `r`、`c`，表示喜爱度为 `x` 的吧唧位于第 `r` 行第 `c` 列。

【输入输出样例 1】
```
3 3 40
50 60 70 80 90 10 20 30 40
```
```
3 2
```

【样例 1 说明】
喜爱度从大到小排序为 `90, 80, 70, 60, 50, 40, 30, 20, 10`，所以 `40` 是第 6 枚上墙的吧唧。按螺旋顺序第 6 个位置是 `(3,2)`。

【输入输出样例 2】
```
2 3 8
5 6 7 8 9 10
```
```
1 3
```

【数据范围与子任务】
对于 100% 的数据，1 ≤ n, m ≤ 30，1 ≤ a_i ≤ 10^9，`a_i` 互不相同，1 ≤ x ≤ 10^9。

| 子任务编号 | 分数 | 特殊性质 |
| --- | --- | --- |
| 1—4 | 20 | `n = 1` 或 `m = 1` |
| 5—9 | 25 | `a_i = i`（即编号越大喜爱度越高） |
| 10—14 | 25 | `n × m ≤ 100` |
| 15—20 | 30 | 无特殊限制 |

== T3 深渊连击 / combo ==
【题目描述】
深渊的一层里有一排 `n` 只怪物，从左到右编号 `1` 到 `n`，第 `i` 只怪物的血量为 `a_i`（`a_i` 为正整数）。

小 F 的一次"连击"必须打一段**连续**的怪物，即选择区间 `[l, r]`，这次连击造成的总伤害等于 `a_l + a_{l+1} + … + a_r`。

她想知道：最多能打出多少段总伤害**恰好等于 `k`** 的连击，并且这些连击**互不重叠**（任意两段对应的区间没有公共位置）。每段连击之间不需要连续，允许跳过一些怪物不打。

【输入格式】
第一行两个整数 `n`、`k`。
第二行 `n` 个正整数 `a_1, a_2, …, a_n`。

【输出格式】
一行一个整数，表示最多可以打出的连击段数。

【输入输出样例 1】
```
6 5
2 3 1 4 2 3
```
```
3
```

【样例 1 说明】
选 `[1,2]`（伤害 2+3=5）、`[3,4]`（伤害 1+4=5）、`[5,6]`（伤害 2+3=5），三段互不重叠，共 3 段。

【输入输出样例 2】
```
3 7
3 3 3
```
```
0
```

【样例 2 说明】
所有连续区间的和为 3、6、9，没有一个恰好等于 7，一段都打不出来。

【输入输出样例 3】
```
8 3
1 2 1 2 1 1 1 3
```
```
4
```

【数据范围与子任务】
对于 100% 的数据，1 ≤ n ≤ 10^6，1 ≤ k ≤ 10^9，1 ≤ a_i ≤ 10^3。

| 子任务编号 | 分数 | 数据规模与特殊性质 |
| --- | --- | --- |
| 1—3 | 15 | `n ≤ 20` |
| 4—7 | 20 | `n ≤ 2000` |
| 8—11 | 20 | `a_i = 1` |
| 12—15 | 15 | `k ≤ 10^3` |
| 16—20 | 30 | 无特殊限制 |

== T4 二创投稿 / clip ==
【题目描述】
小 A 的电脑里存着 `n` 段自制素材，第 `i` 段时长 `a_i` 秒。她准备从中**选出若干段**（可以是 0 段，也可以是全部）拼成一条投稿视频。

每个素材最多使用一次；两个方案相同，当且仅当它们选出的素材**集合**相同（拼接顺序不同不算作新方案）。

平台的规定是：只有总时长**严格大于** `S` 秒的视频才能进入推荐池。

求能进入推荐池的方案数。由于答案可能非常大，请对 `998244353` 取模后输出。

【输入格式】
第一行两个整数 `n`、`S`。
第二行 `n` 个正整数 `a_1, a_2, …, a_n`。

【输出格式】
一行一个整数，表示方案数对 `998244353` 取模的结果。

【输入输出样例 1】
```
3 3
1 2 3
```
```
3
```

【样例 1 说明】
全部 8 个子集里，总时长严格大于 3 的有 `{1,3}`（4 秒）、`{2,3}`（5 秒）、`{1,2,3}`（6 秒），共 3 种。`{3}` 与 `{1,2}` 的总时长恰好是 3，不满足"严格大于"。

【输入输出样例 2】
```
4 5
2 2 2 2
```
```
5
```

【样例 2 说明】
至少要选 3 段：选 3 段有 C(4,3)=4 种，选 4 段有 1 种，共 5 种。

【数据范围与子任务】
对于 100% 的数据，1 ≤ n ≤ 300，1 ≤ a_i ≤ 300，0 ≤ S ≤ 90000。记 `sum = a_1 + a_2 + … + a_n`。

| 子任务编号 | 分数 | 数据规模与特殊性质 |
| --- | --- | --- |
| 1—3 | 15 | `n ≤ 20` |
| 4—7 | 20 | `sum ≤ 5000` |
| 8—11 | 20 | `a_i` 全部相同 |
| 12—14 | 15 | `S ≥ sum` |
| 15—20 | 30 | 无特殊限制 |
