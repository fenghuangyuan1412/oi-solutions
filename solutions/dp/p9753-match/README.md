## 题目大意

给一个长度 $n$ 的小写字符串。一次操作可以**删掉两个相邻的相同字符**，删完两边拼接。能被若干次操作删**空**的串叫**可消除**。问所有非空连续子串里有多少个可消除。

两条立刻要记住的硬事实：

1. 每次删 2 个 ⇒ **奇数长度的子串永远不可能可消除**；
2. 消的顺序**不影响结果**（见第二节观察 1），所以判定一个串可以直接用"栈"。

### 样例 1 手算：为什么答案是 5

输入 `8 / accabccb`，洛谷给的可消子串是 `cc`、`acca`、`cc`、`bccb`、`accabccb`。用程序逐个枚举（实测输出，闭区间）：

| 子串 | 位置 | 怎么删 |
| --- | --- | --- |
| `cc` | $[2,3]$ | 直接删 |
| `acca` | $[1,4]$ | 删 `cc` → `aa` → 删空 |
| `cc` | $[6,7]$ | 直接删 |
| `bccb` | $[5,8]$ | 删 `cc` → `bb` → 删空 |
| `accabccb` | $[1,8]$ | 前 4 个删空、后 4 个删空 |

**合计 5 个**（程序输出 `合计 5`）。再看板书用的前缀栈表（`solution.cpp` 的中间量，实测打印）：

| $i$ | 新字符 | 前缀 $s[1..i]$ 约简后的栈 | 栈深 | 这个栈之前出现过几次 | 累计答案 |
| --- | --- | --- | --- | --- | --- |
| 0 | — | （空） | 0 | 初始化 1 | 0 |
| 1 | a | `a` | 1 | 0 | 0 |
| 2 | c | `ac` | 2 | 0 | 0 |
| 3 | c | `a` | 1 | **1** | **1** ← 子串 $[2,3]$ `cc` |
| 4 | a | （空） | 0 | **1** | **2** ← 子串 $[1,4]$ `acca` |
| 5 | b | `b` | 1 | 0 | 2 |
| 6 | c | `bc` | 2 | 0 | 2 |
| 7 | c | `b` | 1 | **1** | **3** ← 子串 $[6,7]$ `cc` |
| 8 | b | （空） | 0 | **2** | **5** ← 子串 $[5,8]$ `bccb` 和 $[1,8]$ 整串 |

最后一行一次加 2，是因为栈"空"在前面出现过 2 次（第 0 位和第 4 位），两个起点各对应一个以 8 结尾的可消子串。**这张表就是正解的全部**。

### 骗分思路 1（档 1）：暴力本身就是分数

`solution_partial.cpp` 的 `bruteAll()` 就是"枚举所有子串 + 按题意 DFS 判断能不能删空"，$n\le10$ 用它是**零风险**的。但要清楚它的极限：把这份代码的分支阈值放开后实测（10 字母随机串）：$n=20$ 5 ms、$40$ 6 ms、$60$ 125 ms、$100$ **548 ms**、$150$ **10 秒后终止**、$200$ **10 秒后终止**。也就是说**纯暴力连 $n=800$ 档都救不了**，它只值 25 分。

### 骗分思路 2（档 2~3）：区间 DP，以及它为什么在 8000 档靠不住

不接受任何引理也能做：设 $\text{row}[l][r]$ = 子串 $s[l..r]$ 是否可消除。看 $l$ 最后一次被删时和谁配对（设为 $k$），则 $s_k=s_l$、$[l+1..k-1]$ 可消空、$[k+1..r]$ 可消空。代码里先由"$s_k=s_l$ 且中间可消"标出 $[l..k]$，再把 $[l..k]$ 后面接上任意一段可消空的。

它的代价是**时间最坏 $O(n^3)$、空间 $O(n^2)$**：$n=8000$ 时数组 $6.4\times10^7$ 字节（本机 64 MB 级别能开），但 $n=2\times10^5$ 时要 $4\times10^{10}$ 字节——**这一档它本来就过不了**，实测也是 10 秒后终止（无输出）。上表的四组 $n=8000$ 数据说明"能不能过全看数据长相"，讲课时不要把它当 8000 档的稳定解。

### 骗分思路 3（档 2~3 的正解）：$O(n^2)$ 逐左端点约简（推荐）

只要接受"栈约简判可消"这一条引理，中间档的代码会变成五行，而且**时间和内存各降一档**（$O(n^2)$ 时间、$O(n)$ 空间）：

```cpp
for (int l = 0; l < n; ++l) {
    st.clear();
    for (int r = l; r < n; ++r) {
        if (!st.empty() && st.back() == s[r]) st.pop_back(); else st.push_back(s[r]);
        if (st.empty()) ++ans;              // s[l..r] 约简后为空 => 可消除
    }
}
```

实测（本机临时版本，代码不在本目录）：$n=800$ 随机 8 ms；$n=8000$ 随机 45 ms、只有 a、b 88 ms、全同字符 39 ms；$n=2\times10^5$ **10 秒后终止**。和区间 DP 在 504 组小数据 + 135 组中等数据上输出完全一致。

### 骗分思路 4（性质 A：随机串）：截断长度

"每个字符独立等概率"意味着长子串能消空的概率指数级小，于是**只枚举长度 $\le 20$ 的子串**：$n=2\times10^5$ 实测 14 ms、$n=2\times10^6$ 实测 65 ms，而且输出 `8280` / `82779` 与正解**一字不差**。

但**这个做法只在真随机的数据上成立**，同一份代码（$K=20$）在另外两类数据上实测：只有 a、b 的串 158 ms 跑出 `5394418`（真值 `1059213312`，**差 196 倍**）；全同字符 52 ms 跑出 `19999900`（真值 `1000000000000`）。另外在 504 组 $n\le35$ 的样本（穷举抽样 + 随机串）里它有 **3 组偏小**（$n=29$ 算 32 / 真值 34，$n=32$ 算 30 / 真值 31，$n=35$ 算 37 / 真值 39）。手册 T4 的红线在这儿完全适用：**挑有正确性保证的分支写，别把"随机数据上碰巧对"当算法**。

### 骗分思路 5（性质 B：只有 a、b）：状态桶

只有两个字母时，约简后的栈一定是**交替串**（不可能有相邻相同），于是"栈深 + 栈底字符"就唯一决定了栈内容 ⇒ 状态数是 $2n$ 量级，直接开桶配对，一行 $O(n)$：

```cpp
long long key = (top == 0) ? 0 : 2 * top + (stk[1] == 'b');   // 桶号
ans += seen[key]; ++seen[key];
```

实测：$n=2\times10^5$（a、b 随机）10 ms 输出 `55818786`，$n=2\times10^6$ 24 ms 输出 `1059213312`，全同字符 $2\times10^6$ 18 ms 输出 `1000000000000`，`abab…` 19 ms 输出 `0`——四个都和正解一致。正确性另用 8340 组纯 a、b 串验证：$n\le12$ 的 8190 组**全部穷举**（参照是"按定义 DFS"），再加 150 组随机 $13\le n\le72$（参照是"逐子串栈约简"），**0 不一致**。

## 二、正解思路：把"子串"问题压成"前缀配对"

### 观察 1：删法不唯一，但结果唯一

规则只有"删相邻的一对相同字符"。若某个串里有两对可删的相邻相同字符，它们要么不相交（先删哪对都一样），要么重叠在 `aaa` 上（删左边剩 `a`，删右边也剩 `a`）。**所有可能的删法最终都停在同一个"最简串"上**（终止 + 局部合流）。所以判定可消除只需跑**一种**删法：用栈，新字符和栈顶相同就弹栈，否则压栈；栈空 ⇔ 可消除。

### 观察 2：子串可消 ⇔ 两端前缀的栈相同

把每个字母看成"自己的逆元"，前缀 $s[1..i]$ 约简后的栈就是它的"群元素"。子串 $s[l..r]$ 满足

$$\text{prefix}[r] = \text{prefix}[l-1]\cdot s[l..r],$$

所以 $s[l..r]$ 可消（右边那块是单位元）$\Leftrightarrow$ $\text{prefix}[l-1]$ 和 $\text{prefix}[r]$ **栈内容完全相同**。答案 = 在 $n+1$ 个前缀状态里选两个相同状态的方案数。

### 观察 3：给"栈的内容"发编号，不用哈希

栈可能长到 $n$，不能逐字符比。但所有出现过的栈内容构成一棵树：**弹出最后一个字符 = 走向父亲，压入字符 $c$ = 走向标着 $c$ 的儿子**。于是"同一种栈内容"就是"同一个树节点"，只要把 $(\text{父编号}, c)$ 唯一化就能拿到编号。每个节点最多 26 个儿子，**暴力扫兄弟链表**就够了：每次压栈最多比 26 次 ⇒ 总时间 $O(26n)$，纯确定性，没有哈希冲突。

> 反面教材见易错点 1：**按"栈深"发编号是不够的**，同一深度可以装完全不同的内容。

### 为什么 $n=2\times10^6$ 只能 $O(n)$ / $O(n\log n)$

$2\times10^6$ 的平方是 $4\times10^{12}$，比 1 秒的预算大 **4 个数量级以上**；连 $n=2\times10^5$ 的 $O(n^2)$ 都是 $4\times10^{10}$，也死。剩下能写的只有 $O(n)$（每步 $O(1)$ 或 $O(26)$）和 $O(n\log n)$（排序配对）。内存同样卡人：$O(n^2)$ 的状态表在 $n=2\times10^6$ 时是 $4\times10^{12}$ 字节，**根本开不下**。

### 复杂度与实测

正解时间 $O(26n)$、空间 $O(n)$：5 个 `int` 数组 + 1 个 `char` 数组（都长 $n+2$）按 `sizeof` 算是 $21n$ 字节，$n=2\times10^6$ 时约 **42 MB**，再加 2 MB 的字符串（**这是算出来的，本机没有实测峰值 RSS**）。实测跑表：

| 构造方式 | $n=800$ | $n=8000$ | $n=2\times10^5$ | $n=2\times10^6$ | $n=2\times10^6$ 的输出 |
| --- | --- | --- | --- | --- | --- |
| 26 字母独立随机（性质 A 型） | 4 ms | 5 ms | 7 ms | 25 ms | `82779` |
| 只有 a、b（性质 B 型） | 6 ms | 5 ms | 7 ms | 29 ms | `1059213312` |
| 全同字符 `aaaa…` | 5 ms | 4 ms | 6 ms | 23 ms | `1000000000000` |
| `aabb` 循环 | 5 ms | 4 ms | — | 24 ms | `750000000000` |
| `abab` 交替（栈最长、树退化成链） | — | 4 ms | — | 26 ms | `0` |

全部远低于 1000 ms。答案上限 $C(2\times10^6+1,2)\approx2\times10^{12}$，**必须 `long long`**。

## 三、讲解代码

### 正解（`solution.cpp`）的核心两行

```cpp
if (top >= 1 && stk[top] == c) {
    --top;                              // 和栈顶相同：两个一起消掉，退回上一层
} else {
    stk[++top] = c;
    int u = idAt[top - 1];              // 父节点编号（这一层之前那个内容的编号）
    int v = 0;
    for (int e = firstChild[u]; e; e = nextSib[e])      // 兄弟最多 26 个，暴力找
        if (edgeChar[e] == c) { v = e; break; }
    if (v == 0) {                       // (父编号, 字符) 第一次出现才发新编号
        v = ++nodes; edgeChar[v] = c; nextSib[v] = firstChild[u]; firstChild[u] = v;
    }
    idAt[top] = v;
}
int st = idAt[top];
ans += seen[st];                        // 前面有几个前缀和当前栈一样，就有几个可消子串
++seen[st];
```

弹栈之后 `idAt[1..top]` 一个都不用改——它们本来就是同一条栈的前缀，这正是"树"结构的便宜之处。

### 部分分版（`solution_partial.cpp`）的区间 DP

```cpp
for (int l = n; l >= 1; --l)                       // 行从下往上：被引用的行都更短
    for (int k = l + 1; k <= n; ++k) {
        if (s[k - 1] != s[l - 1]) continue;         // 配不了对
        if (k > l + 1 && !row[l + 1][k - 1]) continue;   // 中间消不空
        row[l][k] = 1;                              // [l..k] 自己可消空
        for (int r = k + 2; r <= n; r += 2)         // 后面再接一段可消空的
            if (row[k + 1][r]) row[l][r] = 1;
    }
```

`main` 里 $n\le10$ 走 DFS 暴力、其余走这段 DP。**注意**：这个 DP 的档次（$O(n^3)$ / $O(n^2)$ 内存）比它的"分数定位"高，实际保分时更推荐第一节的 $O(n^2)$ 逐左端点版。

## 四、易错点（每条都编译了错误版实跑）

以下全部是**同一份官方样例**（`8 / accabccb`，正确答案 `5`）上的实际输出。

1. **按"栈深"发编号，而不是按"(父编号, 字符)"** —— 上一版 `solution.cpp` 就栽在这儿，样例输出 `10`。最短反例是 `aab`：错误版输出 `2`，正确 `1`（它把深度 1 的 `a` 和深度 1 的 `b` 当成了同一个状态）。穷举 23490 组小数据里这份错误版有 **12798 组不一致**。
2. **忘记空前缀 $s[1..0]$ 也是状态**（`seen[EMPTY] = 1` 少掉）：样例输出 `3`。丢掉的是"从第 1 位开始的可消前缀"，本例正是 `acca` 和整串。
3. **配对计数写成"先自增再累加"**：样例输出 `13`。`ans += seen[st]; ++seen[st];` 的顺序不能换，换每个前缀就把自己也配进去了。
4. **`canElim` 的奇偶剪枝写反**（把奇数长度当成可消）：样例输出 `25`。反过来说：判可消时"长度必须为偶数"是最便宜、也最容易漏的一条筛子。
5. **区间 DP 忘记"后面再接一段可消空的"**（只标 $[l..k]$）：样例输出 `4`——漏掉的正是 `accabccb` 这种"能拆成两截"的串。演示时要把 `main` 里 $n\le10$ 走暴力的分支关掉，否则样例走不到 DP。
6. **答案用 `int`**：样例输出 `5`，**看不出问题**；但 $n=2\times10^5$ 全同字符上它输出 `1410065408`（真值 `10000000000`），$n=2\times10^6$ 上输出 `-727379968`（真值 `1000000000000`）。同一条代码在 $n=2\times10^6$ 的 a、b 随机串上又"碰巧对"（`1059213312` < $2^{31}$）——**样例过不代表类型过**，手册 T3 说的就是这种事。

## 五、常见变式

| 变式 | 差异 | 备注 |
| --- | --- | --- |
| 每次可删**任意个**相邻相同字符 | 栈约简失效，正解档次改变 | 先想清楚"最简串"还唯不唯一 |
| 求**最长**可消子串 | 同一套前缀状态，改成记录每个状态**首次出现的位置** | 思路一行改动（本机未实测代码） |
| 只能删"配成对的两个不同字符"（如 `ab`） | 观察 1 的合流性不再成立 | 只能回到区间 DP，档次掉到 $n\le800$ 量级 |
| 多次询问 / 在线加字符 | 状态树可以复用，查询变成"这个节点出现过几次" | 与本题同一套"前缀状态 + 树编号"思路 |

## 六、一句话提炼

**"能消空"只看一件事：把串用栈约简到底是不是空；而子串约简为空，又等价于它两端前缀约简出来的栈一模一样** —— 于是"数子串"变成"数相同前缀状态的对数"，剩下的全部难度只是"怎么给一棵栈内容树发编号"（按 $(\text{父编号},\text{字符})$ 发号，别按深度发号）。
