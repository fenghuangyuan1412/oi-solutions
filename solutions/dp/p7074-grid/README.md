## 题目大意（数字逐字）

$n \times m$ 的方格图，每格一个整数。从**左上角**走到**右下角**，每步只能**向上、向下或向右**走一格，**不能重复经过已经走过的方格**，不能走出边界。取走所有经过方格中的整数，求整数之和的**最大值**。

数据范围与提示（逐字）：

- 对于 $20\%$ 的数据，$n, m \le 5$。
- 对于 $40\%$ 的数据，$n, m \le 50$。
- 对于 $70\%$ 的数据，$n, m \le 300$。
- 对于 $100\%$ 的数据，$1 \le n,m \le 10^3$。方格中整数的绝对值不超过 $10^4$。
- 题面另注：`2024/2/4 添加一组 hack 数据。`

## 思路推导

### 1. 暴力想法：DFS（`solution_dfs.cpp`）

按题面直译：从 $(1,1)$ 出发，每步试"右 / 上 / 下"三格，没走过、没越界就走过去，标记、递归、回溯。到 $(n,m)$ 就用当前和更新答案。

**注意一处实现细节**：走到 $(n,m)$ 就 `return`，不再往外扩展。题面只要求"从左上角走到右下角"，路径一旦到达右下角就结束了 —— 如果继续从右下角往外走再回来又算不出合法解（右下角不能重复经过），所以直接结算是对的。

### 2. 关键观察：每一列里路径**只沿一个方向**走

这是本题唯一的"聪明点"，也是三级阶梯共同的地基：

> 路径进入某一列后，只能"从某一行开始，一直向上 **或** 一直向下"走到某一行，然后向右离开这一列。

为什么？假设在本列里先向上再向下，中间必然存在一个"折返点"，向下走时会重新踩到向上时经过的格子 —— 违反"不能重复经过"。左右方向根本不存在（不能向左）。所以一列内的轨迹必是一段**连续、单向**的竖线。

于是整条路径可以被每列的"进列行号 $k$ → 出列行号 $i$"完全描述。

### 3. 中间档：$O(n^2m)$ DP（`solution_mid.cpp`）

$$f[i][j] = \text{走到 }(i,j)\text{、马上向右离开本列的最大分数}$$

转移枚举"上一列停在第 $k$ 行"，本列从 $k$ 直走到 $i$，拿到的格子是区间 $[\min(i,k),\ \max(i,k)]$：

$$f[i][j] = \max_{1\le k\le n}\Big(f[k][j-1] + \underbrace{(\text{pre}[\max(i,k)] - \text{pre}[\min(i,k)-1])}_{\text{本列这一段所有格子之和，前缀和 } O(1)}\Big)$$

第 1 列特殊：只能从 $(1,1)$ 一路向下，$f[i][1] = \sum_{t=1}^{i} a[t][1]$。

三重循环 $n\times m\times n$。

### 4. 满分档：把"枚举 $k$"拆成前缀/后缀最大值（`solution.cpp`）

`solution_mid.cpp` 里 $k$ 与 $i$ 的大小关系要分情况（区间端点取 $\min/\max$），这恰好对应"本列向下走"和"本列向上走"两种情形 —— 于是把状态拆成两个方向：

- $f[i][j][0]$：到达 $(i,j)$，本列这一段是**从上往下**走过来的；
- $f[i][j][1]$：到达 $(i,j)$，本列这一段是**从下往上**走过来的。

记本列前缀和 $\text{pre}[i] = \sum_{t\le i} a[t][j]$，上一列第 $k$ 行的最优 $best[k] = \max(f[k][j-1][0],\, f[k][j-1][1])$。

**向下**：进列点 $k \le i$，段和 $= \text{pre}[i] - \text{pre}[k-1]$

$$f[i][j][0] = \max\Big(\underbrace{f[i-1][j][0] + a[i][j]}_{\text{本列继续往下}},\ \ \text{pre}[i] + \max_{k\le i}\big(best[k] - \text{pre}[k-1]\big)\Big)$$

**向上**：进列点 $k \ge i$，段和 $= \text{pre}[k] - \text{pre}[i-1]$

$$f[i][j][1] = \max\Big(\underbrace{f[i+1][j][1] + a[i][j]}_{\text{本列继续往上}},\ -\text{pre}[i-1] + \max_{k\ge i}\big(best[k] + \text{pre}[k]\big)\Big)$$

内层的 $\max_{k\le i}(\cdot)$ 在 $i$ 从 $1$ 到 $n$ 扫的时候顺手维护；$\max_{k\ge i}(\cdot)$ 在 $i$ 从 $n$ 到 $1$ 扫的时候维护。每列两趟扫描 ⇒ 总 $O(nm)$。

### 5. 正确性说明

- **不重不漏**：任一合法路径由观察 §2 分解为"每列一段单向竖线"，其第 $j$ 列的（进列行号、出列行号、方向）恰好对应 $f$ 的一次转移；反过来，$f$ 的每次转移拼起来的也是合法路径（各列内单调、跨列只向右，不可能重踩）。
- **无后效性**：$f[\cdot][j]$ 只依赖 $f[\cdot][j-1]$ 与本列已扫过的一侧，按列从左到右、列内按方向扫描即可。
- **答案取 $\max(f[n][m][0], f[n][m][1])$**：终点固定在右下角，两个方向都要考虑。

### 6. 复杂度

| 版本 | 时间 | 空间 |
| --- | --- | --- |
| DFS | 指数级（实测 $8\times8$ 已到 138 ms） | $O(nm)$ |
| 中间档 | $O(n^2m)$ | $O(nm)$ |
| 满分档 | $O(nm)$ | $O(nm)$（可滚动成 $O(n)$） |

## 板书演示：样例 1（$n=3,m=4$）

```
  列1   列2   列3   列4
 行1 [ 1] [-1] [ 3] [ 2]
 行2 [ 2] [-1] [ 4] [-1]
 行3 [-2] [ 2] [-3] [-1]
```

最优路线是 DFS 穷举抓出来的（不是手推的），逐格值如下，正好长成"每列单向"的样子：

| 步骤 | 位置 | 格子值 | 累计 | 本列内的动作 |
| --- | --- | --- | --- | --- |
| 1 | $(1,1)$ | $+1$ | $1$ | 第 1 列起点 |
| 2 | $(2,1)$ | $+2$ | $3$ | 第 1 列**向下**走 1 格，然后向右离开 |
| 3 | $(2,2)$ | $-1$ | $2$ | 第 2 列进列即出（行号不变，等于"段长 1"） |
| 4 | $(2,3)$ | $+4$ | $6$ | 第 3 列从行 2 进入 |
| 5 | $(1,3)$ | $+3$ | $9$ | 第 3 列**向上**走到行 1 —— 单向，不能再折回来 |
| 6 | $(1,4)$ | $+2$ | $11$ | 第 4 列从行 1 进入 |
| 7 | $(2,4)$ | $-1$ | $10$ | 第 4 列**向下** |
| 8 | $(3,4)$ | $-1$ | $9$ | 抵达终点 $(3,4)$ |

$1+2-1+4+3+2-1-1 = 9$ ✅。两处值得在黑板上圈出来：

- 第 5 步累计已经是 $9$，但**不能停**：终点在 $(3,4)$，最后还要吃两个 $-1$。"沿途最优点"和"终点最优"不是一回事，路径的最后一列必须付过路费。
- 第 3 步只踩了 $(2,2)$ 一格就向右 —— 说明"进列行号 $= $ 出列行号"是允许的（段长 1），DP 里不能把这种情况漏掉。

样例 2（全是负数）的最优路线：

```
(1,1)-1 → (1,2)-1 → (1,3)-3 → (1,4)-2 → (2,4)-1 → (2,5)-2   = -10
```

对照组："沿第 1 行一路向右再向下"要踩上 $(1,5) = -7$，总和 $-16$；提前在第 4 列向下绕开它，就好 $6$ 分。**有负数时"绕路"是有收益的** —— 这也解释了为什么 $f$ 的初值必须是 $-\infty$ 而不是 $0$（实测把初值写成 $0$，样例 2 输出 $7$，见易错点第 2 条）。

**教学提示**：这两条路径都是现场把 `solution_dfs.cpp` 加两行打印抓出来的（穷举法绝不会漏、也不会算错）。板书不要硬编路径 —— 我在本题上手推错了一次，靠对拍才发现（见易错点第 1 条）。

## 讲解代码

三个版本都在本目录：`solution_dfs.cpp`（20 分)→`solution_mid.cpp`（70 分）→`solution.cpp`（满分）。满分档的核心 18 行：

```cpp
for (int j = 2; j <= m; j++) {
    for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] + a[i][j];   // pre[0] = 0

    long long best = NEG;                                          // max_{k<=i}( best[k] - pre[k-1] )
    for (int i = 1; i <= n; i++) {                                 // 从上往下扫：算 f[i][j][0]
        long long up = max(f[i][j - 1][0], f[i][j - 1][1]);
        if (up > NEG / 2) best = max(best, up - pre[i - 1]);
        long long v = best + pre[i];
        if (i > 1 && f[i - 1][j][0] > NEG / 2) v = max(v, f[i - 1][j][0] + a[i][j]);
        f[i][j][0] = v;
    }

    best = NEG;                                                    // max_{k>=i}( best[k] + pre[k] )
    for (int i = n; i >= 1; i--) {                                 // 从下往上扫：算 f[i][j][1]
        long long up = max(f[i][j - 1][0], f[i][j - 1][1]);
        if (up > NEG / 2) best = max(best, up + pre[i]);
        long long v = best - pre[i - 1];                           // 是 pre[i-1]，不是 pre[i]
        if (i < n && f[i + 1][j][1] > NEG / 2) v = max(v, f[i + 1][j][1] + a[i][j]);
        f[i][j][1] = v;
    }
}
cout << max(f[n][m][0], f[n][m][1]) << '\n';
```

## 易错点与坑

1. **`pre[i]` 还是 `pre[i-1]`（本题我真实踩过的坑）**
   向上那一段的区间是 $[i, k]$，段和 $= \text{pre}[k] - \text{pre}[i-1]$，所以转移里减的是 `pre[i-1]`。当时写成 `best - pre[i]`，**样例 1 输出 `11`（应为 `9`），样例 2 输出 `-3`（应为 `-10`）**。
   这个错的危险之处在于：漏掉的恰好是当前格 $a[i][j]$，而样例里它是负数 ⇒ **答案反而偏大**。凡是"偏大"的 bug，用"看数值有没有变小"的直觉都抓不到，只能靠对拍。课堂上可以把这一行当堂改坏重编，让学生看输出从 `9 / -10` 变成 `11 / -3` —— 比讲十遍"注意下标"都管用。
2. **初值写成 `0`** —— 方格数可为负（样例 2 全是负数），$f$ 必须初始化成 $-\infty$。实测把 `const long long NEG = -(1LL << 50);` 改成 `= 0` 再编一遍：**样例 1 仍然输出 9（碰巧对）**，样例 2 输出 `7`（应为 `-10`）。0 初值等于"允许凭空白拿一格"，正数样例查不出来、负数数据全灭 —— 又是"必须靠负数样例才暴露"的那类坑，所以**造数据一定要造全负的**。
3. **`long long`** —— 绝对值 $\le 10^4$、路径最多 $1000\times1000$ 格，累计可达 $10^{10}$，`int` 必爆。
4. **忘标 / 忘消 `vis`** —— DFS 里 `vis[nr][nc] = true` 后必须在递归返回后 `= false`；漏了回溯，路径条数会被错误地砍掉一大半（小数据上不一定暴露）。
5. **把"不能重复经过"读成"不能往回走"** —— 两者不等价：本题允许向上，只是同列内不能折返。读题时把这两句话分开抄。
6. **第 1 列的特殊性** —— 第 1 列只能从 $(1,1)$ 向下，没有"从左边进来"的选项；写成通用转移会引用 $f[\cdot][0]$ 的垃圾值。

## 常见变式

| 变式 | 差异 | 应对 |
| --- | --- | --- |
| 只能向右/向下（NOIP 经典方格取数） | 无列内竖线结构 | 直接 $O(nm)$ 二维 DP，本题的难点全部消失 |
| 可以向左但不能重复经过 | 结构彻底破坏 | 状态要加"当前列已占用的行集合"，$n\le 5$ 时可状压 |
| 求路径本身 | 需要记录选择 | $f$ 里加 `pre[k]` 或 $\text{argmax}$ 数组，倒着走回去 |
| 网格是环形 | 边界条件变化 | 枚举断边拆环，转化为本题形态 |

## 骗分的正确姿势（本题小结）

这题给了教科书级的阶梯：**DFS 20 分 → $O(n^2m)$ 70 分 → $O(nm)$ 100 分**，而且相邻两档之间只差"一个 $\max$ 能不能提前算好"。考场上如果 40 分钟还没看出列内单向结构，**先交 $O(n^2m)$**：它的代码量小、不易写错，70 分是确定的；剩下的时间再攻满分档。三级都写进仓库，也正好构成一条**自证链**：小数据 DFS 拍 mid、mid 拍 full，任一环节写错就会被自己的另外两版抓到。

## 小结

数据范围不是装饰：$n,m\le5$ 是在说"可以 DFS"，$\le300$ 是在说"三重心循环可以"，$\le1000$ 是在说"必须把最内层 $\max$ 提成前缀量"。把分档表当作提示来读，骗分就变成了有计划的加分。
