# P3622 动物园 · 本机验证记录

全部数字为本机实测（Windows 10 / Git Bash / g++ `-static -O2 -std=c++14`，2026-10-03）。
exe 与临时大数据不进仓库；对拍脚本 [`stress.js`](stress.js)、暴力 [`brute.cpp`](brute.cpp) 仅用于验证，非讲解代码。

## 1. 官方样例

```bash
$ ./sol.exe < sample1.txt    # N=14, C=5
5
$ ./sol.exe < sample2.txt    # N=12, C=7
6
```

两样例与洛谷页面官方输出一致（`5`、`6`），verify/brute.cpp 输出相同。

## 2. 随机对拍（sol vs 2^N 子集枚举暴力）

| 轮次 | 参数（组数 / 最大N / 最大C） | 结果 |
| --- | --- | --- |
| 1 | 1200 / 12 / 8 | 不一致 0 组 |
| 2 | 200 / 14 / 20 | 不一致 0 组 |

生成器特征（stress.js 内置）：n ∈ [10, maxN]；每个小朋友 E 随机、F/L 随机但 **F+L ≤ 5 且都在 5 连窗口内、两两不同**（题面硬约束；第一版生成器允许 F+L=6，喂出非法数据把两份代码一起带偏，修正后重跑）；掺入 F=L=0（永不开心）与同起点多小朋友的形状。累计 **1400 组，0 不一致**。

## 3. 满约束性能（n=10000, c=50000）

```bash
$ time ./sol.exe < big.txt    # 输出 44847
real 0m0.163s
```

洛谷时限 1.00 s / 内存 125 MB，余量一个数量级；空间 1.3 MB 静态区。
