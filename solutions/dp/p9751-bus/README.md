## 题目大意

$n$ 个点 $m$ 条**有向边**的地图，1 号是入口、$n$ 号是出口。每过 $k$ 单位时间有一辆车到入口、同时有一辆车从出口开走；走每条边**恰好 1 单位时间**；边 $i$ 只有**不早于 $a_i$ 时刻**才能通过。小 Z 到达和离开的时刻都必须是 $k$ 的倍数，且**中途不许在任何点或边上停留**。求最早离开时刻，无解输出 `-1`。

把"一条路 + 一个出发时刻 $S$"写清楚：设路有 $L$ 条边 $e_1 \dots e_L$，第 $j$ 条边在 $S+j-1$ 时刻通过，则

$$S \equiv 0 \pmod k,\qquad S + L \equiv 0 \pmod k,\qquad S + j - 1 \ge a_{e_j}\ \text{对所有 } j.$$

样例（`5 5 3`，边 `1→2(0) 2→5(1) 1→3(0) 3→4(3) 4→5(1)`）手算：

| 方案 | 走法 | 各边通过时刻 | 合法吗 |
| --- | --- | --- | --- |
| 0 时刻上车 | 1→2→5 | 0, 1（都 ≥ a） | 2 时刻到了 5 号出口，但 **2 不是 3 的倍数**，没有车，下不了 |
| 3 时刻上车 | 1→3→4→5 | 3, 4, 5 | 3→4 在 4 ≥ 3 ✓，到达时刻 **6** ✓ |

⇒ 输出 `6`。注意答案靠的是**第二班车**：0 时刻那班车根本回不来。

## 一、骗分：这一档怎么拿

problem.txt 的数据范围表（逐字，20 个测试点，总分 100，**未给每点分值**，下面按测试点编号计档）：

| **测试点编号** | $n \leq$ | $m \leq$ | $k \leq$ | **特殊性质** |
|:-:|:-:|:-:|:-:|:-:|
| $1 \sim 2$ | $10$ |$15$ | $100$ | $a _ i = 0$ |
| $3 \sim 5$ | ^ | ^ | ^ | 无 |
| $6 \sim 7$ | $10 ^ 4$ | $2 \times 10 ^ 4$ | $1$ | $a _ i = 0$ |
| $8 \sim 10$ | ^ | ^ | ^ | 无 |
| $11 \sim 13$ | ^ | ^ | $100$ | $a _ i = 0$ |
| $14 \sim 15$ | ^ | ^ | ^ | $u _ i \leq v _ i$ |
| $16 \sim 20$ | ^ | ^ | ^ | 无 |

### 档 1：a_i = 0（测试点 1~2、6~7、11~13，共 7 个点）—— 分层 BFS

所有开放时间消失后，问题只剩"**走多长**"：任何从 1 出发、长度是 $k$ 的倍数的走路（walk，允许重复点/边）都合法，求最短路程。

状态 $(v, r)$：走到点 $v$ 时已走步数 $\bmod\ k = r$。从 $(1,0)$ 出发 BFS，答案 $= dist[n][0]$，走不到 $-1$。复杂度 $O(k(n+m))$。

本机实测：自造 $n=10^4, m=2\times10^4, k=100$ 的全 0 数据，**153 ms**（含进程启动）出答案。

### 档 2：n ≤ 10（测试点 3~5）—— 按时间逐秒模拟（精确，慢）

$R_t$ = "$t$ 时刻人**可能**站在哪些点"（对所有可能的上车时刻取并集）：

$$R_t = \{1\ (\text{若 } k \mid t)\} \cup \{v : \exists\, u{\to}v \in E,\ u \in R_{t-1},\ t-1 \ge a_{u\to v}\}$$

答案 = 最小的 $t \equiv 0 \pmod k$ 使 $n \in R_t$。模拟到 $U = \max a + (n+1)k + 5$ 还没有 ⇒ `-1`（上界见第二节引理）。

本机实测：自造最坏小数据（$n=10$，链长 9 + 自环，全部 $a=10^6$，$k=100$，答案 1000100）**85 ms**（含启动）。

### 档 3：k = 1 且 a_i = 0（测试点 6~7）—— 档 1 的顺带收获

分层 BFS 在 $k=1$ 时退化成普通 BFS，一行都不用多写。**这就是"按特殊性质分档、代码只写一份"的甜头**（手册 T4）。

### 拿不到的档，以及为什么拿不到

- **测试点 8~10（k=1，a 任意）**：档 2 的模拟在这里 $U \approx 10^6$、$m = 2\times 10^4$，最坏 $O(Um) = 2\times 10^{10}$。本机自造满规模通用数据（$n=10^4, m=2\times10^4, k=100, a\le10^6$）实测 **5599 ms**（答案 1008600，能算对但远超 1 s）——**暴力是精确的，死在运行时间上**。
- **测试点 14~15（$u_i \le v_i$）**：DAG 上"最早上到 $(v,r)$ 支配一切"看似成立，其实要处理自环与"推迟上车"两层账，另写一套拓扑 DP 只为 2 个点，不划算，**本目录不实现**。
- 兜底红线（手册）：本目录的 `solution_partial.cpp` 在任何输入上要么在时限内给出**精确**答案，要么超时——它不会输出一个"看起来合法的错答案"，这比"近似算法蒙混"更符合骗分伦理。

## 二、正解（只讲思路，不实现）

### 关键观察 1：把"时刻"换成"路 + 上车时刻"

如第一节公式：方案 = 走路 $e_1..e_L$ + 上车时刻 $S$，约束 $S \equiv 0$、$L \equiv 0 \pmod k$、$S \ge a_{e_j} - j + 1$。目标 $D = S + L$。

### 关键观察 2（界引理）：若解存在，最早离开时刻 ≤ max a + (n+1)k

**去环论证**：把路上各时刻的状态写成 $(v_i,\ (S+i) \bmod k)$，一共 $L+1$ 个。若某状态重复（第 $i$ 步与第 $j$ 步同点同余数），删掉中间那段环（环长是 $k$ 的倍数），并把上车时刻**推迟** $j-i$：之后每条边的**绝对通过时刻不变**、之前边的时刻只会更晚，全部约束仍满足，而 $D = S+L$ 不变。反复去环后 $L \le nk-1$，且 $S$ 可取"满足约束的最小 $k$ 倍数" $\le \max a + k$。

这条引理就是档 2 暴力的正确性来源，也是官方解法的复杂度地基。

### 正解难在哪（以及本目录为什么不实现）

官方解法是在 $(v,\ r \bmod k)$ 的分层图上做 DP。**陷阱**：不许停留 ⇒ "同一余数类里到达得早"并**不**支配"到达得晚"——晚到 $k$ 个单位反而可能踩开更多没开放的边（样例 1 靠第二班车，正是这个现象）。所以每个状态要存的是"这条路所需的最早上车时刻 + 路长"这一对量，转移时要比较两个目标函数的组合，正确性论证依赖上面的去环引理，细节多、极易写错。**本机没有评测环境可以验证自创的完整版**，与其"假装实现"一个没验证过的 DP，不如把已验证精确的两档写扎实——这与 [P9755 种树](../../greedy/p9755-tree/README.md) 目录的处理方式一致。

$k=3$，边 `1→2(0) 2→5(1) 1→3(0) 3→4(3) 4→5(1)`：

| t | $R_t$（可能站的点） | 说明 |
| --- | --- | --- |
| 0 | {1} | 第一班车到入口 |
| 1 | {2, 3} | 0 时刻踩 1→2、1→3（a=0 ✓） |
| 2 | {5} | 1 时刻踩 2→5（1≥1 ✓）；3→4 要 1≥3 ✗。**5∈R 但 2 不是 3 的倍数，下不了车** |
| 3 | {1} | 第二班车到 ⇒ 从 1 重新可出发；{5} 没出路 |
| 4 | {2, 3} | 3 时刻踩 1→2、1→3 |
| 5 | {4, 5} | 4 时刻踩 3→4（4≥3 ✓）、2→5（4≥1 ✓）；但 5 不是 3 的倍数 |
| 6 | {1, 5} | 5 时刻踩 4→5（5≥1 ✓），同时第三班车到、1 重新可站 ⇒ **6 是 3 的倍数且 5∈R_6，下车！答案 6** ✓ |

## 四、讲解代码（`solution_partial.cpp` 关键片段）

```cpp
// 档 1：a_i 全 0 —— 分层 BFS
vector<vector<int>> dist(n + 1, vector<int>(k, -1));
dist[1][0] = 0; q.push({1, 0});
while (!q.empty()) {
    int u = q.front().first, r = q.front().second; q.pop();   // C++14：不用结构化绑定
    for (const Edge &e : out[u]) {
        int nr = (r + 1) % k;                       // 走一条边，步数 +1
        if (dist[e.v][nr] == -1) { dist[e.v][nr] = dist[u][r] + 1; q.push({e.v, nr}); }
    }
}
printf("%d\n", dist[n][0]);                          // -1 表示走不到

// 档 2：通用暴力 —— 逐时刻可达集
long long U = (long long)maxa + (long long)(n + 1) * k + 5;   // 界引理
for (long long t = 1; t <= U; ++t) {
    if (t % k == 0) mark(1);                         // 每 k 单位一辆新车：入口重新可达
    for (int u : act)                                // act = R_{t-1}
        for (auto &e : out[u])
            if (t - 1 >= (long long)e.a) mark(e.v);  // 在第 t-1 时刻踩这条边
    if (t % k == 0 && cur[n]) { printf("%lld\n", t); return 0; }
}
```

## 五、易错点与坑（每条都是故意写错的版本跑官方样例的**实际输出**）

1. **忘了"不许停留"**：允许等到边开放（`t = max(dist[u], a) + 1`），最后把到达时刻向上取整到 $k$ 的倍数 ⇒ 实测输出 `3`（正确 6）。它"造"出了 2 时刻到 5、在出口等到 3 再上车的假方案——题面逐字："只想一直沿着景区道路移动，而不想在任何地点（包括景区入口和出口）或者道路上停留"。
2. **忘了离开时刻必须是 k 的倍数**：模拟全对，但 $n$ 第一次可达就输出 ⇒ 实测输出 `2`（正确 6）。
3. **忘了"每 k 单位时间一辆车"**：只允许 0 时刻出发一次 ⇒ 实测输出 `-1`（正确 6）。样例 1 的答案恰恰靠**第二班车**，这一条最隐蔽。
4. **界引理偷懒：把 $(n+1)k$ 写成 $n$**（模拟上限 $U$ 取小）：官方样例上它照样输出 `6`（样例抓不住这个 bug！），但在自造数据 `2 2 100 / 1 2 0 / 2 2 0`（1→2 后在 2 号自环凑长度，正确答案 100）上，实测输出 `-1`，而正确版输出 `100`。上界必须含 $n \cdot k$ 项——去环后路长可到 $nk-1$，自环就是活例子。

## 六、常见变式

| 变式 | 差异 | 备注 |
| --- | --- | --- |
| 允许在点停留等待 | 直接 Dijkstra `max(t,a)+1` | 坑 1 的"错误版"反而是这题的正解 |
| 边有权重（通过耗时 >1） | 模拟步数变多，分层 BFS 失效 | 需要按时间展开 |
| 求方案数 | 可达集换成计数 DP，模数另说 | 同框架 |
| k 很大（>1000） | 分层状态 $O(nk)$ 爆炸 | 正解也要另想办法 |

## 七、一句话提炼

**"不许停留"让'越早到越好'失效，但'每 k 一辆车'给了无穷多次重新出发**——把状态从"点"升维成"点 + 步数 mod k"，再用去环引理把时间轴压出上界，暴力的正确性就有了；剩下的纯粹是运行时间，而这正是部分分该逐档去换的东西。
