P1499 [CTSC2000] 公路巡逻

一条没有分岔的高速公路上有 n 个关口，相邻两个关口之间距离 10 km。所有车辆的最低速度 60 km/h、
最高速度 120 km/h，并且只能在关口处改变速度。

巡逻方式：在某个时刻 T_i 从第 n_i 个关口派出一辆巡逻车匀速驶抵第 n_i + 1 个关口，路上耗时 t_i 秒。

两辆车相遇是指：它们之间发生超车，或者两车同时到达某关口（同时出发不算相遇）。

求一辆 6 点整从第 1 个关口出发去第 n 个关口的车（目标车）最少会与多少辆巡逻车相遇；并输出相遇次数
最少时最早到达第 n 个关口的时刻。假设所有车辆到达关口的时刻都是整秒。

输入格式：
  第一行两个整数 n（关口数）和 m（巡逻车数）。
  接下来 m 行，每行三个数 n_i, T_i, t_i（按出发位置 n_i 递增排序给出），
  其中 T_i 形如 HHMMSS（24 小时制，前置 0 补齐）。

输出格式：
  第一行一个整数，表示最少相遇的巡逻车数。
  第二行一个 HHMMSS 格式的时刻，表示相遇次数最少时最早到达第 n 个关口的时刻（格式同输入，补前导 0）。

数据范围：
  1 < n < 50，1 < m < 300，1 <= n_i < n，300 <= t_i <= 600，
  所有 T_i 不早于 05:00、不晚于 23:00。

样例输入：
3 2
1 060000 301
2 060300 600

样例输出：
0
061301
