P2058 [NOIP 2016 普及组] 海港
https://www.luogu.com.cn/problem/P2058

【题目描述】
记录 n 艘船：第 i 艘到达时间 t_i（秒）、乘客数 k_i、每名乘客国籍 x_{i,1..k_i}。
对每艘船 i，统计满足 t_i-86400 < t_p <= t_i（p <= i）的所有船只上的乘客来自多少个不同的国家。

【输入格式】
第一行一个整数 n。
接下来 n 行，每行先是两个整数 t_i、k_i，然后跟 k_i 个整数 x_{i,j}。
保证 t_i 递增。

【输出格式】
输出 n 行，第 i 行为第 i 艘船到达后的统计值。

【输入输出样例 #1】
输入 #1
3
1 4 4 1 2 2
2 2 2 3
10 1 3

输出 #1
3
4
4

【输入输出样例 #2】
输入 #2
4
1 4 1 2 2 3
3 2 2 3
86401 2 3 4
86402 1 5

输出 #2
3
3
3
4

【数据范围】
1 <= n <= 10^5，sum k_i <= 3*10^5，1 <= x_{i,j} <= 10^5，1 <= t_i <= 10^9，t_i 递增。
