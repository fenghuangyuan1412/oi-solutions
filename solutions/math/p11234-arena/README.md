## 题目大意

$2^k$ 人的单败淘汰赛。题面逐字（见 problem.txt）：

> 对于每场比赛，会先抽签决定一个数 0/1。……抽到 0 则表示编号小的选手为擂主，抽到 1 则表示编号大的选手为擂主。**擂主获胜当且仅当他的能力值 $a\geq R$**。也就是说，游戏的胜负只取决于**擂主的能力值**与**当前比赛是第几轮**的大小关系，**与另一位的能力值无关**。

> 补充**尽量少**的选手使总人数为 $2$ 的整次幂，且所有选手进行一次完整的擂台游戏后，所有**可能成为总冠军**的选手的**编号之和**是多少。……**如果补充的选手有可能取胜，也应当计入答案中**。

对每个询问 $c_i$：只看前 $c_i$ 人的能力值，补人补到 $2^k\ (2^k\ge c_i)$，补充的人能力值**任取**，把所有"存在某种补人方案能夺冠"的选手编号求和得 $A_i$。每组测试数据输出 $(1\times A_1)\oplus(2\times A_2)\oplus\dots\oplus(m\times A_m)$，共 $T$ 组。

**样例 1 手算**（照 problem.txt 样例解释）：第一组数据真实能力值 $[1,0,0,2,1]$。以 $c=3$ 为例：补 1 人（4 号）。第 1 场 $d_{1,1}=1$，擂主是 2 号，$a_2=0<1$，1 号赢；第 2 场 $d_{1,2}=0$，擂主 3 号，$a_3=0<1$，4 号赢；决赛 $d_{2,1}=1$ 擂主是 4 号——4 号是补充选手，能力值任取：$a_4<2$ 则 1 号夺冠，$a_4\ge 2$ 则 4 号夺冠，所以答案为 $1+4=5$。五问依次为 $A=[19,4,1,1,5]$，
$(1\times19)\oplus(2\times4)\oplus(3\times1)\oplus(4\times1)\oplus(5\times5)=5$。
样例 2~5 的文件题面写明"见选手目录下的 arena/arenaN.in"，**不在 problem.txt 里，本地只能验证样例 1**。

## 一、骗分：这一档怎么拿

### 先做一件把题面"打折"的事：能力值分桶

全题 $2^{31}$ 种能力值，但能力值**只有一个用途**：和轮数 $R\le K\le 17$ 比大小（`a >= R`）。
所以 $a$ 可以压成 $K+1$ 个桶：`bucket = min(a, K)`——$0,1,\dots,K{-}1$ 各一桶，$\ge K$ 归并成一桶。
**分桶之后，"补充选手能力值任取"就从"无穷种方案"变成"$K+1$ 种方案"**，"谁能夺冠"就可以被精确 DP 了。这一步是本题骗分的全部地基，也是正解大概率绕不开的第一步。

有了桶，对每个**不同的**询问 $c$ 单独跑一遍"逐轮合并可能胜者集合"的 DP（讲解代码一节）：
每场对局把左半、右半的可能胜者集合按擂主够不够格（桶 $\ge R$ / 桶 $< R$）合并上来。**这是精确算法，不是近似**。

## 二、正解思路（本目录不实现）

剩下的 56 分（13~15、16~25）要求把"每个不同询问重跑一遍 $O(2^k\cdot k)$ 的 DP"变成**跨询问共享**：所有询问的赛制都是那棵固定 $2^K$ 满二叉树的"前缀 + 补齐"形态，原则上可以把每个节点的信息做成一种**可合并、可对"轮数平移"的摘要**（比如"该节点内每个选手赢下本子树所需的最低能力桶"这种函数式表示），每次询问只沿 $O(K)$ 个被 $c$ 切开的边界节点拼合。难点有二：其一，同一个子树在不同询问里充当**不同的轮次**（阈值 $R$ 跟着变），合并操作不再是简单的集合运算；其二，$T$ 最高 256 组，每组 $a_i$ 都被 $X$ 重洗，能跨组复用的结构很有限。这就是 difficulty=8 的来源，**超出本批教学范围，本目录不实现**；上面 DP 的正确性只在我自写的枚举暴力覆盖的小数据范围内被验证过。

## 三、讲解代码（`solution_partial.cpp`，关键片段）

```cpp
// 桶：能力值只和轮数比大小，超过 K 的一律记成 K
bkt[i] = (unsigned)min(val[i], (long long)K);

// 一次合并（第 h 轮、本场编号 j）：dd=0 擂主是编号小的一侧（左），dd=1 是右侧
unsigned lowmask = (1u << h) - 1, kepmask = ~lowmask;  // 桶 < h：擂主"不够格"
bool low = false;
for (int u = a0; u < a1; ++u) {                 // a 侧 = 擂主一侧
    unsigned long long e = cur[u];
    unsigned mask = (unsigned)(e >> 32);        // 高 32 位：该选手能赢下本子树的桶集合
    if (mask & lowmask) low = true;             // 擂主存在不够格的取法 => 对面整段晋级
    unsigned keep = mask & kepmask;             // 擂主够格的桶才留下
    if (keep) nxt[pos++] = ((unsigned long long)keep << 32) | (unsigned)(e & 0xffffffffu);
}
if (low) for (int u = b0; u < b1; ++u) nxt[pos++] = cur[u];   // b 侧 = 挑战者一侧
```

```cpp
// 主循环：每组数据重新算 val/bkt/memo（X 变了！），最后按 (i*A_i) 异或
res ^= memo[c] * (long long)i;      // (1*A_1) ⊕ (2*A_2) ⊕ ... ⊕ (m*A_m)
```

叶子初始化是全部学问的另一半：已报名选手 $p\le c$ 只带一个桶 `1u << bkt[p]`；**补充选手 $p>c$ 带满桶 `full = (1<<(K+1))-1`**，因为他的能力值任取。

## 四、易错点（每条都有实测证据：故意写错后跑官方样例 1）

官方样例 1 正确输出（逐字）：

```
5
19
7
1
```

1. **擂主条件是 $a \ge R$，不是 $a > R$**：把 `lowmask = (1u<<h)-1` 写成 `(1u<<(h+1))-1`（等于要求 $a \ge h{+}1$），实测输出 `29 / 29 / 19 / 29`——四行全错。
2. **异或下标是 $i \bmod 4$，$i$ 从 1 起**（题面：$a_i = a'_i \oplus X_{i\bmod 4}$）：写成 `X[(i-1)%4]`，实测输出 `19 / 20 / 26 / 19`——全错，且第一行不再是 5，样例能抓住。
3. **$T$ 组数据每组独立**：`memo` 忘了每组清空（改成 `static` 跨组复用），实测输出 `5 / 5 / 5 / 5`——第 2~4 行全变成第 1 组的结果，而第 1 行还是对的，**只看样例第一行会以为自己过了**。
4. **输出公式是 $(i \times A_i)$ 全体异或**：有人写成"输出最后一问的答案"，实测输出 `5 / 6 / 2 / 1`——第一行 5 纯属巧合（$A_5$ 恰好等于该组答案），后三行当场露馅。
5. **补充选手的桶集合必须含最高桶 $K$**：`full` 少写一位（`(1u<<K)-1`），实测输出 `18 / 19 / 7 / 1`——四行里三行照样对，**只错一组**，是最隐蔽的一类。
6. 抽签串每行是 $2^{K-R}$ 个**无空格**的 0/1，要整行按字符串读；用 `cin >> int` 会把 `1001` 拆成四个数直接读崩（构造上 $d_{1,G}$ 必须 $G$ 对齐取字符，见讲解代码的 `drow[h][j]`）。

## 五、常见变式

| 变式 | 差异 | 备注 |
| --- | --- | --- |
| 只有 $c=n$ 一个询问 | 单次 DP 或单次枚举 | 本题的"读懂规则"热身版 |
| 补充选手**不计入**答案 | 根节点集合里剔掉 $p>c$ 的条目 | 一行改动，练"集合语义" |
| 胜负条件改 $a_{\text{擂主}} \ge$ 对手能力 | 分桶失效，变回真·排序题 | 提醒学生"本题赢在比的是轮数" |
| 求"必然夺冠"的编号和 | 全称量词取代存在量词，DP 状态要取交集 | 与本题对照讲"可能/必然"差别 |

## 六、一句话提炼

**把 $2^{31}$ 种能力值压成 $K+1$ 个桶，"任取"就变成了可枚举；把"谁能夺冠"压成逐轮合并的胜者集合，difficulty=8 的压轴题也能按档把 1~12 号测试点（约 44 分）整整齐齐搬走——骗分的本质不是绕开难题，而是只写"有正确性保证"的那部分。**
