## 题目大意

题面关键原文（逐字，完整版见 `problem.txt`）：

> 一个如下的 $6 \times 6$ 的跳棋棋盘，有六个棋子被放置在棋盘上，使得每行、每列有且只有一个，每条对角线（包括两条主对角线的所有平行线）上至多有一个棋子。
>
> 上面的布局可以用序列 $2\ 4\ 6\ 1\ 3\ 5$ 来描述，第 $i$ 个数字表示在第 $i$ 行的相应位置有一个棋子。
>
> 请编一个程序找出所有棋子放置的解。并把它们以上面的序列方法输出，解按字典顺序排列。请输出前 $3$ 个解。最后一行是解的总个数。

用自己的话复述：$n\times n$ 棋盘放 $n$ 个"皇后"（题面说跳棋棋子，规则就是皇后互不攻击）：**每行每列恰好一个、每条斜线至多一个**。一个解写成 $n$ 个数的序列：第 $i$ 个数 = 第 $i$ 行棋子的列号。要求：① 按字典序输出**前 3 个解**；② 最后一行输出**解的总数**——注意总数要把**所有**解数完，不能找到 3 个就收工。

数据范围（逐字）：$6 \le n \le 13$。

题面给的示例布局 `2 4 6 1 3 5` 本身就该当堂验证一遍（行号 1..6，列号 2,4,6,1,3,5）：行+列 $=3,6,9,5,8,11$ 互不相同，行−列 $=-1,-2,-3,3,2,1$ 互不相同，列互不相同 —— 这就是下面对角线编号的活教材。

## 思路推导

### 1. 暴力想法与"降维阶梯"

直接按题面翻译，搜索空间一路瘦身：

| 写法 | 空间 | $n=6$ | $n=13$ |
| --- | --- | --- | --- |
| ① $n^2$ 个格子里选 $n$ 个（组合） | $\binom{n^2}{n}$ | $\binom{36}{6}=1947792$ | $\binom{169}{13}\approx 4\times10^{17}$，绝望 |
| ② 每行独立选列（可同列，事后检查） | $n^n$ | $46656$ | $13^{13}\approx 3.0\times10^{14}$，绝望 |
| ③ 枚举 $1..n$ 的**全排列**（列天然不重复） | $n!$ | $720$ | $13!=6227020800\approx 6.2\times10^{9}$，还是太多 |
| ④ 按行 DFS + 三条标记数组边放边剪 | 远小于 $n!$ | 瞬间 | **实测 234 ms** ✅ |

③ 就是 `verify.js` 里的参照实现（对拍用，$n\le9$ 才跑得动）；④ 是讲解代码。阶梯的每一步都在问同一个问题：**"每行恰一个、每列恰一个"这两个约束，能不能不检查就自动成立？** —— 能，方式是"按行放 + 列打标记"。

### 2. 关键观察

1. **按行放 ⇒ "每行有且只有一个"免费满足**：搜索树从"选格子"（$n^2$ 岔口 × $n$ 层）降为"选列"（$n$ 岔口 × $n$ 层）。放满 $n$ 行时 $n$ 个子互不同列 ⇒ 每列也恰好一个。
2. **对角线可以编号成一维数组**。画一个 $6\times6$ 格子，标上 $(i,j)$：
   - **副对角线（↗ 方向，右上-左下）**：沿同一条走，一行加一、一列减一 ⇒ $i+j$ **恒定**。$i+j$ 取值 $[1+1,\,n+n]=[2,2n]$，共 $2n-1$ 条，数组开 $2n$ 就够（不用平移，最小是 2 不为负）。
   - **主对角线（↘ 方向，左上-右下）**：沿同一条走，行列同加同减 ⇒ $i-j$ **恒定**。$i-j$ 取值 $[1-n,\,n-1]$，**是负数**！C++ 负下标是未定义行为，所以整体 **加 $n$ 平移**成 $[1,\,2n-1]$，即 `d2[i - j + n]`，数组同样开 $2n$。
   - 两子冲突 $\iff$ 同列，或 $i+j$ 同，或 $i-j$ 同 —— 三个 $O(1)$ 查表就是全部剪枝。
3. **回溯 = 打标记 + 递归 + 撤销标记**。`col[i]` 数组顺手记下每行选择，叶子处直接输出（BFS 想输出"路径"得存前驱，这里天然就有）。
4. **字典序是写出来的，不是排出来的**：行号固定从 1 到 $n$、列号从 $1$ 到 $n$ 从小到大枚举，找到的解序列 $(col[1],col[2],\dots)$ 自动字典序升序 ⇒ "前 3 个解"就是最先命中的 3 个叶子，无需排序。
5. **"输出前 3"≠"找 3 个就停"**：第四行要报解的总数（$n=13$ 有 $73712$ 个），所以搜索必须走完，只是 `total<=3` 时才打印。提前 `return`/退出递归 = 总数错。
6. **与 P1443/P1135 的对照（本题在教学上的真正价值）**：那两题问"**最少**几步" ⇒ BFS 按层、每状态进队一次即可；本题要"**全部**方案（按字典序 + 计数）" ⇒ 必须 DFS 回溯，且标记必须**撤销**后重试同层下一个列。BFS 的"入队即永久打标记"在这里是致命 bug（会漏掉经过同一状态的其他方案）。

### 3. 算法设计

```
dfs(i)：给第 i 行选列 j = 1..n
    j 合法 <=> !usedCol[j] && !d1[i+j] && !d2[i-j+n]
    放子：col[i]=j，三个标记置 true → dfs(i+1) → 三个标记清 false
i > n：total++；total<=3 时打印 col[1..n]
主程序：dfs(1) 后打印 total
```

### 4. 正确性说明

- **不漏**：任一合法解是 $1..n$ 的一个排列 $p$；按行递归会枚举"第 1 行 $p_1$、第 2 行 $p_2$、…"这条路径，且每个前缀都不触发剪枝（前缀合法是整体合法的必要条件），故必达该叶子。
- **不重**：每个叶子对应唯一序列 $(col[1..n])$，不同叶子序列不同 ⇒ 每个解恰好数一次。
- **剪枝安全**：`usedCol/d1/d2` 命中意味着新子与已放某子同列/同斜线，**其任意扩展都非法**，剪掉的整棵子树里不可能有解。
- **字典序**：DFS 访问叶子的顺序 = 序列的字典序（同层按 $j$ 升序，深层优先），与题面要求一致。

### 5. 复杂度

时间由搜索树节点数决定，上界 $O(n\cdot n!)$（排列树），实际三个 $O(1)$ 剪枝大幅砍枝——本机 $n=13$ 全程（含输出）实测 229~235 ms。空间：递归栈 $O(n)$ + `col/usedCol/d1/d2` 共 $O(n)$，微乎其微。

## 板书演示（$n=6$，下表为插桩程序打印的真实进入/回退顺序）

**第一幕：$col_1=1$ 整棵子树全军覆没。** 第一条放到第 5 行的链条（括号内为打的标记）：

| 步骤 | 动作 | 说明 |
| --- | --- | --- |
| 1 | 放 $(1,1)$，d1=2，d2=6 | 第 1 行只能从列 1 试起 |
| 2 | 列 1、2 跳过；放 $(2,3)$，d1=5，d2=5 | 列 1 撞 `usedCol[1]`；$(2,2)$ 撞 d2=6（$2-2+6=6$，同主对角线） |
| 3 | 列 1..4 跳过；放 $(3,5)$，d1=8，d2=4 | $(3,1)$、$(3,3)$ 撞列标记，$(3,2)$ 撞 d1=5，$(3,4)$ 撞 d2=5 |
| 4 | 放 $(4,2)$，d1=6，d2=8；放 $(5,4)$，d1=9，d2=7 | 第 4、5 行都只剩这一个选择 |
| 5 | **第 6 行列 1..6 全部跳过** | 无位可放 ⇒ 回退 $(5,4)$、$(4,2)$、$(3,5)$… |

这条链以 $1\ 3\ 5\ 2\ 4\ \_$ 卡死。此后 DFS 继续翻整棵 $col_1=1$ 子树，**一个解都没找到**（实测日志里 `unplace row=1 col=1` 直接接在 `place row=1 col=2` 之前）——$n=6$ 的 4 个解开头都是 2/3/4/5。

**第二幕：$col_1=2$ 内第一条链也卡死，第二条链出解 #1。**

| 步骤 | 动作 | 标记 |
| --- | --- | --- |
| 1 | 放 $(1,2)$ | d1=3，d2=5 |
| 2 | 列 1 跳过（$2+1=3$ 撞 d1）、列 2 跳过（撞列）、列 3 跳过（$2-3+6=5$ 撞 d2）；放 $(2,4)$ | d1=6，d2=4 |
| 3 | 放 $(3,1)$ | d1=4，d2=8 |
| 4 | 放 $(4,3)$ | d1=7，d2=7 |
| 5 | 放 $(5,5)$；**第 6 行列 1..6 全跳过** ⇒ 卸 $(5,5)$ 后 $(5,6)$ 撞 d2=5；卸 $(4,3)$ 后第 4 行其余候选也全撞，一路回退到第 3 行 | — |
| 6 | 改放 $(3,6)$ | d1=9，d2=3 |
| 7 | 放 $(4,1)$ | d1=5，d2=9 |
| 8 | 放 $(5,3)$ | d1=8，d2=8 |
| 9 | 列 1..4 全撞列标记；放 $(6,5)$ | d1=11，d2=7 |
| 10 | **FOUND #1：`2 4 6 1 3 5`** | 与题面示例序列一致 ✅ |

随后程序继续跑，第二、三个解 `3 6 2 5 1 4`、`4 1 5 2 6 3`（实测输出），第四个 `5 3 1 6 4 2` 只计数不打印，末行输出总数 `4` ✅。

**当堂验证 `2 4 6 1 3 5`**：$i+j=3,6,9,5,8,11$；$i-j=-1,-2,-3,3,2,1$；两组数字全部互不相同，加上列互不相同，三个标记数组恰好抓全三种冲突——这条算式就是"为什么只需三个数组"的证明。

## 可视化讲解

交互动画见同目录 [`visualization.html`](visualization.html)。一帧只做一件事，棋盘 + 三张标记数组表 + 递归栈 + 已找到的解同屏联动，代码面板与 `solution.cpp` 行号对应。四类帧要分开讲：

| 帧类型 | 面板给看什么 | 讲课要点 |
| --- | --- | --- |
| 试 $(i,j)$ **被剪** | 撞的是 `col`、`d1` 还是 `d2` 会写明，并把**冲突的那颗旧棋子**在棋盘上标红 | 一次判断只查三个布尔数组，$O(1)$；不用扫棋盘 |
| 试 $(i,j)$ **合法** | `col[j]`、`d1[i+j]`、`d2[i-j+n]` 三个格子全是 0 | 对角线编号公式在这里落地：同一副对角线 $i+j$ 相同，同一主对角线 $i-j$ 相同，加 $n$ 是为了把负数挪进下标 |
| **落子** | 三格同时置 1，`pos[i]=j`，递归栈多一层 | 做选择 |
| **★ 回溯** | 三格同时清 0，`pos[i]` 清零，栈退一层 | 撤销选择 —— 和 P1443 的"入队即永久标记"正好相反，这是本题最该讲清的一处对比 |

预设三档：`n=4`（2 个解，113 帧，最适合逐帧讲回溯）、`n=6`（官方样例，1357 帧，走完末帧给出前 3 解 + 总数 4，与题面逐字一致）、`n=7`（40 个解，5280 帧，用来说明"搜索树会爆炸，逐帧演示只适合小数据"）。逐帧演示上限 $n=7$；$n=8$ 的 92 个解、题面上限 $n=13$ 的 73712 个解请用 `solution.cpp` 跑。

## 讲解代码

完整逐行注释版见 [`solution.cpp`](solution.cpp)，核心 10 行：

```cpp
void dfs(int i) {                            // 给第 i 行放子
    if (i > n) { printSolution(); return; }  // 放满 n 行 = 找到一个解
    for (int j = 1; j <= n; j++) {           // 列升序 => 解自动按字典序
        if (usedCol[j] || d1[i + j] || d2[i - j + n]) continue;
        col[i] = j;
        usedCol[j] = d1[i + j] = d2[i - j + n] = true;   // 打标记
        dfs(i + 1);
        usedCol[j] = d1[i + j] = d2[i - j + n] = false;  // 撤销（回溯的灵魂）
    }
}
```

## 易错点与坑

1. **对角线数组开小了** —— `d1/d2` 必须按 $2n$ 开，跟 `col` 一样开 $n$ 必越界：$i+j$ 最大 $2n$。写 `bool d1[15]` 配 `n=13` 是本题第一大 WA 源，而且越界写不一定当场崩，可能"样例过了、$n$ 大了才错"。
2. **`d2 = i - j` 不加偏移** —— $i-j$ 最小 $1-n$（负数），`d2[i-j]` 是未定义行为。必须 `d2[i - j + n]`（平移进 $[1, 2n-1]$）。$n\times n$ 棋盘斜线条数 $2n-1$ 这条账要当堂推，不能背。
3. **撤销标记忘了写** —— 只打不清，搜完一条链后标记堵满全图，解数严重偏少（$n=6$ 实测只剩 1 个解都到不了）。回溯三件套"标记→递归→撤销"缺一行都不叫回溯。
4. **找到 3 个解就退出** —— 末行要求解的**总数**（$n=13$ 是 73712）。正确写法是 `total++` 永远执行、`total<=3` 才打印；用 `if (total==3) return` 提前收工会把总数写小。
5. **行末多打空格** —— 本题输出格式严格（"两个数字之间用一个空格隔开"），行尾多一个空格可能 PE/WA。打印模板 `printf("%d%c", col[i], i==n?'\n':' ')` 先判最后一个再打分隔符，比"每格后面打空格、行末打换行"可靠。P1443 那题判定宽松可以带尾空格，**两题对照着讲正好纠正"空格无所谓"的误解**。
6. **列不按升序枚举** —— 用随机序/倒序枚举，解依然对但顺序乱，"前 3 个解"直接错。字典序是枚举顺序保证的，不是排序排出来的。
7. **把"每行一个"当成需要检查的约束** —— 按行递归天然满足，若还开二维棋盘数组逐格判"这行有没有子"，代码变长还容易漏，属于自己加戏。

## 常见变式

| 变式 | 差异 | 应对 |
| --- | --- | --- |
| 只数方案数（如 N 皇后计数） | 不用输出序列 | 去掉 `col[]` 与打印，只留 `total++`；$n=13$ 还能更快 |
| 输出**所有**解 | 前 3 限制取消 | `total<=3` 判断删掉即可 |
| 数独 / 八数码 | 约束更多、状态不同 | 仍是回溯，但剪枝换成"候选集 + 单位传播"，或转 BFS（问最少步时） |
| 求本质不同解（旋转/翻折去重） | 字典序前 3 不成立 | 需要 Burnside 或生成时限制第一子位置，明显变难 |
| 棋盘加障碍格 | 某些 $(i,j)$ 禁放 | 枚举 $j$ 前多查一张禁放表，骨架不变 |

## 小结

按行放子把"每行每列恰一个"变成免费约束，剩下斜线用 $i+j$ 恒定、$i-j$ 恒定两条编号各抓一个 $O(1)$ 查表——回溯 = 标记、递归、撤销，列升序送字典序，`total` 记全数、只印前三；问"最少"用 BFS（P1443/P1135），要"全部方案"就得回到 DFS。
