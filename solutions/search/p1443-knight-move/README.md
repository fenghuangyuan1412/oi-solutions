## 题目大意

题面关键原文（逐字，完整版见 `problem.txt`）：

> 有一个 $n \times m$ 的棋盘，在某个点 $(x, y)$ 上有一个马，要求你计算出马到达棋盘上任意一个点最少要走几步。
>
> 一个 $n \times m$ 的矩阵，代表马到达某个点最少要走几步（不能到达则输出 $-1$）。

用自己的话复述：给一个 $n\times m$ 棋盘和马的起点，**对每个格子**回答"马最少走几步能到"。马走"日"字（国际象棋的 Knight），一共 8 个跳法；到不了的格子输出 $-1$。

数据范围（逐字）：$1 \le x \le n \le 400$，$1 \le y \le m \le 400$。

题面还有一条影响输出代码的补充（逐字）：

> 2022 年 8 月之后，本题去除了对输出保留场宽的要求。为了与之兼容，本题的输出以空格或者合理的场宽分割每个整数都将判作正确。

也就是说输出格式很宽松：**空格分隔即可**，不用 `\%3d` 之类对齐场宽。

## 思路推导

### 1. 直觉想法 A：一层一层"试探"

"我先走 1 步能到哪些格？再走 2 步呢？"——把每一步能落到的格子全找出来。这个直觉**完全正确**，它就是 BFS 的按层扩展，只是还没翻译成代码。

### 2. 直觉想法 B：DFS 一路走到底，第一次到达就记步数

听起来更简单：递归地跳，跳到没访问过的格子就把当前步数写进去。**这是错的**，而且错得很隐蔽——它写出来的表"看起来像答案"。本机实测（$4\times4$ 棋盘、起点 $(1,1)$，方向顺序与讲解代码相同）：

| 格子 | 错误 DFS（第一次到达即写死） | 本目录 BFS |
| --- | --- | --- |
| $(3,2)$ | $3$ | $1$（$(1,1)\to(3,2)$ 一步就到） |
| $(1,2)$ | $13$ | $3$ |

DFS 先钻进了 $(1,1)\to(2,3)\to(4,4)\to(3,2)$ 这条"弯路"，把 $(3,2)$ 定死成 3；而 BFS 从起点按层铺，第 1 层就把 $(3,2)$ 抓到。**结论：DFS 的"第一次到达"只是"第一条搜到的路"，不是"最短路"；只有按层扩展的 BFS，第一次到达才等于最少步。**

### 3. 关键观察

1. **马每一步代价相同（都算 1 步）** ⇒ 问题变成"无权图单源最短路"⇒ BFS 的层数就是答案，不需要 Dijkstra、不需要 DP。
2. **一次 BFS 填满整张表**：题目要"任意一个点"，恰是 BFS 的副产品——从起点扩散一次，`dist` 数组本身就是到每格的最少步数，无需逐格重跑。
3. **`-1` 初值身兼两职**：既是 vis（非 $-1$ = 已访问），又是最终答案里"不可达"的输出值，一箭双雕。3×3 样例里中心格 $(2,2)$ 就是真实不可达（马跳不进去），所以本题**确实存在** $-1$，不是摆设。
4. **输出体量**：$400\times400 = 160000$ 个整数，本机输出实测约 $0.6$ MB。`printf` 走 stdio 缓冲没问题；若改用 `cin/cout` 必须 `ios::sync_with_stdio(false)`，否则同步开销会盖过算法本身（见验证结论计时）。

### 4. 算法设计

1. 读入 $n,m,x,y$；`dist` 全部置 $-1$，`dist[x][y]=0`，起点入队。
2. 当队列不空：弹出队首 $(a,b)$，对马的 8 个偏移各算一次 $(na,nb)$：
   - 出界跳过；`dist[na][nb] != -1`（已访问）跳过；
   - 否则 `dist[na][nb] = dist[a][b] + 1`，**立即入队**。
3. 按行输出 `dist`，空格分隔，不可达自然还是 $-1$。

### 5. 正确性说明

**为什么 BFS 第一次到达就是最少步？** 对"出队的先后"归纳：

- 队列里的格子按 `dist` **不减**排列（起点 0；每次入队的是"队首 +1"，接在队尾）。
- 于是格子是按 `dist` 从小到大被弹出的：先弹完所有 $d$ 步格，才会弹 $d+1$ 步格。
- 某格第一次被赋值发生在其某个邻居弹出时，值为邻居 $+1$。若存在更短的 $d'-1$ 步邻居 $u$，$u$ 的 `dist` 更小、会更早弹出，该格就会在更早时刻被填上 $d'$，矛盾。

所以填进 `dist` 的数就是最少步数；从未被填过的格即"从起点经任意步数都到不了"，输出 $-1$ 正确。

### 6. 复杂度

每格至多入队一次 ⇒ 弹出至多 $nm$ 次，每次 $O(8)$ ⇒ 时间 $O(nm)$，$400^2=1.6\times10^5$，忽略不计；瓶颈其实在输出。空间 `dist` $O(nm)$，队列最坏同阶。

## 讲解代码

完整逐行注释版见 [`solution.cpp`](solution.cpp)，核心 12 行：

```cpp
const int DX[8] = {1, 2, 2, 1, -1, -2, -2, -1};
const int DY[8] = {2, 1, -1, -2, -2, -1, 1, 2};
// ... dist 全置 -1 后：
dist[x][y] = 0; q.push({x, y});
while (!q.empty()) {
    int a = q.front().first, b = q.front().second;  q.pop();   // C++14 写法
    for (int k = 0; k < 8; k++) {
        int nx = a + DX[k], ny = b + DY[k];
        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
        if (dist[nx][ny] != -1) continue;
        dist[nx][ny] = dist[a][b] + 1;
        q.push({nx, ny});
    }
}
```

（上块为板书速记；`solution.cpp` 里是纯 C++14 的 `make_pair` 写法，以文件为准。）

## 易错点与坑

1. **马的偏移写成 4 个** —— `(±1,±2)` 与 `(±2,±1)` 两组各 4 个，共 8 个；只写 `DX[]={1,2,2,1}` 这类一半，样例 $3\times3$ 的对称棋盘可能碰巧对，非对称棋盘必错。背口诀："横走一格竖跳两格、横跳两格竖走一格，四个象限轮一遍"。
2. **`dist` 初值写成 0** —— 起点也是 0，"没访问过"和"0 步到达"混淆，BFS 认为满盘都已访问，输出全 0。正确姿势：初值 $-1$，起点单独写 0；$-1$ 还兼职"不可达"输出，一举两得。
3. **标记打在出队，而不是入队** —— 若 `push` 时不写 `dist`、等弹出时才判重，同一格子会被 8 个邻居重复拖入队列，400×400 下队列瞬间膨胀（理论上每个状态被反复塞入，直接 TLE/MLE）。**"入队即打标记"是 BFS 的铁律**，保证每格至多进队一次，复杂度分析才成立。
4. **先访问数组再判界** —— `if (dist[nx][ny]==-1 && nx>=1 && ...)` 这种顺序在越界时**已经读了越界内存**，C++ 不报错但读到垃圾值，结果随机错。边界检查必须放在任何下标访问之前。
5. **输出纠结场宽** —— 2022-08 起本题不要求场宽，`printf("%d ", v)` 即可（题面明示行末/空格分隔均判对）；反过来，抱着旧题解抄 `printf("%5d", v)` 也能过，但别把"必须 `%5d`"当知识点教。
6. **以为"所有格都可达"** —— $3\times3$ 的中心就是不可达的；$n$ 或 $m$ 很小（如 $1\times m$ 一行）时马一步都跳不出去，除起点外全是 $-1$。造小数据时故意看一眼 $-1$。

## 常见变式

| 变式 | 差异 | 应对 |
| --- | --- | --- |
| 只问终点 $(tx,ty)$ 的最少步 | 不用填全表 | BFS 中一赋值到 $(tx,ty)$ 就 `return`（第一次碰到仍是最短） |
| 棋盘有障碍格 | 某些格禁止落子 | 判界之外多判 `block[nx][ny]`，骨架不变 |
| 马的数量/覆盖类计数 | 不是"最少步" | 可能是二分图匹配或 DP，BFS 不再适用 |
| 每步代价不同（如加权） | 无权假设被破坏 | 换 Dijkstra 或 0-1 BFS，见 graph 主题目录 |

## 小结

BFS 按层扩散 ⇒ 第一次到达即最少步；`dist` 初值 `-1` 同时当 vis 和"不可达答案"，一次出队填一格的写法（入队即打标记）把"求最短路"三行代码模板钉死。与 DFS 对照记忆：DFS 给你**第一条**路，BFS 给你**最短**路。
