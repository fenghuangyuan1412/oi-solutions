## 题目大意

题面关键原文（逐字，完整版见 `problem.txt`）：

> 大楼的每一层楼都可以停电梯，而且第 $i$ 层楼（$1 \le i \le N$）上有一个数字 $K_i$（$0 \le K_i \le N$）。电梯只有四个按钮：开，关，上，下。上下的层数等于当前楼层上的那个数字。当然，如果不能满足要求，相应的按钮就会失灵。
>
> 那么，从 $A$ 楼到 $B$ 楼至少要按几次按钮呢？

用自己的话复述：站在一栋 $N$ 层楼里，第 $i$ 层写着数 $K_i$。在 $i$ 层按"上"到 $i+K_i$ 层、按"下"到 $i-K_i$ 层；结果不是 $1..N$ 里的层号时该按钮**失灵**（没有这个按钮效果）。问从 $A$ 层到 $B$ 层最少按几次"上/下"，去不了输出 $-1$。

数据范围（逐字）：$1 \le N \le 200$，$1 \le A, B \le N$，$0 \le K_i \le N$。本题共 $16$ 个测试点，前 $15$ 个每个测试点 $6$ 分，最后一个测试点 $10$ 分。

题面自带的例子值得课上读一遍：$K=(3,3,1,2,5)$，在 1 楼按"上"到 $1+3=4$ 楼；按"下"要到 $-2$ 楼，**不存在，所以失灵** —— 这句就是"越界的边不存在"的拟人说法。

## 思路推导

### 1. 暴力想法：搜索所有按键序列

把"按一次按钮"想成一棵树的一层：第 1 层是两次选择（上/下），第 2 层再各两次……深度 $d$ 时最多 $2^d$ 个序列，而且图里有**环**（比如 4 楼按下到 2 楼、2 楼按上又能回……取决于 $K$，某些数据里能绕回原层），不记录"当前在几楼"就根本停不下来。就算用 `vis` 限制"同一楼不进第二条路径"，DFS 先搜到的路径也**不保证按键最少**（和 P1443 里错误 DFS 一模一样的坑）。

### 2. 关键观察：这其实就是一张图

1. **状态就是楼层号**：任何一个时刻只需要知道"现在在几楼"，$1..N$ 共 200 个状态。
2. **每个状态恰好 2 条出边**：$i \to i+K_i$（存在当且仅当 $i+K_i \le N$）和 $i \to i-K_i$（当且仅当 $i-K_i \ge 1$）。"按钮失灵" = 这条边不存在。边还带**自环**（$K_i=0$ 时 $i\to i$），无害但要想见。
3. **每条边代价都是"按 1 次"** —— 无权图。无权图求 $A$ 到 $B$ 最少边数就是 **BFS 层数**，**不需要 Dijkstra**（那是边带权的），也不需要 DP（有环，无后效性顺序找不到）。
4. 与 P1443 对照：棋盘格 → 楼层，8 个偏移 → 2 个按钮，"每格最少步" → "每层最少按键数"。骨架代码一字不改，变的只是"邻居怎么生成"。

### 3. 算法设计

1. 读 $N,A,B$ 和 $K_{1..N}$；`dist[1..N]` 置 $-1$。
2. `dist[A]=0`，$A$ 入队（**入队即打标记**，同 P1443 铁律）。
3. 弹出 $x$：若 $up=x+K_x\le N$ 且未访问 ⇒ `dist[up]=dist[x]+1` 入队；`down` 同理（$\ge 1$）。判界必须在读 `dist` 之前。
4. 输出 `dist[B]`：不可达时它保持 $-1$，正合题面；$A=B$ 时它是 $0$（按 0 次就是最少）。

小优化：弹出/赋值时一碰到 $B$ 就可立刻结束（BFS 第一次碰到即最短）；本题 $N\le200$，讲课时建议先跑完整 BFS，让 `dist` 数组当"板书"用。

### 4. 正确性说明

- 与 P1443 同一归纳：队列按 `dist` 不减排列 ⇒ 楼层第一次被赋值即最少按键数。
- 边集与题意一一对应：题面"按上/下后必须仍在 $1..N$"恰是"边存在"的条件，失灵按钮 = 没有出边，因此图上的一条路径 $\equiv$ 一串合法按键，路径长 $\equiv$ 按键次数。
- $A=B$：`dist[A]=0`，0 次按键合法且不可能更少。

### 5. 复杂度

$N$ 个点各入队至多一次，每次 $O(1)$ 处理两条边 ⇒ 时间 $O(N)$，空间 $O(N)$。$N\le200$，本质上是"能不能想到建图"而不是"能不能跑得快"。

## 板书演示（官方样例 `5 1 5` / `3 3 1 2 5`，下表为插桩程序实测）

$K_1=3,K_2=3,K_3=1,K_4=2,K_5=5$，从 1 楼到 5 楼：

| 弹出楼层 | 它的 dist | "上" $x+K_x$ | "下" $x-K_x$ | 新入队 | 弹出后队列 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | $1+3=4$ ✅ | $1-3=-2$ 失灵 | 4（=1） | $[4]$ |
| 4 | 1 | $4+2=6>5$ 失灵 | $4-2=2$ ✅ | 2（=2） | $[2]$ |
| 2 | 2 | $2+3=5$ ✅ | $2-3=-1$ 失灵 | 5（=3） | $[5]$ |
| 5 | 3 | $5+5=10$ 失灵 | $5-5=0$ 失灵 | — | $[]$ |

最终 `dist = [0, 2, -1, 1, 3]`（下标 1..5），程序输出 `dist[5] = 3` ✅。

两个必讲的细节：

- **路径是 $1\to4\to2\to5$，不是 $1\to4\to5$**。4 楼只有两条去路：上到 6（不存在）、下到 2 —— "从 4 直接按到 5"根本没有这个按钮效果。最少 3 次由此得来。
- **3 楼全程没被访问，`dist[3]` 保持 $-1$**：要跳到 3 楼，得存在 $x$ 使 $x+K_x=3$ 或 $x-K_x=3$。挨个查：$1\pm3\to4/-2$、$2\pm3\to5/-1$、$4\pm2\to6/2$、$5\pm5\to10/0$，没人能落到 3 —— 从 1 楼出发永远去不了 3 楼（虽然它自己按"下"能去 2 楼，但你进不去它）。

## 讲解代码

完整逐行注释版见 [`solution.cpp`](solution.cpp)，核心 8 行：

```cpp
int up = x + k[x];
if (up <= n && dist[up] == -1) { dist[up] = dist[x] + 1; q.push(up); }  // 先判界再读数组
int down = x - k[x];
if (down >= 1 && dist[down] == -1) { dist[down] = dist[x] + 1; q.push(down); }
// k[x]==0 时 up==down==x，dist[x] 已非 -1，自环自动跳过，不会死循环
```

对拍参照特意选了 Floyd：它算的是**任意两楼层间**的最少按键数，连 `A==B`、不可达这些边角都会暴露；BFS 只在 $A$ 一处开花。两套机器 200 组全一致，可信度高。**洛谷提交结果未获取，因此不下 AC 结论。**

## 易错点与坑

1. **忘判 $A=B$** —— 用"入队即返回"写法（一碰到 $B$ 就打印退出）时，$A=B$ 压根没进过循环，输出错成 $-1$。要么老老实实 `dist[A]=0` 后查表输出（本讲解代码的写法，天然给 0），要么开头显式特判 $0$，**二选一，别两头都不管**。
2. **把"按钮失灵"实现成越界访问** —— 先算 `nx = x - k[x]` 再去读 `dist[nx]`：`nx` 可能 $\le 0$ 或 $>N$，C++ 不报错，读到的是别的变量的内存，答案随机。顺序必须是**先判 $1\le nx\le N$，再碰数组**。
3. **$K_i=0$ 的自环 + 出队才打标记 = 死循环** —— $i$ 楼按哪个按钮都停在 $i$ 楼。若 `dist` 标记打在出队时，同一层会被自己反复入队，队列永不清空。入队即打标记则第二次立刻被 `dist[x]!=-1` 拦住。
4. **看到"最少"就想 Dijkstra/DP** —— 本题边权全是 1，BFS 层数即答案；$N\le200$ 且有环，DP 找不到无环顺序，反而把简单题做死。课堂上问一句"什么时候才配不上 Dijkstra？"——答：所有边等权时。
5. **`dist` 初值 0 而不是 -1** —— 同 P1443：起点 0 步与"没访问"无法区分，BFS 一步都走不动，`A≠B` 时全错（$A=B$ 碰巧输出 0 对，更隐蔽）。
6. **读入 `K` 前就开始 BFS / 下标 0 起 1 止混用** —— 楼层是 1-based，数组多开一位比换算安全。

## 常见变式

| 变式 | 差异 | 应对 |
| --- | --- | --- |
| 问所有楼层对的最少按键 | 多源多次查询 | 就是参照实现 Floyd $O(N^3)$，或 N 次 BFS |
| 上/下按 $K_i$ 层之外还有第三种按钮（费用不同） | 边不再等权 | 0-1 BFS 或 Dijkstra |
| 电梯到站必须开/关一次门 | 边权变 2~3 | 仍是图，BFS 换成带权最短路 |
| 问"最少按键路径字典序最小" | 要方案本身 | BFS 树上记录前驱，从 $B$ 倒回 $A$ 再比较 |

## 小结

"状态只有 200 个、每个状态固定两个动作"就是 BFS 的信号：把楼层当点、按键当边，`dist` 层数即最少按键数；`-1` 初值兼职 vis 与"不可达"输出，先判界再碰数组、入队即打标记，两条铁律原封不动从 P1443 搬过来。
