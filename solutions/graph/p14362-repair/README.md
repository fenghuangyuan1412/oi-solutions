## 题目大意

题面逐字（见 problem.txt）：

> C 国政府希望以最低的费用将**原有**的 $n$ 座城市两两连通，也即任意两座原有的城市都能通过若干条修复或新建造的道路相互到达。

- $m$ 条原有双向道路全部震坏，修复第 $i$ 条费用 $w_i$；
- $k$ 个乡镇：先花 $c_j$ 城市化改造，之后乡镇 $j$ 可与任意城市 $i$ 花 $a_{j,i}$ 造路；
- 可以改造**任意多个**乡镇，也可以一个都不改。目标是让**原有 $n$ 座城市**两两连通（乡镇不要求被连通，但要用它的边就必须先付 $c_j$）。

**样例 1 手算**（$n=4$，边 $(1,4,6),(2,3,7),(4,2,5),(4,3,4)$；乡镇 1：$c=1$，$a=[1,8,2,4]$；乡镇 2：$c=100$，$a=[1,3,2,4]$）。
枚举全部 $2^2=4$ 种乡镇子集，每个子集把"乡镇当作额外节点"跑一遍 MST（下面的数字是本机程序逐子集实测打印的）：

| 子集 $S$ | sum $c_j$ + MST 费用 | 明细 |
| --- | --- | --- |
| $\{\}$ | 15 | 只修路：$4+5+6$ |
| $\{\text{乡镇}1\}$ | **13** | 修 3、4 号路 $5+4$，改造花 $1$，造 $t_1\to 1$ 城 $1$、$t_1\to 3$ 城 $2$：$5+4+1+1+2=13$，与题面解释逐字一致 |
| $\{\text{乡镇}2\}$ | 110 | 改造费 100 太贵 |
| $\{\text{乡镇}1,\text{乡镇}2\}$ | 112 | 同上再加 100 与一条 1 元边 |

答案 `13`。**为什么固定 $S$ 后跑 MST 是对的**：把用得到的乡镇 $j$ 当作多出来的一个节点（编号 $n{+}1..n{+}k$），"修好的原路 + 造出的新路"必须让 $n+|S|$ 个点全连通——这是合法方案；反过来，全局最优解真正用到的乡镇集合 $J$ 上，最优道路结构一定包含一棵覆盖 $n+|J|$ 个点的生成树，所以 $|S|$ 固定时 MST 不劣于任何方案。两边一夹：**最优答案 = $\min_S(\sum_{j\in S} c_j + \mathrm{MST}(n+|S| \text{ 个点}))$**，枚举即精确。

**合计约 72 分**。剩下 15,16 与 21~25（28 分）是 $k=10$ 无性质档，本质是"1024 × 百万边扫不动"，正解的活。

### 三条可操作的动作

1. **动作一：先交"Kruskal 模板 + k=0 判断"（16 分，约 15 分钟）**。这题的 $k=0$ 档就是裸 MST，考场上无论后面写不写得动，先把模板分锁死。
2. **动作二：写"性质 A 检测"（再 +8~16 分，约 5 分钟）**：读入时检查"所有 $c_j=0$ 且乡镇 $j$ 存在一条 $a_{j,i}=0$"。满足就**所有乡镇全上、只跑一次 Kruskal**。为什么全上不吃亏：$c_j=0$，又有一条 0 元边，把 $t_j$ 挂到 MST 上成本为 0，多挂一个叶子不破坏连通、不增加费用，边只会更多、MST 只会更便宜。
3. **动作三：$k\le5$ 全枚举（把分刷满 72）**：$\le 32$ 个 mask，每个 mask 把"原边（排好序）+ 选中乡镇的边（排好序）"线性 `merge` 后一遍 Kruskal。**必带 fread 快读**：$m=10^6$ 时 scanf 光读入就要 1.1 秒以上（本机实测：只读入+排序的探针程序总耗时 1211 ms，其中 sort 仅 59 ms）。
4. **兜底红线**：$k>5$ 且非 A 时，本代码只试 {空集、每个单乡镇、全集} 共 $k+2$ 种，**保证输出一个合法的连通方案费用**（不 RE、不 TLE、不刷 0 行），但不保证最小——在自造 $n=10^3,m=10^6,k=10$ 数据上，兜底给出 422461152，而全枚举真最优是 418826792，差 0.87%。这份数据上"没拿分"是诚实预期。

## 二、正解思路（本目录不实现）

$k=10$ 无性质档（测试点 15,16、21~25，共 7 点 28 分）要求比 $2^k$ 次全图扫描更快的做法。从题面结构看方向大致是：把 $k n \le 10^5$ 条乡镇边和 $m$ 条原边**一次性排好序**，跑一遍 Kruskal 的同时在"森林/连通块"上携带"已经接入了哪些乡镇"的 $2^k$ 状态（乡镇一旦接入，它剩下的边就全图可用——这正是 $c_j$ 作为"开包费"的代价结构），即 **Kruskal + 状态压缩在连通块上的合并**。难在：状态必须挂在"块"而不是"点"上才能不爆，块间合并的复杂度分析很讲究；$m=10^6$ 下任何 $\times 2^k$ 的边集复制都必死（本机全枚举 $k=10$ 实测 13.8 s / 7.7 s，时限只有 2 s）。这已超出本批教学范围，且官方题解本目录无法联网核对——**因此本节只给方向，不实现、不贴代码**。

## 三、讲解代码（`solution_partial.cpp`，关键片段）

```cpp
// 固定乡镇子集：sum c_j + MST(把 n+|towns| 个点全部连通)
long long calc(const vector<int>& towns) {
    int tot = n + (int)towns.size();
    ...
    for (size_t t = 0; t < towns.size(); ++t) {
        int j = towns[t];
        cost += ct[j];                                   // 改造费一分不能少
        extra.insert(extra.end(), star[j].begin(), star[j].end());
    }
    sort(extra.begin(), extra.end());                    // 乡镇边很少(<=kn)，单独排序
    buf.resize(base.size() + extra.size());
    merge(base.begin(), base.end(), extra.begin(), extra.end(), buf.begin());  // 百万边不重排，线性合并
    for (int i = 1; i <= tot; ++i) fa[i] = i;            // 注意是 tot，不是 n！
    int used = 0;
    for (size_t i = 0; i < buf.size() && used < tot - 1; ++i) {   // 够了边就提前停
        int x = findf(buf[i].u), y = findf(buf[i].v);
        if (x != y) { fa[x] = y; cost += buf[i].w; ++used; }
    }
    return cost;
}
```

## 四、易错点（每条都有实测证据；错误版本 = 对正确版只改一行）

官方样例正确输出（逐字）：`13`。

1. **忘加乡镇改造费 $c_j$**（删掉 `cost += ct[j]`）：样例实测输出 `10`——比正解少 3，正好漏掉 $c_1=1$ 和两条本不该免费的路。样例当场抓住。
2. **总费用用 `int`**：样例仍然输出 `13`——**样例根本查不出来**！在本机自造 $k=0$ 极限数据（$n=10^4,m=10^6,w\sim10^9$，正确答案 `42871249427`）上，`int` 版实测输出 `-78423533`（负数）。答案上界 $10^{13}$，`long long` 一个都不能省。
3. **乡镇节点编号和城市撞号**（$t_j$ 写成 $j+1$ 而不是 $n+1+j$）：样例实测输出 `12`——把"乡镇 1"当成了"城市 1"，凭空造出一条不要钱的"城市 1 自环星"。
4. **DSU 初始化漏掉乡镇节点**（`for i<=tot` 写成 `for i<=n`）：样例仍输出 `13`（查不出来）；在自造双乡镇小数据（正解 9）上实测输出 `3`——**比真最优还小，物理上不可能的答案**；在 $n=10^3,m=10^6,k=5$ 数据上输出 `41317296898`，正确版是 `41378704508`。
5. **子集枚举不完整**（"至多用一个乡镇"，`mask < (1<<k)` 写成 `mask <= k`）：样例还是 `13`（样例最优恰好用 1 个乡镇，查不出来）；在自造双乡镇数据上实测输出 `57`，而暴力验证真最优是 `9`（必须两个乡镇同时上才便宜）。
6. **不加 fread 快读**：不是答案错，是**白送的档也会 TLE**——本机探针实测 scanf 读 20 MB 输入 ≈ 1.1 秒（含 sort 共 1211 ms），$k\le5$ 档直接逼近时限。`m=10^6` 的题，读入本身就是考点。

## 五、常见变式

| 变式 | 差异 | 备注 |

## 六、一句话提炼

**"选哪几个乡镇"只有 $2^k$ 种，$k\le5$ 时每种跑一遍 Kruskal 就是满分做法的退化版——72 分全是这么搬回来的；剩下 28 分卡在 $1024 \times 10^6$ 条边扫不动，那是正解的账，考场上把快读、$c_j$、`long long`、DSU 范围四件事做对，就没人能从你手里多拿走一分。**
