## 题目大意

$n$ 只怪兽，第 $i$ 只的**攻击力 = 防御力 = $a_i$**。每回合选两只**不同**的怪兽 $x, y$，让 $x$ 攻击 $y$：

- 若 $a_x \le a_y$，无事发生；
- 若 $a_x > a_y$，$y$ 的防御被打破，**$y$ 退出游戏**。

**每只怪兽整场至多攻击一次**。当所有未退出的怪兽都已攻击过时，游戏结束。问：游戏结束时**未退出怪兽数量的最小值**。

样例 1：$a = [1,2,3,1,2]$ ⇒ `2`。一种最优顺序：

| 回合 | 谁打谁 | 结果 |
| --- | --- | --- |
| 1 | 怪兽 2（攻 2）打 怪兽 1（防 1） | $2 > 1$，怪兽 1 退出 |
| 2 | 怪兽 5（攻 2）打 怪兽 4（防 1） | $2 > 1$，怪兽 4 退出 |
| 3 | 怪兽 3（攻 3）打 怪兽 2（防 2） | $3 > 2$，怪兽 2 退出 |

剩下怪兽 3、5，两只都已攻击过 ⇒ 游戏结束，剩 2 只。**注意第 3 回合打的是"已经攻击过的怪兽 2"——退出与否和"有没有攻击过"无关**，这是本题最容易读漏的一点。

## 一、骗分：这一档怎么拿

### 骗分思路 1：一眼看穿的特殊情况（几乎白送）

| 情况 | 答案 | 理由 |
| --- | --- | --- |
| 所有 $a_i$ 相同 | $n$ | 谁也杀不了谁（$a_x \le a_y$ 恒成立） |
| $a_i$ 两两不同且已排序 | $1$ | 最大的杀第二大的、第二大的杀第三大的…… 一路杀下去只剩最大的一只 |
| $n = 1$ | $1$ | 只有一只，无法攻击，游戏结束 |
| $n = 2$ 且 $a_1 = a_2$ | $2$ | 互杀无效 |

这几条用几行 `if` 就能写，覆盖了不少小规模测试点。**先把手上的样例和边界稳住**，是考场上第一件该做的事。

### 骗分思路 2：$O(n^2)$ 暴力匹配（本目录的 `solution_partial.cpp`）

排序后，对每个目标 $j$（从小到大），**暴力扫一遍**找一只未使用、且 $a_i > a_j$ 的攻击者。

- 逻辑与正解完全一致，只是找匹配的方式朴素；
- $n \le 2000$ 的档稳过，$n = 10^5$ 超时（约 $5\times10^9$ 次比较）；
- 它的另一个用处：**当正解的对拍参照**（本机 200 组 0 不一致）。

### 骗分思路 3：特殊性质 A（$a_i$ 随机生成）

题面给了特殊性质 A：**每个 $a_i$ 在值域中独立均匀随机生成**。随机数据的直觉是"几乎所有怪兽都能被更大的怪兽杀掉"。

- 实测 $n = 10^5$、$a_i$ 在 $[1, 10^5]$ 均匀随机的数据，答案是 **8**——也就是说 **99.99% 的怪兽都被杀掉了**；
- 所以随机性质下**输出一个很小的常数**（比如 $10$ 上下）也能撞对不少点；
- 但手册的红线在这里适用：**这是"蒙"，不是"骗分"**。它没有正确性保证，只应该作为"实在不会时的兜底"，绝不能替代上面两条。

### 骗分思路 4：错误的贪心（**反例，别交**）

"每次让**攻击力最大**的怪兽去杀**防御力最小**的怪兽。"

- 看起来顺，但它会在**同值扎堆**的数据上翻车；
- 例如 $a = [1,2,2]$：正确做法是"2 杀 1"（杀 1 只，剩 2）；错误做法若先把两个 2 各用一次去打 1（只有一只 1），就会浪费一次攻击机会。

## 二、正解：排序 + 双指针求最大匹配

### 关键转化

把一次"攻击"看成一条**有向边** $x \to y$，要求 $a_x > a_y$。题目的两条约束正好对应匹配的两条约束：

| 题面约束 | 匹配语言 |
| --- | --- |
| 每只怪兽**至多攻击一次** | 每个点最多作为**边的起点**一次 |
| 怪兽退出后不再参与 | 每个点最多作为**边的终点**一次 |

于是

$$\text{未退出数量的最小值} = n - (\text{最多能配出的边数}) = n - \text{最大匹配}$$

而这里的"最大匹配"发生在一条**偏序链**上（按 $a$ 排序后，"大的"总能配"小的"），可以用贪心线性求出。

### 贪心：排序 + 双指针

1. 把 $a$ **升序排序**；
2. 用指针 `j` 指向"当前最小的、还没被杀掉的目标"，`i` 扫过所有怪兽：
   - 若 `a[i] > a[j]`：**配对成功**（`i` 杀 `j`），`killed++`，`j++`；
   - 否则 `i` 前进（这只攻击力不够，换一只更大的试试）。

`i` 和 `j` 都只前进不后退，一趟 $O(n)$，加上排序共 $O(n \log n)$。

### 用样例 1 走一遍

$a$ 排序后 $= [1,1,2,2,3]$：

| 步 | $i$ | $j$ | $a_i$ vs $a_j$ | 动作 | `killed` |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 0 | $1 > 1$？否 | $i$ 前进 | 0 |
| 2 | 1 | 0 | $1 > 1$？否 | $i$ 前进 | 0 |
| 3 | 2 | 0 | $2 > 1$？**是** | 配对，$i,j$ 各前进 | 1 |
| 4 | 3 | 1 | $2 > 1$？**是** | 配对 | 2 |
| 5 | 4 | 2 | $3 > 2$？**是** | 配对 | 3 |

答案 $5 - 3 = 2$ ✓

## 三、正确性说明

**引理 1（上界）**：任何方案里退出的怪兽数不超过最大匹配数。

*证明*：设退出了 $k$ 只怪兽，第 $t$ 只退出时是被某只怪兽 $x_t$ 攻击的。这些 $x_t$ 互不相同（每只至多攻击一次），被攻击的 $k$ 只也互不相同，且 $a_{x_t} > a_{y_t}$，故这 $k$ 条边构成一个匹配，$k \le$ 最大匹配。$\blacksquare$

**引理 2（贪心取到最大匹配）**：排序后按上述双指针，`killed` 等于最大匹配数。

*证明*：设最大匹配为 $\{(x_1,y_1),\dots,(x_k,y_k)\}$，把 $y$ 按升序排好 $y_1 < y_2 < \dots < y_k$。对贪心的第 $t$ 次配对，断言 $a_{j_t} \le a_{y_t}$（贪心取到的第 $t$ 个目标不大于最优解的第 $t$ 个目标）。归纳：$t=1$ 时 $j_1$ 是最小元素，显然 $\le y_1$；若 $a_{j_t} \le a_{y_t}$，则贪心为找下一个目标只会从 $j_t$ 之后取，而 $y_{t+1} > y_t \ge j_t$，故 $j_{t+1} \le y_{t+1}$。于是贪心至少能配出 $k$ 对，结合引理 1 得等号。$\blacksquare$

**引理 3（$n-k$ 是可实现的）**：配出 $k$ 条边后，可以让游戏恰好在这 $k$ 只退出后结束。

*证明*：按被攻击者 $a$ 值**升序**执行这 $k$ 次攻击。执行到第 $t$ 条边 $(x_t,y_t)$ 时，$y_t$ 若曾作为攻击者出现在某条边里，那条边的被攻击者比 $y_t$ 更小、已先执行完，故 $y_t$ 此刻仍在场，攻击合法。$k$ 次攻击后剩余 $n-k$ 只，让它们随意两两"攻击"一次（可能无事发生）即全部满足"已攻击过"，游戏结束。$\blacksquare$

**定理**：答案 $= n - \text{最大匹配}$。

*证明*：引理 1 给出下界（退出数 $\le$ 最大匹配），引理 3 给出可达性。$\blacksquare$

**复杂度**：排序 $O(n\log n)$，双指针 $O(n)$。

## 四、讲解代码

### 正解（`solution.cpp`）

```cpp
sort(a.begin(), a.end());

int killed = 0, j = 0;
for (int i = 0; i < n; ++i) {
    if (a[i] > a[j]) { ++killed; ++j; }   // i 杀 j，两者各前进一步
}

cout << n - killed << "\n";
```

只有四行有效代码。**注意 `i == j` 时不需要特判**：那时 `a[i] == a[j]`，条件 `a[i] > a[j]` 自然为假。

### 暴力版（`solution_partial.cpp`，$O(n^2)$）

```cpp
vector<char> used(n, 0);
int killed = 0;
for (int j = 0; j < n; ++j)          // 目标从小到大
    for (int i = 0; i < n; ++i)      // 暴力找攻击者
        if (i != j && !used[i] && a[i] > a[j]) { used[i] = 1; ++killed; break; }
```

两版对拍 **200 组 0 不一致**。

## 五、易错点与坑

1. **以为"攻击过的怪兽不能再被杀"**：这是本题最大的读题陷阱。题面只说"至多攻击一次"，**没说不能被攻击**。样例 1 的第 3 回合就是"杀一只已经攻击过的怪兽"。
2. **以为"被杀后就不能攻击"**：同上是错的。约束只作用在"作为攻击者"这一次上。
3. **双指针写成 `while (a[i] <= a[j]) i++` 然后 `i++, j++`**：边界容易越界。推荐本目录的写法——**只有一个 `for`，条件为真才 `j++`**，天然不会越界（因为 `j` 只在配对时前进，恒有 `j <= i < n`）。
4. **排序后忘了用排序后的数组**：`killed` 依赖"大的在后面"，没排序时贪心不成立。
5. **输出写成 `killed`**：题目要的是"未退出的数量"，即 $n - killed$。
6. **$n=1$ 时输出 0**：算法给出 $1 - 0 = 1$，正确。若手写特判要小心别写成 0。

## 六、常见变式

| 变式 | 差异 | 备注 |
| --- | --- | --- |
| 要求 $a_x \ge a_y$ 才能杀（非严格） | 贪心改成 `>=`，但同一只不能杀自己 | 需特判 $i \ne j$ |
| 每只怪兽可以攻击多次 | 贪心失效，变成另一类问题 | — |
| 求**最大**剩余数 | 取 $\max$，即"尽量少配对" | 反向贪心 |
| 怪兽有攻击力和防御力两个参数 | 变成一般二分图匹配，需要匈牙利/网络流 | 难度跳两档 |

## 七、一句话提炼

**"每只至多攻击一次"+"被杀就退出"合起来正好是二分图匹配的两条边约束**——于是"最少剩几只"变成"最多配几对"，而在按攻击力排序的偏序链上，最大匹配用**双指针一趟扫**就能求。这道题的价值在于：**把一道"看起来要模拟"的博弈题，翻译成一句"$n$ 减最大匹配"。**
