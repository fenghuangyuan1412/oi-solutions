## 题目大意

公路上有 $n$ 个站点，站点 $i$ 到 $i+1$ 相距 $d_i$ 公里；站点 $i$ 的油价是 $a_i$ 元/升，**只能买整数升**。车从站点 1 出发，油箱初始为空，**油箱无限大**，每升油能跑 $v$ 公里。求从站点 1 开到站点 $n$ 的**最少花费**。

样例：`n=5, v=4`，$d = [10,10,10,10]$，$a = [9,8,9,6,5]$ ⇒ `79`。

最优方案（手算）：

| 站点 | 油价 | 买几升 | 花多少 | 为什么 |
| --- | --- | --- | --- | --- |
| 1 | 9 | 3 | 27 | 够走到站点 2（10 公里需 2.5 升 → 取整 3） |
| 2 | 8 | 5 | 40 | 站点 2 比后面便宜（8 < 9），但要留神站点 4 的 6 更便宜，所以只买到能撑到站点 4 |
| 4 | 6 | 2 | 12 | 只差 8 公里，买 2 升 |
| 合计 | | | **79** | |

## 一、骗分：这一档怎么拿

本题正解只有十行，**骗分的意义不在于"绕过难点"，而在于演示"按特殊性质分档"和"按数据范围分档"两种最常用的保分手段**。

### 骗分思路 1：特殊性质 A —— 站点 1 油价最低

题面给了特殊性质 A：**站点 1 的油价最低**。此时最优策略简单到不用想：**全程的油都在站点 1 一次买齐**。

- 需要的总油量 = $\lceil \text{总距离} / v \rceil$，总距离 = $\sum_{i=1}^{n-1} d_i$；
- 答案 = 总油量 $\times a_1$。

这一档只值几行代码，却是**稳拿的一档分**。识别方式：读入后判断 $a_1 = \min_i a_i$。

### 骗分思路 2：特殊性质 B —— $d_i$ 都是 $v$ 的倍数

题面给的另一个性质是**所有 $d_i$ 都是 $v$ 的倍数**。此时"向上取整"这一步永远不会产生余数，油箱里的剩余油量恒为 0。

- 好处是：**不用担心"买多了油"的情况**，贪心逻辑大幅简化；
- 具体做法：在每个站点 $i$，如果 $a_i$ 比它**之后所有站点**都便宜，就在这里买够到终点；否则只买到"下一个更便宜的站点"。
- 这其实是正解的简化版，写对了就是满分，写错了也只是掉这一档。

### 骗分思路 3：朴素贪心"每站买够到下一站"（**反例，别交**）

一个看起来非常顺的贪心：**每到一个站，就只买刚好能开到下一站的油。**

- 样例上它算出 $3\times 9 + 3\times 8 + 3\times 9 + 3\times 6 = 96 > 79$，**样例 1 就过不去**；
- 错因：它丢掉了"油箱无限大"这个条件——题目允许你**在最便宜的站提前买油**，而这个贪心从不提前买。
- 记在手册 T6 名下：**漏掉一条题面规则，代价比复杂度差一档更大。**

### 骗分思路 4：按数据范围分档（本目录的 `solution_partial.cpp`）

把正解的贪心**用最朴素的方式实现**：每次暴力向后找"下一个更便宜的站"、暴力累加距离，整体 $O(n^2)$。

- $n \le 2000$ 的档稳过，$n = 10^5$ 超时；
- 但它的**逻辑与正解完全一致**，所以是一个天然的对拍参照——本机 200 组 0 不一致就是这么来的。

## 二、正解：只在需要时买，且永远按历史最低价买

### 关键观察

**油箱无限大 ⇒ 你可以在最便宜的那个站，一次性预买未来的油。**

于是把"在哪买油"这个问题反过来问：**第 $i$ 段路烧掉的油，到底应该算多少钱？**

> 第 $i$ 段烧掉的油，可以"平移"到它**之前**出现过的最便宜站点去买，价钱只降不升。

把每一段都做这种平移，就得到一个非常简单的算法：维护两个量。

| 变量 | 含义 |
| --- | --- |
| `rest` | 油箱里还能走多少**公里** |
| `minp` | 从起点走到当前站，出现过的**最低油价** |

走到第 $i$ 段（从站点 $i$ 到 $i+1$）时：

1. `minp = min(minp, a[i])` —— 先把这个站的油价纳入"历史最低"；
2. 若 `rest >= d[i]`：直接开过去，**一分钱不花**，`rest -= d[i]`；
3. 否则缺 `need = d[i] - rest` 公里，**至少要买 $\lceil need/v \rceil$ 升**（整数升，向上取整），按 `minp` 结算；`rest += buy * v - d[i]`。

### 用样例走一遍

`v=4`，$d=[10,10,10,10]$，$a=[9,8,9,6,5]$：

| $i$ | `minp` | `rest`（进） | `d[i]` | 需要 | 买几升 | 花 | `rest`（出） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 9 | 0 | 10 | 10 | $\lceil 10/4\rceil=3$ | $3\times9=27$ | $12-10=2$ |
| 2 | **8** | 2 | 10 | 8 | $\lceil 8/4\rceil=2$ | $2\times8=16$ | $2+8-10=0$ |
| 3 | 8 | 0 | 10 | 10 | 3 | $3\times8=24$ | 2 |
| 4 | **6** | 2 | 10 | 8 | 2 | $2\times6=12$ | 0 |
| 合计 | | | | | | **79** | |

注意站点 3 的油价是 9，但 `minp` 仍是 8 —— 所以这里买的 3 升按 **8 元**结算，等价于"在站点 2 多买了 3 升带过来"。这就是算法的全部魔法。

### 为什么"按历史最低价买"不违规？

有学生会问：站点 3 的油明明是 9 元，凭什么按 8 元算？

答：**因为可以真的在站点 2 买**。站点 2 到站点 3 只隔 10 公里，在站点 2 多买 3 升完全合法（油箱无限大）。算法只是把"在站点 2 多买的那 3 升"**记账记到了站点 3**而已。账目可以换，油不能凭空产生——而这里油的来源始终是真实的。

## 三、正确性说明

**引理（交换论证）**：设某最优方案在第 $i$ 段消耗了 $x$ 升油，这些油是在某个站点 $j \le i$ 买的。若存在 $j' < j$ 且 $a_{j'} < a_j$，则把"这 $x$ 升油改为在 $j'$ 购买"仍是一个合法方案，且花费不增。

*证明*：在 $j'$ 到 $i$ 的整个过程中，油箱多出的 $x$ 升油不会导致任何容量问题（油箱无限大），故方案合法；花费从 $x \cdot a_j$ 变为 $x \cdot a_{j'} \le x \cdot a_j$，不增。$\blacksquare$

**定理**：算法输出的 `ans` 是最小花费。

*证明*：反复对最优方案使用引理，可把每一段消耗的油都"平移"到该段之前的最低价站点。平移后各段的买油站点，恰好就是算法中 `minp` 取到最小值的位置；而算法在每一段买的数量也恰好是"该段实际需要的最小整数升数"（少了跑不到，多了白花钱）。故算法花费 $\le$ 最优花费；又算法方案合法，故等于最优。$\blacksquare$

**复杂度**：一趟循环，$O(n)$ 时间、$O(n)$ 空间（存 $d, a$）。

**数值范围**：总距离可达 $10^5 \times 10^5 = 10^{10}$ 公里，总油量同量级，乘上油价 $10^5$ ⇒ 答案可达 $10^{15}$ 量级，**必须 `long long`**。

## 四、讲解代码

### 正解（`solution.cpp`，$O(n)$）

```cpp
long long ans = 0, rest = 0, minp = LLONG_MAX;
for (int i = 1; i < n; ++i) {
    minp = min(minp, a[i]);                 // 记住历史最低价
    if (rest >= d[i]) { rest -= d[i]; continue; }   // 油够，直接开过去
    long long need = d[i] - rest;
    long long buy  = (need + v - 1) / v;    // 向上取整
    ans += buy * minp;                      // 按历史最低价结算
    rest += buy * v - d[i];
}
cout << ans << "\n";
```

### 慢速版（`solution_partial.cpp`，$O(n^2)$）

```cpp
for (int i = 1; i < n; ++i) {
    int nxt = n;                            // 向后找第一个更便宜的站
    for (int k = i + 1; k <= n; ++k)
        if (a[k] < a[i]) { nxt = k; break; }
    long long dist = 0;
    for (int k = i; k < nxt; ++k) dist += d[k];
    if (rest < dist) {
        long long buy = (dist - rest + v - 1) / v;
        ans += buy * a[i];
        rest += buy * v;
    }
    rest -= d[i];
}
```

两版对拍 **200 组 0 不一致**。

## 五、易错点与坑

1. **忘记"整数升"要向上取整**：`need / v` 是截断除法，会买少油、跑不到下一站。必须写 `(need + v - 1) / v`。
2. **答案用 `int`**：总花费可达 $10^{15}$，`int` 直接溢出成负数。这是本题**最致命**的坑，`long long` 一个都不能少（`ans`、`rest`、`need`、`buy`、`d`、`a`）。
3. **"随用随买"贪心**：样例 1 就过不去（算出 96，正解 79）。原因是忽略了"油箱无限大 ⇒ 可以提前买"。
4. **`minp` 只取"当前站"而不是"历史最低"**：若写成 `minp = a[i]`，就退化成"随用随买"，同样错。
5. **`rest` 的单位搞混**：本文用"还能走多少**公里**"，也有人用"还有几**升**"。两种都对，但**必须全文统一**，混用必出 bug。
6. **数组下标从 1 开始但 `d` 只读 $n-1$ 个**：`d[n]` 不存在，循环写 `i < n` 而不是 `i <= n`。

## 六、常见变式

| 变式 | 差异 | 备注 |
| --- | --- | --- |
| 油箱容量有限（比如最多 $C$ 升） | 贪心失效，需要 DP 或单调队列 | 难度直接跳两档 |
| 油价随天数变化 | 需要先确定"第几天到哪个站" | 与 P9755 同型 |
| 只能买整箱（$k$ 升一买） | 把向上取整换成向上取整到 $k$ 的倍数 | 一行改动 |
| 求**最大**花费 | 反过来：在每个站都按最贵的价格买 | 贪心方向反转 |

## 七、一句话提炼

**"油箱无限大"意味着可以把未来要烧的油提前买**——于是"在哪买"这个问题变成"每段路烧的油，历史上最便宜是多少钱"；维护一个 `minp`（历史最低价）和一个 `rest`（还能跑多远），一趟扫描就够。这道题是**"交换论证 + 一个变量记历史最优"**最干净的入门示范。
