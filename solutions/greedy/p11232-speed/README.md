## 题目大意

一条南北向主干道长 $L$，上有 $m$ 个测速仪（位置 $p_j$）。$n$ 辆车：第 $i$ 辆从位置 $d_i$ 驶入，初速度 $v_i>0$、加速度 $a_i$ 做匀加速运动向北；当它到达最北端 $L$、或速度降为 0（仅 $a_i<0$ 时）时驶离。经过**开启**的测速仪时若瞬时速度**超过**限速 $V$ 即判超速（驶入、驶出位置上的测速仪也测）。

1. **第一问**：所有测速仪都开，有多少辆车被判超速？
2. **第二问**：在"每辆原判超速的车仍被抓到"的前提下，**最多能关多少**个测速仪？

### 用官方样例手算（$L=15, V=3$，测速仪位置 $2,5,8,9,15$）

关键：车在位置 $x$ 的速度平方 $g(x)=v_i^2+2a_i(x-d_i)$（题面提示给出 $\sqrt{v_0^2+2as}$ 公式），且 $v_i,a_i,x,d_i,V$ **全是整数**，所以"超速 $=\text{速度}>V$" 等价于整数比较 $g(x) > V^2$（这里 $V^2=9$），根本不用开方、不用担心浮点。

| 车 | $(d,v,a)$ | 位置区间内各测速仪的 $g(p)$ | 有无 $g>9$ | 结论 |
| --- | --- | --- | --- | --- |
| 1 | $(0,3,0)$ | 恒为 $9$ | 否（要 $>9$，$9$ 不算） | 不超速 |
| 2 | $(12,4,0)$ | $p=15:16$ | 是（在 15） | 超速 |
| 3 | $(1,1,4)$ | $p=2:9,\;5:33,\;8:57,\;9:65,\;15:113$ | 是（除 2 外都 $>9$） | 超速 |
| 4 | $(5,5,-2)$ | $p=5:25,\;8:13,\;9:9,\;15:-15$ | 是（5、8） | 超速 |
| 5 | $(6,4,-4)$ | $p=8:0,\;9:-8,\;15:-32$（在 $[6,6.875)$ 才超速，无测速仪） | 否 | 不超速 |

⇒ 第一问 $=3$。第二问见"板书演示"，$=3$。

## 一、骗分：这一档怎么拿

题面 `problem.txt` 给的测试点表（洛谷 `fullScore=100`，共 10 个测试点，**按均分推算每点 10 分**，题面本身没写每点分值）：

| 测试点 | $n,m\le$ | 特殊性质 | 推算分值 |
| :---: | :---: | :---: | :---: |
| 1 | $10$ | 无 | 10 |
| 2 | $20$ | 无 | 10 |
| 3 | $3000$ | A（$a_i=0$） | 10 |
| 4 | $10^5$ | A | 10 |
| 5 | $3000$ | B（$a_i>0$） | 10 |
| 6 | $10^5$ | B | 10 |
| 7 | $3000$ | C（$a_i<0$ 且所有车都不在最北端驶离） | 10 |
| 8 | $10^5$ | C | 10 |
| 9 | $3000$ | 无 | 10 |
| 10 | $10^5$ | 无 | 10 |

也就是说：**$n,m\le3000$ 的 1/2/3/5/7/9 共 6 个点（约 60 分）用暴力就能拿**，只有 4/6/8/10 四个 $10^5$ 档需要"排序 + 二分"。

### 骗分思路 1：$O(nm)$ 暴力（小档保底，本目录 `solution_partial.cpp`）

不排序、不二分，直接**每辆车 × 每个测速仪**枚举：位置在 $[d_i, L]$ 且 $g(p)>V^2$ 就把这个测速仪记进该车的超速区间（取最小/最大下标，排序后天然连续）。逻辑与正解**完全一致**，只是判定用暴力扫描。

- $n,m\le 10$（测试点 1）与 $n,m\le 3000$（测试点 3/5/7/9）：**实测 $n=m=3000$ 时 0.058 s**（含进程启动），稳过这 6 个点；
- $n=m=10^5$：$10^{10}$ 次内层运算，**实测 7.86 s**，远超 2000 ms 时限 → 4 个大档拿不到。
- 好处：它和正解是同一套判据，是**天然的对拍参照**（300 组 0 不一致就是这么来的）。

### 骗分思路 2：用整数平方比较，"免费"避开精度丢分（**性价比最高的一档**）

题面最后一句警告："如果你使用浮点数进行计算，需要注意潜在的精度问题"。很多选手算 $\sqrt{v_0^2+2as}$ 再和 $V$ 比浮点，边界数据上 WA。而我们全程只比 $g(p)=v^2+2a(p-d)$ 与 $V^2$，**两个都是整数**。这一步不降低任何复杂度，却能把"本该对却因精度挂掉"的分捡回来——**是本目录最看重的骗分点**。

- 实测：`>` 误写成 `>=`（把"到达限速"也算超速）→ 官方样例第一问从 `3` 变 `4`（见易错点 1），说明边界判定极其敏感。

### 骗分思路 3：按 $a_i$ 的符号切档（性质 A / B / C 各 4 个点）

三个特殊性质的本质是**把 $g(x)=v^2+2a(x-d)$ 的单调性钉死**：

| 性质 | 条件 | $g$ 随位置 | 超速位置形状 | 能省掉什么 |
| :---: | :---: | :---: | :---: | --- |
| A | $a_i=0$ | 恒定 | 要么整段、要么空 | 连二分都不需要，一次比较定终身 |
| B | $a_i>0$ | 递增 | 后缀 $[\text{某点},L]$ | 只找"第一个 $g>V^2$" |
| C | $a_i<0$ 且不从最北端驶离 | 递减 | 前缀 $[d_i,\text{某点})$ | 只找"最后一个 $g>V^2$" |

**只写自己熟悉的那一支也值 40 分**（A/B/C 各含一个 $3000$ 档和一个 $10^5$ 档）。其中 A 档最划算：判据退化成"出发时是否已超速"，一行 `if`，$n,m\le10^5$ 也照样秒过。

### 骗分思路 4：把暴力升级成"排序 + 二分"（第一问直接满分）

暴力慢在"每辆车扫全部 $m$ 个测速仪"。先对 $p$ **排序**，利用 $g$ 单调，对每辆车只做**两次二分**（一次定位置窗口 $[d_i,L]$，一次定超速边界），$O(nm)\to O(n\log m)$。$n=m=10^5$ 时**实测约 0.30 s**，第一问就稳了。剩下的第二问交给下面的贪心。

## 二、正解：整数判据 + 区间打点贪心

### 关键观察

1. **一辆车的"超速位置"是一段连续区间。** 由 $a_i$ 的符号决定 $g(x)=v_i^2+2a_i(x-d_i)$ 对 $x$ 单调（$a_i>0$ 递增、$a_i<0$ 递减、$a_i=0$ 恒定），所以 $g>V^2$ 的解在位置轴上是一段（后缀 / 前缀 / 整段）。
2. **能抓到它的测速仪 = 落在该区间里的测速仪，排序后是一段连续下标。** 于是"这辆车对应一个测速仪下标区间 $[A,B]$"。
3. 第一问 = 数有多少个非空 $[A,B]$；第二问 = **最少的点（测速仪下标）能命中所有区间**，即经典的**区间打点**问题。

### 算法

- **判超速（整数）**：车 $i$、测速仪 $p$ 满足 $d_i\le p\le L$ 且 $v_i^2+2a_i(p-d_i)>V^2$。
- **求 $[A,B]$**：位置窗口用 `lower_bound/upper_bound` 定出 $[\text{lo},\text{hi}]$；再在窗口内按单调性二分找超速边界（$a_i>0$ 取后缀、$a_i<0$ 取前缀、$a_i=0$ 整段或空）。$A>B$ 即不超速。
- **第二问·区间打点贪心**：把所有区间**按右端点升序**排序，维护上一个已放的点 `lastPt`；遇到 $A_i >$ `lastPt`（还没被命中）就在 $B_i$ 处放一个点。$m - \text{keep}$ 就是最多能关的数量。

### 正确性（区间打点部分）

贪心选当前**未覆盖区间中右端点最小**的那个、并把点钉在其右端点。交换论证：任一最优解都必须在这个右端点或其左侧放点；把它挪到右端点不会少覆盖任何区间（右端点是该区间能"顺带"覆盖到最右的位置），故不劣。归纳可得该贪心给出**最少点数**。判超速部分由 $g$ 的单调性保证区间判定等价于暴力枚举（对拍 300 组一致）。

**复杂度**：每测试数据 排序 $O(m\log m)$ + 每车两次二分 $O(n\log m)$ + 区间排序 $O(n\log n)$ + 贪心 $O(n)$，整体 $O((n+m)\log)$；空间 $O(n+m)$。$n=m=10^5$、$T\le20$ 下总运算在时限内（单组实测约 0.30 s）。

## 三、板书演示（官方样例的第二问）

测速仪排序后下标 $1..5$：$p_1=2,p_2=5,p_3=8,p_4=9,p_5=15$。三辆超速车的区间：

| 车 | 超速位置 | 对应测速仪下标区间 $[A,B]$ |
| --- | --- | --- |
| 2（15） | $p=15$ | $[5,5]$ |
| 3（2 之外） | $p=5,8,9,15$ | $[2,5]$ |
| 4（5、8） | $p=5,8$ | $[2,3]$ |

按**右端点升序**排：$[2,3]\;[5,5]\;[2,5]$，`lastPt` 初始 $=-1$：

| 步骤 | 区间 | $A>$`lastPt`? | 动作 | `lastPt` | keep |
| --- | --- | --- | --- | --- | --- |
| 1 | $[2,3]$ | $2>-1$ ✓ | 在 3 放点 | 3 | 1 |
| 2 | $[5,5]$ | $5>3$ ✓ | 在 5 放点 | 5 | 2 |
| 3 | $[2,5]$ | $2>5$ ✗ | 已被点 5 覆盖 | 5 | 2 |

最少保留 `keep=2` → 最多关闭 $m-\text{keep}=5-2=\boxed{3}$。结合第一问 $=3$，输出 **`3 3`**，与官方一致。

## 四、讲解代码

### 判超速 + 求区间（`solution.cpp` 核心）

```cpp
ll V2 = V * V;
auto g = [&](int i, ll x)->ll { return v[i]*v[i] + 2LL*a[i]*(x-d[i]); }; // 整数速度平方

int lo = lower_bound(p.begin(),p.end(),d[i]) - p.begin(); // 位置窗口 [d_i, L]
int hi = (upper_bound(p.begin(),p.end(),L) - p.begin()) - 1;
if (lo > hi) continue;                    // 路上没有测速仪
int A, B;
if (a[i] > 0)        { /* g 递增：后缀，二分找第一个 g>V2 */ }
else if (a[i] < 0)   { /* g 递减：前缀，二分找最后一个 g>V2 */ }
else                 { if (v[i]*v[i] <= V2) continue; A=lo; B=hi; }
if (A <= B) { ++speedCnt; segs.push_back({A,B}); }
```

### 第二问：区间打点贪心（`solution.cpp`）

```cpp
sort(segs.begin(), segs.end(),
     [](auto&x, auto&y){ return x.second < y.second; }); // 按右端点
int keep = 0, lastPt = -1;
for (auto& s : segs)
    if (s.first > lastPt) { ++keep; lastPt = s.second; } // 钉在右端点
cout << speedCnt << " " << (m - keep) << "\n";
```

`solution_partial.cpp` 是同一逻辑的 $O(nm)$ 暴力版（枚举每个测速仪），供小档与对拍。

## 五、易错点（每条都实测过官方样例，正解输出为 `3 3`）

1. **把"超过 $V$"当成"到达 $V$"**：$g>V^2$ 误写成 $g\ge V^2$。匀速 3 的车（$g=9=V^2$）被误判超速，样例第一问变多：
   实测输出 `4 3`（应为 `3 3`）。
2. **忘了"驶入点之后才测得到"**：去掉 $p\ge d_i$ 下界，车还没进场就被身后的测速仪抓拍：
   实测输出 `4 4`（应为 `3 3`）。
3. **拿 $g$ 直接和 $V$ 比、忘了两边都是"平方"**：应是 $g>V^2$ 不是 $g>V$：
   实测输出 `4 3`（应为 `3 3`）。
4. **第二问把"最少保留 `keep`"当成"最多关闭"输出**：忘记用 $m-\text{keep}$：
   实测输出 `3 2`（应为 `3 3`）。
5. **测速仪没排序**：不排序时"区间"在下标上不连续，打点贪心直接失效。本目录两版都先 `sort(p)`。
6. **浮点精度**：改用 `sqrt()` 与 $V$ 比浮点，官方样例侥幸也是 `3 3`，但边界数据会 WA——所以正文一律整数平方比较。

## 六、常见变式

| 变式 | 差异 | 备注 |
| --- | --- | --- |
| 求"最少开几个测速仪" | 就是本题第二问（区间打点） | 一句话反义 |
| 测速仪可移动 / 位置非整数 | 区间打点的"点"变成连续量 | 结论仍钉右端点 |
| 求最多能关到"每辆车都被抓 $\ge 2$ 次" | 打点问题升级成"每段至少 2 点" | 贪心稍改，右端点放两次 |
| 加速度随时间非匀变速 | $g$ 不再线性，单调性破坏 | 本方法失效，需积分/分段 |

## 七、一句话提炼

**速度平方 $g(x)=v^2+2a(x-d)$ 对位置单调，于是"超速"是一段连续区间，判据是纯整数 $g>V^2$；"最少保留测速仪抓全所有超速车"就是把每辆车的区间打点——按右端点排序、遇未覆盖就钉右端点。** 这道题是**"整数判据防精度 + 区间打点贪心"**最干净的组合示范。
