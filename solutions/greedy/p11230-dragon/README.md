## 题目大意（照 `problem.txt` 摘录关键规则）

$n$ 个人，每人一个整数序列 $S_i$（词库）。一局游戏分若干轮，每轮：

- 某人 $p$ 带词库 $S_p$ 接龙；**若这不是第一轮，本轮的人不能与上一轮相同**（可与上上轮及更早相同）；
- 接龙者选 $S_p$ 的一段**长度在 $[2,k]$ 的连续子序列** $A$ 作为本轮"接龙序列"；**第一轮 $A$ 须以元素 $1$ 开头**，否则 $A$ 须以上一轮接龙序列的**最后一个元素**开头。

$g$ 个任务，第 $j$ 个问：能否进行**恰好 $r_j$ 轮**且**最后一轮接龙序列的最后一个元素恰好为 $c_j$**？能输出 `1`，否则 `0`。

### 官方样例逐条手算（$n=3,k=3$；词库 1=`1 2 3 4 1`，2=`1 2 5`，3=`5 1 6`）

| 询问 $(r,c)$ | 期望 | 依据（题面解释） |
| --- | --- | --- |
| $(1,2)$ | `1` | $p_1=1, A_1=12$：词库 1 里 `1 2` 是长度 2、以 1 开头、结尾 2 ✓ |
| $(1,4)$ | `0` | 要一步从 1 接到 4，需子串 `1 2 3 4` 长 $4>k=3$，非法 |
| $(2,4)$ | `1` | $\{p\}=\{2,1\},\{A\}=\{12,234\}$：第 1 轮词库 2 的 `1 2`，第 2 轮词库 1 的 `2 3 4`（长 3）✓ |
| $(3,4)$ | `0` | 反例 $\{2,1,1\},\{12,23,34\}$：第 2、3 轮都是人 1，违反"相邻不同人" |
| $(6,6)$ | `1` | $\{1,2,3,1,2,3\},\{12,25,51,12,25,516\}$（末段 `5 1 6` 长 3 结尾 6）✓ |
| $(1,1)$ | `0` | 子串长度必须 $\ge2$，$A_1=1$ 非法 |
| $(7,7)$ | `0` | 没人词库含数字 `7` |

本目录 `solution_partial.cpp` 在官方样例上输出 **`1 0 1 0 1 0 0`**，逐字一致。

## 一、骗分：这一档怎么拿

本题满分 20 个测试点，`problem.txt` 的分值表如下（照题面）：

| 测试点 | $n\le$ | $r\le$ | $\sum l\le$ | $q\le$ | 特殊性质 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| 1 | $10^3$ | $1$ | $2000$ | $10^3$ | 无 |
| 2,3 | $10$ | $5$ | $20$ | $10^2$ | ^ |
| 4,5 | $10^3$ | $10$ | $2000$ | $10^3$ | A |
| 6 | $10^5$ | $10^2$ | $2\times10^5$ | $10^5$ | ^ |
| 7,8 | $10^3$ | $10$ | $2000$ | $10^3$ | B |
| 9,10 | $10^5$ | $10^2$ | $2\times10^5$ | $10^5$ | ^ |
| 11,12 | $10^3$ | $10$ | $2000$ | $10^3$ | C |
| 13,14 | $10^5$ | $10^2$ | $2\times10^5$ | $10^5$ | ^ |
| 15~17 | $10^3$ | $10$ | $2000$ | $10^3$ | 无 |
| 18~20 | $10^5$ | $10^2$ | $2\times10^5$ | $10^5$ | ^ |

性质 A：$k=2\times10^5$；性质 B：$k\le5$；性质 C：单组内任一字符在所有词库中出现次数之和 $\le5$。

### 骗分思路 1：单轮档 $r=1$（测试点 1，最稳的一档）

$r=1$ 时"相邻不同人""往后接龙"等约束全部消失，只剩一句话：**是否存在某个词库，含一段长度 $[2,k]$、以 $1$ 开头、结尾为 $c$ 的子串**。

做法：读入时顺手记录 `canOne = { 一轮之内从 1 出发能接到的所有结尾值 }`，查询 $O(1)$ 命中。

- 实测：造 `n=10^5, sum l=2·10^5, q=10^3, 全 r=1` 的数据，**0.28 s**（含进程启动），这一档稳拿。

### 骗分思路 2：小 $n$ 小 $r$ 的精确 DFS（测试点 2,3 及性质档的小数据）

把"每轮选谁、接成什么结尾"直接**记忆化搜索**枚举：状态 `(第几轮, 当前起始值, 上一个人)`，`dfs` 里对每个"不是上一个人"的人，取其 `reach[人][起始值]`（该人以起始值开头、长度 $[2,k]$ 的子串能接到的结尾集合）逐个下探；最后一轮要求结尾 $=c$。

- 这正是"暴力但正确"的参照版：$n=10,r\le5$ 的档**实测 0.04 s** 出正确答案；
- 性质 A 的 $n\le1000,r\le10$ 小档（造 $n=1000$、词库长 20、值域 $1..10$、$q=10^3$）**实测 0.05 s** 跑完（记忆化把重复状态吃掉）；
- 关键点：`reach[i]` 只存"**以某值开头能接到哪些结尾**"，不存具体位置，建表 $O(\sum l\cdot\min(k,l))$，因此**单个超长词库 + 超大 $k$** 会让建表退化成 $O(l^2)$——这也是满档不能靠暴力硬扛的原因之一。

### 骗分思路 3：为什么大档一定拿不到

满档 $n=10^5, r=10^2, q=10^5$：DFS 每个状态都要扫一遍"所有可能的人"，状态与转移无法压进 2 s。实测把 `n=10^5, q=10^5, r≤100` 的随机数据丢进去，**20 s 后被 `timeout` 强制终止（exit 124）**——不是"感觉会超时"，是真的跑不完。这正是手册红线说的：**能跑完的小档全拿，跑不完的大档别硬凑 RE**。

### 骗分思路 4：兜底原则

本文件对任何输入都**能编译、能输出 0/1、不崩**：$r=1$ 走 $O(1)$ 分支，其余走 DFS；DFS 只在状态可达时才下探，最坏是慢而不是 RE。交一份"小档对、大档慢"的部分分版，胜过一份"看着像正解却挂掉"的。

## 二、正解（只讲思路，本目录不实现）

把游戏看成**可达性问题**：把"上一轮用了谁、当前结尾值是多少"当作状态。朴素状态 `(轮数, 值, 上一个人)` 太多；正解的要点是把"人"这一维压缩：

1. **建二分图**：一侧是"值"（$1..2\times10^5$），一侧是"人"（词库）。某人的词库里有一段 $[2,k]$ 子串从值 $x$ 接到值 $y$，就构成一条"经过这个人、从 $x$ 到 $y$"的可用转移。
2. **相邻两轮不同人**这条限制，只在"某个值只能通过**唯一**那个人继续往外接"时才真正卡人；若一个值能被 $\ge2$ 个人收尾，则上一轮用了谁都不影响下一轮。于是对每个值只需保留"能到它的结尾的人是否唯一 / 是哪个人"这一点点信息，状态得以压到 $O(\sum l)$ 级。
3. 因 $r\le100$，按**轮数分层做 BFS**：第 $t$ 层算出"接 $t$ 轮后能到达的所有值（及其收尾人信息）"，一遍预处理即可回答所有 $(r,c)$ 询问，无需逐条重搜。

复杂度做到 $O(r\cdot\sum l)$ 量级即可满分，但**建模与"唯一收尾人"的边界处理繁琐**，对初三~高中生是一次"读懂就好"的图论课，故本目录**不实现**它——它适合作为单独的图论专题，而不适合和签到贪心放在同一批教学里。

> 与 P9755 一样：**"答案/过程本身有清晰的可达性结构，但正解代价高时，先把 r=1 和可枚举的小档稳稳拿走，比空想正解更划算。"**

## 三、讲解代码（`solution_partial.cpp` 关键片段）

```cpp
// 建表：reach[i][x] = 词库 i 中以 x 开头、长度∈[2,k] 的子串能接到的结尾集合
for (int st = 0; st < l; ++st)
    for (int len = 2; len <= k && st + len <= l; ++len) {
        int a = s[st], b = s[st + len - 1];
        reach[i][a].insert(b);
        if (a == 1) canOne.insert(b);      // 第一轮从 1 出发，一轮可达的结尾
    }

// r==1 直接查 canOne；否则记忆化 DFS
bool dfs(int depth, int startVal, int lastPerson, int R, int c) {
    // key=(depth,startVal,lastPerson) 记忆化略
    for (int j = 0; j < n; ++j) {
        if (j == lastPerson) continue;                 // 相邻两轮不能同一个人
        auto f = reach[j].find(startVal);
        if (f == reach[j].end()) continue;
        for (int e : f->second)
            if (depth == R - 1) { if (e == c) return true; }   // 最后一轮：结尾须为 c
            else if (dfs(depth + 1, e, j, R, c)) return true;
    }
    return false;
}
```

第一轮以值 $1$ 起手、无上一个人（`lastPerson=-1`），故调用 `dfs(0, 1, -1, r, c)`。

## 四、易错点（每条都编译了错版跑官方样例，正解输出 `1 0 1 0 1 0 0`）

1. **忘了"相邻两轮不能同一个人"**：删掉 `if (j==lastPerson) continue`。样例第 4 问 $(3,4)$ 本该 `0`（反例正是第 2、3 轮同人），错版把它判成 `1`：
   实测输出 `1 0 1 1 1 0 0`（第 4 位错）。
2. **忘了子串长度必须 $\ge2$**：把建表循环从 `len=2` 改成 `len=1`。$(1,1)$ 本该 `0`（$A_1=1$ 非法），错版接上了；同时 $(3,4)$ 也被错误放开：
   实测输出 `1 0 1 1 1 1 0`（第 4、6 位错）。
3. **忘了第一轮必须以 $1$ 开头**：一轮分支去掉 `if (a==1)` 限制，任何值都能起手。$(1,4)$ 与 $(1,1)$ 被错误放开：
   实测输出 `1 1 1 0 1 1 0`（第 2、6 位错）。
4. **接龙结尾下标写成 `s[st+len]`（越界一位）**：正确应是 `s[st+len-1]`（子串最后一个元素）。本机把它编译后跑官方样例，输出仍是 `1 0 1 0 1 0 0`——**因为 `st+len<=l` 时读到的是内存里的相邻数据（越界访问，UB）**，样例侥幸没露馅，换一组就会乱。这类坑样例测不出来，只能靠手写对边界（本文件保留正确写法 `s[st+len-1]`）。

## 五、常见变式

| 变式 | 差异 | 备注 |
| --- | --- | --- |
| 只问"能否 $\le r$ 轮到达" | 把"恰好 $r$ 轮"改成"不超过" | 分层 BFS 累加即可 |
| 去掉"相邻不同人" | 纯子串可达，简单得多 | 本文件删一行即退化版 |
| 要求输出具体接龙方案 | 需在 DFS/BFS 里记前驱 | 空间翻倍 |
| $r$ 很大（$\le10^9$） | 逐层 BFS 失效 | 要矩阵快速幂 / 判稳态 |

## 六、一句话提炼

**"能否恰好 $r$ 轮接到 $c$"本质是带限制的可达性**：$r=1$ 时限制全消、查一张表即可；小 $n$ 小 $r$ 时用记忆化 DFS 精确枚举"每轮选谁、接到什么"；一旦 $n,r,q$ 同时上到 $10^5$，就必须把"上一轮是谁"压进分层 BFS 才够快。骗分的次序恰好和这个结构一致——**先拿约束消失的那一档（$r=1$），再拿能暴力枚举的小档，跑不完的大档宁可不碰。**
