【题目描述】
给你两个字符串 s1,s2,要求生成一个新的字符串 s3 = s1' + s2' 并且字符串 s3 的字典序尽可能小。
其中 s1' 是 s1 的非空前缀，s2' 是 s2 的非空前缀

【输入格式】
一行两个字符串 s1,s2,用空格隔开
其中字符串长度范围为 [1, 10^5]

【输出格式】
输出字典序最小字符串 s3

【输入输出样例】
输入 #1
happy birthday
输出 #1
hab

输入 #2
abc defg
输出 #2
abcd
