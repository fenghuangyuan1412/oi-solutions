## 题目大意（数字与格式逐字）

给定整系数 $a,b,c$（$a\neq 0$，$|a|,|b|,|c| \le M$），判断 $ax^2+bx+c=0$ 是否有实数解，并**按要求的格式**输出。

- 若 $\Delta = b^2 - 4ac < 0$：输出 `NO`；
- 否则 $\Delta \ge 0$，有两解（可能相等），记**较大者**为 $x$：
  - $x$ 为**有理数** ⇒ 按有理数格式输出；
  - 否则 $x$ 可唯一写成 $x = q_1 + q_2\sqrt{r}$，其中 $q_1,q_2$ 为有理数且 $q_2 > 0$；$r$ 为正整数、$r > 1$、且不存在 $d>1$ 使 $d^2 \mid r$（$r$ 无平方因子）。

**有理数格式**（题面逐字）：存在唯一整数 $p,q$ 满足 $q>0$、$\gcd(p,q)=1$、$v=p/q$；$q=1$ 时输出 `{p}`，否则输出 `{p}/{q}`；$v=0$ 时输出 `0`。

**无理数格式**（题面逐字拆成四步）：
1. 若 $q_1 \neq 0$：按有理数格式输出 $q_1$，**再输出一个加号 `+`**；否则跳过这一步；
2. 若 $q_2 = 1$：输出 `sqrt({r})`；
3. 否则若 $q_2$ 为整数：输出 `{q2}*sqrt({r})`；
4. 否则若 $q_3 = 1/q_2$ 为整数：输出 `sqrt({r})/{q3}`；
5. 否则存在唯一整数 $c,d$（$c,d>1$、$\gcd(c,d)=1$、$q_2 = c/d$）：输出 `{c}*sqrt({r})/{d}`。

并且："每行输出的字符串中间**不应包含任何空格**"。

数据范围（逐字）：$1 \le T \le 5000$，$1 \le M \le 10^3$，$|a|,|b|,|c| \le M$，$a \neq 0$。

**测试点分档表（逐字照抄）**：

| 测试点编号 | $M \le$ | 特殊性质 A | 特殊性质 B | 特殊性质 C |
| --- | --- | --- | --- | --- |
| $1$ | $1$ | 是 | 是 | 是 |
| $2$ | $20$ | 否 | 否 | 否 |
| $3$ | $10^3$ | 是 | 否 | 是 |
| $4$ | $10^3$ | 是 | 否 | 否 |
| $5$ | $10^3$ | 否 | 是 | 是 |
| $6$ | $10^3$ | 否 | 是 | 否 |
| $7, 8$ | $10^3$ | 否 | 否 | 是 |
| $9, 10$ | $10^3$ | 否 | 否 | 否 |

其中（逐字）：特殊性质 A：保证 $b = 0$；特殊性质 B：保证 $c = 0$；特殊性质 C：如果方程有解，那么方程的**两个解都是整数**。

## 骗分第四课：性质列是"能拿几分"的答案，但要会换算成数学条件

这张表里"是/否"不是装饰，它直接告诉你**哪些测试点你可以用简单代码搞定**。把三条性质翻译成关于 $\Delta$ 的话：

| 性质 | 题面 | $\Delta$ 变成 | 推论 |
| --- | --- | --- | --- |
| B：$c=0$ | $ax^2+bx=0$ | $\Delta = b^2$ | **永远是完全平方数** ⇒ 根必为有理数（$0$ 与 $-b/a$） |
| C：两根皆整数 | $r_1,r_2\in\mathbb{Z}$ | $\Delta = a^2(r_1-r_2)^2$ | **永远是完全平方数** ⇒ 走有理数分支 |
| A：$b=0$ | $ax^2+c=0$ | $\Delta = -4ac$ | ⚠️ **不一定**！$a=1,c=-2$ 时 $\Delta=8$，根 $\pm\sqrt2$ 是无理数 |

于是"只写有理数分支"的骗分版（本目录 `solution.cpp`）能稳过的测试点是：**1、3、5、6、7、8（共 6 个）**，而 4（只有 A）、2、9、10（全否）里必然混着无理根，它会输出错误格式。按洛谷 10 个测试点均分推算 ⇒ **约 60 分**（这是推算，不是提交结果，见"验证结论"）。

### 性质 A 是最值得当堂敲一遍的陷阱

学生看到 $b=0$ 通常心想"这最简单"，直接 `sqrt(-c/a)` 就写了。实测统计（`node` 跑 20 万组随机 $b=0$、$|a|,|c|\le1000$）：

| 分类 | 组数 | 占比 |
| --- | --- | --- |
| $\Delta < 0$（输出 `NO`） | 99675 | 49.8% |
| $\Delta \ge 0$ 且为完全平方数（有理根） | 495 | **0.2%** |
| $\Delta \ge 0$ 但非完全平方（**无理根**，要 `sqrt(...)` 格式） | 99830 | 49.9% |

**结论**：性质 A 的测试点里将近一半的数据是"必须输出根式格式"的 —— 以为 $b=0$ 简单，恰好在这点上丢分。课堂上一句"哪一半"比讲十分钟格式更有效。

## 思路推导（满分版：`solution_full.cpp`）

### 1. 先把"较大根"这件事钉死，尤其是 $a<0$

求根公式 $x = \dfrac{-b \pm \sqrt{\Delta}}{2a}$。**当 $a<0$ 时除以负数会翻转大小方向**，所以较大根是：

$$x = \frac{-b + \sqrt{\Delta}}{2a}\ (a>0),\qquad x = \frac{-b - \sqrt{\Delta}}{2a}\ (a<0)$$

代码里用一行同时处理两种情况，并统一把形式写成 $q_1 + q_2\sqrt r$ 且 **$q_2 > 0$**（题面要求）：

$$q_1 = \frac{-b}{2a}\ \text{（分母带符号，归一化成 } q>0\text{）},\qquad q_2 = \frac{s}{2|a|},\quad D = s^2\cdot r$$

为什么 $q_2$ 天然为正？因为 $a>0$ 时取 $+\sqrt{D}$、$a<0$ 时取 $-\sqrt{D}$，除以 $2a$（负）后正好又是 $+\dfrac{s}{2|a|}\sqrt r$。**这一步是本题唯一真正需要动脑的地方**，写错就是 $a<0$ 的测试点全灭（官方样例第 2 行 `-1 -1 -1` 就是负 $a$，只不过它是 `NO`；第 4 行 `1 5 4` 输出 `-1` 是有理分支的负数例子）。

### 2. $\Delta$ 是有理根的判据：完全平方

$\Delta\ge0$ 时，根为有理数 $\iff \sqrt{\Delta}\in\mathbb{Z}$。代码：

```cpp
long long t = (long long)(sqrt((long double)D) + 0.5L);   // 先猜整数平方根
while (t * t > D) --t;                    // 浮点可能猜大，往下修
while ((t + 1) * (t + 1) <= D) ++t;       // 可能猜小，往上修 ⇒ 保证 t = floor(sqrt(D))
if (t * t == D) { /* 有理根，用整数分数算，绝不碰浮点 */ }
```

`double` 只有 53 位有效位，$\Delta$ 到 $5\times10^6$ 时直接 `sqrt` 取整**已经可能错 1**。本仓库的做法是"猜完再修正"，两次 `while` 保证 $t = \lfloor\sqrt{\Delta}\rfloor$ 精确，之后的判定全是整数运算。有理根的输出也全程走整数分数（`__gcd` 约分），**不使用浮点**。

### 3. 无理根：把 $\Delta$ 拆成 $s^2\cdot r$

```cpp
long long s = 1, r = D;
for (long long d = 2; d * d <= r; ++d)            // r 越除越小，循环自然提前结束
    while (r % (d * d) == 0) { r /= d * d; s *= d; }
```

退出时 $r$ 必无平方因子（若有，其最小素因子平方 $\le \sqrt{r}$ 早该被除掉），满足题面 "$r>1$ 且不存在 $d^2\mid r$"。于是 $x = \dfrac{-b}{2a} + \dfrac{s}{2|a|}\sqrt{r}$，两个分数各自约分 ⇒ $q_1, q_2$。

### 4. 五种输出写法：把题面编号抄成 if-else

题面把格式写成 5 条带条件的规则，代码就写 5 个分支，**一条都不合并**（合并就容易漏）：

```cpp
if (q1n != 0) { 输出 q1（最简分数）; cout << '+'; }     // 规则①：q1=0 时整段跳过
if (q2d == 1) {
    if (q2n == 1) cout << "sqrt(" << r << ')';           // 规则②：q2 = 1
    else          cout << q2n << "*sqrt(" << r << ')';   // 规则③：q2 是整数
} else {
    if (q2n == 1) cout << "sqrt(" << r << ")/" << q2d;   // 规则④：1/q2 是整数
    else          cout << q2n << "*sqrt(" << r << ")/" << q2d;  // 规则⑤：c*sqrt(r)/d
}
```

### 5. 复杂度

$|a|,|b|,|c|\le 1000 \Rightarrow |\Delta| \le 10^6 + 4\times10^6 = 5\times10^6$。
分解 $s^2$ 的试除上限 $\sqrt r \le 2237$。$T\le5000$ ⇒ 总运算量约 $10^7$ 级别，1000ms 富余。

| `-1 -1 -1` | $1-4=-3$ | $<0$ | 无实数解 | `NO` |

| `1 0 -432` | $1728$ | 无理 | $1728=24^2\cdot3$，$q_1=0$（跳过①），$q_2=\frac{24}{2\cdot1}=12$ | `12*sqrt(3)` |
| `1 -3 1` | $5$ | 无理 | $5=1^2\cdot5$，$q_1=\frac31=3$，$q_2=\frac12$ ⇒ 规则④ | `3/2+sqrt(5)/2`？——见下注 |
| `2 -4 1` | $8$ | 无理 | $8=2^2\cdot2$，$q_1=\frac{4}{4}=1$，$q_2=\frac{2}{4}=\frac12$ ⇒ 规则④ | `1+sqrt(2)/2` |
| `1 7 1` | $45$ | 无理 | $45=3^2\cdot5$，$q_1=-\frac72$，$q_2=\frac32$ ⇒ 规则⑤ | `-7/2+3*sqrt(5)/2` |

⚠️ 第 7 行板书时容易写错：$\Delta = 9-4 = 5$，$q_1 = \frac{-(-3)}{2\cdot1} = \frac{3}{2}$，输出的是 `3/2+sqrt(5)/2`（不是 `3` 也不是 `3/2+sqrt(5)`）。**$q_1$ 是有理数、要带分母；$\sqrt$ 里只有 $r$**。这一行的正确输出（官方给出）：`3/2+sqrt(5)/2`。

## 讲解代码

两版都在本目录：`solution_full.cpp`（满分档）与 `solution.cpp`（骗分档 / 只会有理根）。

**骗分档的价值**：它只写"整数分数 + 约分"，**没有任何根式化简**，代码短、10 分钟能写完、按推算拿 60 分；无理根分支它用 `double` 四舍五入成整数蒙，注释里明确写着"这段是骗不是分"。课堂作用是让学生理解：特殊性质表能兑现成分数，但**必须换算成数学条件再判断，不能靠感觉**。

## 易错点与坑

1. **$a<0$ 时忘记翻转**：$\frac{-b+\sqrt{\Delta}}{2a}$ 在 $a<0$ 时是**较小**根。这是本题第一大坑。
2. **只输出一个根**：题面要的是"两个实数解中的**较大者**"，不是两个都输出，也不是输出较小者。
3. **$q_1 = 0$ 时不能输出 `0+sqrt(...)`**：规则①写的是"若 $q_1\neq0$ …否则跳过这一步输出"。官方样例第 6 行 `12*sqrt(3)` 前面就没有 `0+`。
4. **`NO` 与 `Yes`/`No` 之类**：本题只有 `NO` 全大写，别写 `No`/`no`；也别多输出空格（题面："字符串中间不应包含任何空格"）。
5. **用 `double` 判完全平方**：$\Delta=4999999$ 这类数用 `sqrt` 直接取整可能差 1，导致把无理根误判成有理（或反之）。必须"猜 + 双向修正"，或干脆整数二分。
6. **$r$ 没除干净**：$\Delta = 72$ 要写成 $6^2\cdot 2$（$s=6,r=2$），只提出 $2^2$ 会得到 $r=18$（含 $3^2$），违反"$d^2\nmid r$" ⇒ 格式判错。
7. **约分只约一半**：$q_2 = \frac{s}{2|a|}$ 也要 $\gcd$ 约分；题面规则⑤明确要求 $\gcd(c,d)=1$。
8. **重根**（$\Delta = 0$）：走有理分支，输出 $\frac{-b}{2a}$ 约分后的值；`4 4 1` ⇒ `-1/2` 就是这个例子。
9. **`0` 的写法**：$v=0$ 时 $p=0,q=1$ ⇒ 输出 `0`，不能输出 `0/1`，也不能输出 `-0`。
10. **把性质 A 当"简单档"**：见上文统计，$b=0$ 时约一半数据是无理根。

## 常见变式

| 变式 | 差异 | 应对 |
| --- | --- | --- |
| 要求输出**两个**根 | 多一行输出 | 两个分支都要写，注意 $a<0$ 时顺序 |
| 系数绝对值到 $10^9$ | $\Delta$ 到 $4\times10^{18}$，`long long` 边缘 | 用 `__int128` 算 $\Delta$ 与试除（本仓库 P1005 讲过 `__int128` 输出） |
| 要求 $\sqrt{}$ 保留 $k$ 位小数 | 变成浮点输出题 | `printf("%.9f")` + `double`/`long double` 够用，但要重读题面的精度承诺 |
| 判定"是否有整数解" | 只判 $\Delta$ 是否平方且整除 | 本题有理分支去掉格式部分即可 |

## 骗分阶梯：这题怎么安排时间

| 时间投入 | 写法 | 覆盖的测试点（推算） |
| --- | --- | --- |
| 10 分钟 | `solution.cpp`：`NO` + 完全平方走整数分数；无理根乱蒙 | 1、3、5、6、7、8 ⇒ **约 60 分** |
| 25 分钟 | 加上 $s^2$ 提出 + $q_1,q_2$ 约分 | 覆盖全部 $\Delta$ 分类 ⇒ **满分** |

**教学落点**：这题的 60 分不是"写了个差不多"，而是**读懂了性质列**（B、C 保证 $\Delta$ 为完全平方）换来的。会读表，骗分就变成有依据的加分；不会读表，就会在自认为最简单的性质 A 上丢一半。

## 小结

输出格式类题目（字符串、分数、根式）拼的不是算法而是**逐字对照**：题面写了几条规则，代码里就该有几个分支，注释里就该抄几行原文。而特殊性质分档表是免费的分数地图 —— 把它翻译成"哪种数据一定长什么样"，60 分就到手了。
