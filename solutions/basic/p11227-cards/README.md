## 题目大意

逐字引自 `problem.txt`：

> 小 P 从同学小 Q 那儿借来一副 $n$ 张牌的扑克牌……每张牌具有两个属性：花色和点数。花色共有 $4$ 种……点数共有 $13$ 种……注意：点数 $10$ 在本题中记为 $\tt T$。
> 我们称一副扑克牌是**完整**的，当且仅当对于每一种花色和每一种点数，都**恰好**有一张牌……小 P 想知道他至少得向小 S 借多少张牌，才能让从小 S 和小 Q 借来的牌中，可以选出 $52$ 张牌构成一副完整的扑克牌。

一句话：**手里有些牌（可能重复），要补齐成「每种牌各一张」的 52 张，最少再借几张。**

样例 2 手算（`n=4`：`DQ H3 DQ DT`）：

| 手里的牌 | 是不是新牌种 | 不同牌种累计 |
| --- | --- | --- |
| `DQ` | 新 | 1 |
| `H3` | 新 | 2 |
| `DQ` | **重复**，不加 | 2 |
| `DT` | 新 | 3 |

已出现 3 种不同牌，缺 $52-3=49$ 种，每种补 1 张 ⇒ **输出 49**（与题面样例一致）。

## 一、骗分：这一档怎么拿

本题数据范围表（逐字取自 `problem.txt`，`^` = 同上）：

| 测试点编号 | $n \le$ | 特殊性质 |
| :---: | :---: | :---: |
| $1$ | $1$ | A |
| $2\sim 4$ | $52$ | ^ |
| $5\sim 7$ | ^ | B |
| $8\sim 10$ | ^ | 无 |

- **特殊性质 A：保证输入的 $n$ 张牌两两不同。**
- 特殊性质 B：保证所有牌按照点数从小到大依次输入，点数相同时按照方片、草花、红桃、黑桃的顺序依次输入。

### 骗分思路 1：押「性质 A —— 两两不同」，直接 `52 − n`

若所有牌两两不同，那么「不同牌种数」就等于牌数 $n$，答案直接是 $52-n$，**连牌面都不用看**：

```cpp
int n; cin >> n; string s;
for (int i = 0; i < n; ++i) cin >> s;   // 读掉，不用
cout << 52 - n << "\n";
```

- **能拿分**：测试点 1（$n\le1$，性质 A）+ 测试点 2~4（性质 A）= **4 个点 ≈ 40 分**。
- **拿不满的原因**：点 5~7（性质 B）与 8~10（无性质）里**允许重复牌**，$52-n$ 会把答案算小。
- **实测证据**（本机 `solution_partial.exe`）：样例 2（含重复的 `DQ`）实测输出 **48**，正解是 49；把「52 张全是 `SA`」喂进去，实测输出 **0**，正解是 51。两处都错，正好卡在「有重复就翻车」。

### 骗分思路 2：其实去重就两三行，别停在骗分

这题正解比骗分代码长不了几行，考场里**直接上去重更划算**。押性质 A 的价值在于演示 CSP-J 常见的第一档送分逻辑——「读特殊性质 → 找最省事的等价式」。

## 二、正解：答案只看「出现过几种不同的牌」

### 关键观察

借来的牌**想要哪种就有一种**，于是手里同一牌种有几张毫无意义（完整牌每种只要一张）。把所有牌按牌种去重后：

> 还缺的张数 = $52 - (\text{手里出现过的不同牌种数})$。

### 算法设计

1. 开 `bool seen[4][13]`，全置 `false`；
2. 每读一张牌，把 `(花色, 点数)` 映射成下标 `(a,b)`，令 `seen[a][b] = true`（重复置 true 不改变结果）；
3. 数一共有多少个 `true`，记作 `cnt`；输出 `52 - cnt`。

### 正确性

`seen` 中为 `true` 的格子与「手里出现过的牌种」**一一对应**，所以 `cnt` 就是不同牌种数。完整牌恰有 52 种，凡 `seen` 里没有的种，手里一张都没有、**必须各借 1 张**；凡有的种借 0 张即可。故最少借 $52-\text{cnt}$ 张，且这个数不能更小。$\blacksquare$

### 复杂度

一趟读入 $O(n)$（$n\le52$），数格子固定 $4\times13=52$ 次，均视为 $O(1)$；空间一张 `bool[4][13]`。$n=52$ 实测约 5 ms（几乎全是进程启动）。

## 三、板书演示：`bool seen[4][13]` 逐步点亮

样例 2（`DQ H3 DQ DT`），花色 `D=0,C=1,H=2,S=3`，点数 `A=0 … 9=8 T=9 J=10 Q=11 K=12`：

| 读入 | (花色,点数) | 点亮格子 | 之前是否已亮 | `cnt` |
| --- | --- | --- | --- | --- |
| `DQ` | (0,11) | `seen[0][11]=true` | 否 | 1 |
| `H3` | (2,2) | `seen[2][2]=true` | 否 | 2 |
| `DQ` | (0,11) | `seen[0][11]` 本已 true | **是，跳过** | 2 |
| `DT` | (0,9) | `seen[0][9]=true` | 否 | 3 |

输出 $52 - 3 = \mathbf{49}$。第 3 行的「跳过」正是重复牌不加分的体现。

## 四、讲解代码

### 正解（`solution.cpp`）核心

```cpp
string ranks = "A23456789TJQK";              // 点数表，T 代表 10，占一个下标
int suitId[256]; suitId['D']=0; suitId['C']=1; suitId['H']=2; suitId['S']=3;
bool seen[4][13] = {};
for (int i = 0; i < n; ++i) {
    string s; cin >> s;                        // 长度 2：s[0] 花色、s[1] 点数
    seen[suitId[(int)s[0]]][(int)ranks.find(s[1])] = true;   // 重复置 true 无影响
}
int cnt = 0;
for (int a = 0; a < 4; ++a) for (int b = 0; b < 13; ++b) if (seen[a][b]) ++cnt;
cout << 52 - cnt << "\n";
```

### 骗分版（`solution_partial.cpp`）

```cpp
int n; cin >> n; string s;
for (int i = 0; i < n; ++i) cin >> s;
cout << 52 - n << "\n";                        // 赌「两两不同」：不同数 = n
```

**差别就一句话**：正解用 `seen[4][13]` 把重复牌压掉，得到「不同牌种数」；骗分版把「不同牌种数」直接当成 $n$，只在性质 A 成立时才对。

## 五、易错点与坑（每条都附本机实测输出）

1. **把点数当整数读**。有人写 `char c; int num; cin >> c >> num;`——可 `10` 记为 `T`，`A/J/Q/K` 也都不是数字，**第一次抽取就失败**，后面全不读。实测样例 2 输出 **51**（正解 49）。正确做法：把整张牌当**长度为 2 的字符串**读，用 `"A23456789TJQK".find(s[1])` 求点数下标。
2. **去重只看花色、漏掉点数维度**（把 `seen[4][13]` 写成 `seen[4]`）。同一花色不同点数被并成一种。实测样例 2 输出 **50**（正解 49）。
3. **押「两两不同」不做去重**，即 `52 - n`。实测样例 2 输出 **48**（正解 49）、52 张全 `SA` 输出 **0**（正解 51）——这就是本目录 `solution_partial.exe`。
4. **输出手里已有的张数 `cnt`，忘记套 `52 -`**。实测样例 1 输出 **1**（正解 51）、样例 2 输出 **3**（正解 49）。
5. **花色映射漏写一种**（如忘记 `'C'`）会让 `'C'` 落到未初始化的下标上，轻则撞格、重则越界。本解用 `suitId[256]` 显式把 `D C H S` 映射到 `0 1 2 3`，四种都要写上。

## 六、常见变式

| 变式 | 差异 | 备注 |
| --- | --- | --- |
| 判断「手里是不是已经是完整一副」 | 只需 `cnt == 52` | 去掉减法 |
| 每种牌允许凑 $k$ 张（多副） | `bool` 换成 `int seen[4][13]` 计数 | 答案是「不足 $k$ 的种各补差额」 |
| 借牌也有张数上限 | 变成能否凑齐的判定 | 需要特判 |
| 只数某一花色的缺牌 | 循环维度砍一半 | 一行改动 |

## 七、一句话提炼

**重复不加分，缺种才要补**——答案只等于 $52$ 减去「手里出现过的不同牌种数」；所以拿一张 `bool seen[4][13]` 把牌面点亮、数亮格，就是这道题的全部正解，而押「两两不同」输出 `52-n` 只能兜住性质 A 的约 40 分。
