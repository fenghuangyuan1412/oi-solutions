## 题目大意

$2N$ 名选手，每人有初始分数 $s$ 和实力值 $w$（$w$ 两两不同）。进行 $R$ 轮比赛：

- 每轮开始前按**总分从高到低**排名，**总分相同则编号小的靠前**（题面逐字："总分相同的，约定编号较小的选手排名靠前"）；
- 第 1 名和第 2 名、第 3 名和第 4 名、…、第 $2K-1$ 名和第 $2K$ 名各赛一场；
- 胜者总分 $+1$，负者不变；

所有 $R$ 轮结束后再排一次名，输出排名第 $Q$ 的选手编号。

数据范围（逐字）：

- 对于 $30\%$ 的数据，$1 \le N \le 100$；
- 对于 $50\%$ 的数据，$1 \le N \le 10000$；
- 对于 $100\%$ 的数据，$1 \le N \le 10^5$，$1 \le R \le 50$，$1 \le Q \le 2N$，$0 \le s \le 10^8$，$1 \le w \le 10^8$。

## 骗分第一课：先读分档表，再决定写什么

| 档位 | 条件 | 暴力 $O(RN\log N)$ 够不够 | 结论 |
| --- | --- | --- | --- |
| 30% | $N \le 100$ | $50 \times 200 \times 8 \approx 10^5$ | 秒过 |
| 50% | $N \le 10^4$ | $50 \times 2\times10^4 \times 15 \approx 1.5\times10^7$ | 秒过 |
| 100% | $N \le 10^5, R \le 50$ | $50 \times 2\times10^5 \times 18 \approx 1.8\times10^8$ 次比较 | **边缘**，取决于评测机 |

`sort` 的常数很小，$1.8 \times 10^8$ 次比较在现代 CPU 上是"半秒级"。**本机实测这份暴力用了 0.43~0.50 s**（三轮各三次，见验证结论），所以它在这台机器上不会被时限卡死；但考场的评测机通常更慢、时限更硬，"暴力刚好压线"是最不可靠的状态 —— 这正是"能写正解就别赌暴力"的理由，也是"写不出正解时暴力仍有 50 分以上保底"的理由。

**两个方向都要教给学生**：暴力不是耻辱（它有保底分），但暴力不能当终点（$10^8$ 级别的操作量在考场上就等于是赌运气）。

## 思路推导

### 1. 暴力写法（`solution.cpp`）

把选手存进结构体数组，每轮：先 `sort` 排名 → 相邻两两比 $w$ 加分 → 下一轮再 `sort`。最后输出 `p[Q].id`。逻辑与题面一一对应，几乎不需要思考，这就是它的价值。

### 2. 关键观察：本轮的胜者队列**天生有序**

正解只需要一个观察：**排名靠前者分数不低于排名靠后者**（分数降序、同分编号升序）。

把每轮的胜者按"他们在上一轮名次里出现的顺序"收集，得到队列 `win`，负者同样得到 `lose`：

- **分数单调**：第 $i$ 对的胜者来自位置 $2i-1$ 或 $2i$，第 $i+1$ 对的胜者来自 $2i+1$ 或 $2i+2$。上一轮序里 $s_{2i} \ge s_{2i+1}$，两边都 $+1$（或都不 $+1$）后仍满足 $s'_{\text{win}_i} \ge s'_{\text{win}_{i+1}}$；
- **同分时的编号也单调**：若两个胜者同分，说明他们来自 $s$ 相同的相邻两对，而上一轮里同分者按编号升序排列，靠前一对的胜者编号必然更小（他的原始位置 $\le 2i < 2i+1 \le$ 后一对胜者的原始位置）；
- **负者队列同理**（负者没加分，不等式方向不变）。

两条队列各自有序 ⇒ **一次归并**就得到本轮结束后的新序，$O(N)$。总复杂度 $O(RN) = 50 \times 2\times10^5 = 10^7$。

### 3. 算法设计

```
初始按 (分数降序, 编号升序) 排一次
重复 R 次：
    顺序扫描相邻对 (1,2), (3,4), ...
        胜者 +1 后压入 win，负者原分压入 lose        // 两个队列自动有序
    win 与 lose 归并回 a[]                           // 比较规则与 sort 用的 cmp 完全一致
输出 a[Q].id
```

### 4. 正确性说明

- **归并与 sort 等价**：`win ∪ lose` 就是全体选手，且各自内部已按 `(s 降, id 升)` 有序；归并保持这个序，结果与全排序相同（排序结果的唯一性由比较规则的全序性质保证：分数不同比分数，分数不同不可能，则比编号，编号两两不同）。
- **队列有序性的证明**在上面第 2 节，关键在于"同一对内部胜者名次不劣于负者"以及"跨对时原始名次单调"。
- **边界**：$R$ 轮结束后还要不要再排一次？题面说"每轮比赛开始前，以及所有比赛结束后，都会进行一次排名"。本实现里每轮开头就已经是排好序的数组，最后一轮结束时 `a[]` 也是排好序的（归并的产物），所以直接取 `a[Q]` 即可。

### 5. 复杂度分析

| 版本 | 时间 | 空间 |
| --- | --- | --- |
| 暴力 `solution.cpp` | $O(RN\log N)$，$1.8\times10^8$ 次比较 | $O(N)$ |
| 归并 `solution_full.cpp` | $O(RN + N\log N)$，初始排序主导 | $O(N)$ |

## 讲解代码

两版都在本目录：`solution.cpp`（每轮 `sort`）与 `solution_full.cpp`（归并）。正解的核心 12 行：

```cpp
for (int round = 1; round <= r; round++) {
    int nw = 0, nl = 0;
    for (int i = 1; i <= 2 * n; i += 2) {
        if (a[i].w > a[i+1].w) { a[i].s += 1;   win[++nw] = a[i];   lose[++nl] = a[i+1]; }
        else                   { a[i+1].s += 1; win[++nw] = a[i+1]; lose[++nl] = a[i];   }
    }
    int i = 1, j = 1, k = 0;                       // 归并两条有序队列
    while (i <= nw && j <= nl)
        a[++k] = cmp(win[i], lose[j]) ? win[i++] : lose[j++];
    while (i <= nw) a[++k] = win[i++];
    while (j <= nl) a[++k] = lose[j++];
}
```

## 验证结论

本机 `g++ -static -O2 -std=c++14` 编译**无警告**，实测：

| 检验项 | 结果 |
| --- | --- |
| 官方样例 `2 4 2 / 7 6 6 7 / 10 5 20 15` | 两版都输出 `1` ✅ |
| 随机对拍 1500 组（$N \le 10$，$R \le 10$，初始分只在 $0..10$ 里取 ⇒ 大量同分） | 暴力 vs 归并 **0** 组不一致；暴力 vs 独立的 JS 全模拟参照 **0** 组不一致 |
| 极限数据 $N = 10^5$（$2N = 2\times10^5$）、$R = 50$，初始分 $0..100$，同一份随机数据各跑三遍 | 三轮实测：暴力 `477 / 501 / 493` ms、`481 / 472 / 465` ms、`425 / 428 / 425` ms；归并 `153 / 151 / 152` ms、`149 / 151 / 150` ms、`133 / 128 / 131` ms。**两版每次输出同一个数**（第三轮是 `91018`；数据每轮重新随机生成，数字会变，"两版相同"才是结论） |

（计时随机器负载有 ±10% 波动，量级稳定：**暴力约 0.43~0.50 s，归并约 0.13~0.15 s，差约 3.1~3.3 倍**。最后一轮 425 / 133 ms 是紧跟着跑完 P1005 的同一批后台任务里测的，机器已经热了，所以整体偏低。）

**洛谷提交结果未获取，因此两版都不下 AC 结论。**暴力在**本机**约 0.4~0.5 s 跑完 $1.8\times10^8$ 量级比较，没有超时，这恰好说明"暴力能拿多少分必须靠提交才知道，不能靠估"；归并版本比暴力快约 3.1~3.3 倍，是考场上更稳的选择。

## 易错点与坑

- **同分排序漏了编号**：只按分数排序，`sort` 对相等元素的顺序不确定，同分档位的测试点会随机错。`cmp` 必须写成"分数降序，分数相同则编号升序"。
- **`cmp` 传引用 vs 传值**：这里结构体很小，传值反而快；关键是 `cmp` 必须是**严格弱序**（不能写成 `x.s >= y.s`，那会让 `sort` 未定义行为）。
- **实力值只用于 pairwise 比较**：不要拿实力值参与排序。
- **数组开小**：$2N$ 可达 $2\times10^5$，`win/lose` 也要同样大小；写成 `N` 会越界。
- **以为"胜者队列有序"就只输出 win**：归并是两条队列一起，漏掉 lose 直接少了一半人。

## 常见变式

| 变式 | 差异 | 应对 |
| --- | --- | --- |
| 允许实力值相同 | 同对战无胜者？需题面额外规定 | 题面保证 $w$ 互不相同，去掉就要重新设计 |
| 求 $k$ 轮后前 $Q$ 名 | 多次查询 | 归并版天然是全序，直接答 |
| 每轮随机配对 | 不再是相邻对 | 归并性质不成立，必须每轮重排 |

## 小结

"暴力 = 部分分"不是安慰话，而是**可算的账**：把分档表里的 $N, R$ 代入 $O(RN\log N)$，能跑完的档位就是能拿的分；跑不完的那一档，正解往往只差一个"我早就知道它有序"的观察。
