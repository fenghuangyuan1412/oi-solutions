## 题目大意

题面只有一句话（逐字）：**"有一个 $n \times m$ 方格的棋盘，求其方格包含多少正方形、长方形（不包含正方形）。"**

数据范围（逐字）：一行两个正整数 $n, m$（$n \le 5000, m \le 5000$）。输出两个整数：正方形个数、长方形（不含正方形）个数。

## 思路推导

### 1. 暴力想法：枚举四个坐标

一个子矩形由"上下两条横线 + 左右两条竖线"唯一确定，直接枚举四个边界：

$$O(n^2 m^2) = (5000^2)^2 = 6.25 \times 10^{14}$$

**这个规模必然超时**，是本题最好的"数据范围反推复杂度"教材：看到 $n, m \le 5000$，就该立刻想到允许的复杂度大约是 $10^7 \sim 10^8$，也就是 $O(nm)$ 级别。

### 2. 关键观察：按"尺寸"分类计数

设子矩形的**高 $h$、宽 $w$**（$1 \le h \le n$，$1 \le w \le m$）。这种尺寸的子矩形能放多少种？只要选左上角：

- 左上角行号可以取 $1 \dots n-h+1$，共 $n-h+1$ 种；
- 左上角列号可以取 $1 \dots m-w+1$，共 $m-w+1$ 种。

所以 **尺寸 $h \times w$ 的子矩形共有 $(n-h+1)(m-w+1)$ 个**，且不同尺寸之间不重不漏。于是：

$$\text{正方形} = \sum_{k=1}^{\min(n,m)} (n-k+1)(m-k+1), \qquad \text{长方形} = \Big(\sum_{h,w}(n-h+1)(m-w+1)\Big) - \text{正方形}$$

枚举 $h, w$ 是 $O(nm)$，$2.5 \times 10^7$ 次，一次乘法一次加法，稳过。

### 3. 更省的做法（顺带讲原理）

四个边界独立选取，所以**矩形总数（含正方形）**有闭式：

$$\text{total} = \binom{n+1}{2}\binom{m+1}{2} = \frac{n(n+1)}{2} \cdot \frac{m(m+1)}{2}$$

正方形部分对 $k$ 求和展开成 $\sum_k (n+1-k)(m+1-k)$，用 $\sum k = \frac{s(s+1)}{2}$、$\sum k^2 = \frac{s(s+1)(2s+1)}{6}$（$s = \min(n,m)$）就能 $O(1)$ 算完。本仓库的 `verify.js` 用这份闭式（`BigInt` 精确整数）作为对拍参照。

### 4. 正确性说明

- **不重**：每个子矩形有唯一的 $(h, w)$；
- **不漏**：任何子矩形的高和宽都在 $[1,n] \times [1,m]$ 内，被枚举覆盖；
- **左上角计数**：高 $h$ 的矩形其顶边可以落在第 $1 \dots n-h+1$ 行，超出就会越界，因此 $(n-h+1)$ 是精确计数；
- **正方形与长方形互斥**：判定条件 $h = w$ 把总集合切成两半，题面"长方形（不包含正方形）"正是取差集。

### 5. 复杂度分析

时间 $O(nm)$，$n = m = 5000$ 时 $2.5 \times 10^7$ 次循环（本机实测 17~19 ms，重复运行；首次冷启动 122 ms 是进程与安全软件开销）；空间 $O(1)$。闭式做法是 $O(1)$。

## 板书演示（不用可视化）

官方样例 $n=2, m=3$（$2$ 行 $3$ 列）：

| 尺寸 $h \times w$ | $(n-h+1)(m-w+1)$ | 个数 | 是否正方形 |
| --- | --- | --- | --- |
| $1\times1$ | $2 \times 3$ | 6 | 是 |
| $1\times2$ | $2 \times 2$ | 4 | 否 |
| $1\times3$ | $2 \times 1$ | 2 | 否 |
| $2\times1$ | $1 \times 3$ | 3 | 否 |
| $2\times2$ | $1 \times 2$ | 2 | 是 |
| $2\times3$ | $1 \times 1$ | 1 | 否 |

合计 $6+4+2+3+2+1 = 18$ 个矩形；正方形 $6+2 = 8$，长方形 $18-8 = 10$ → 输出 `8 10` ✅。

闭式核对：$\binom{3}{2}\binom{4}{2} = 3 \times 6 = 18$ ✓ 与逐项相加一致。

极限 $n = m = 5000$：本机程序输出 `41679167500 156270827082500`，闭式（`BigInt`）独立算得同一对数 —— 正方形数也等于 $\sum_{j=1}^{5000} j^2 = \frac{5000 \cdot 5001 \cdot 10001}{6} = 41679167500$ ✓。

## 讲解代码

完整带注释版本见 `solution.cpp`。核心：

```cpp
long long sq = 0, rect = 0;
for (long long h = 1; h <= n; h++)
    for (long long w = 1; w <= m; w++) {
        long long cnt = (n - h + 1) * (m - w + 1);
        if (w == h) sq += cnt; else rect += cnt;
    }
cout << sq << ' ' << rect << '\n';
```

## 易错点与坑

- **`int` 溢出（本题最大的坑）**：$n = m = 5000$ 时总数 $\approx 1.56 \times 10^{14}$，`int` 上限 $2.1 \times 10^9$，`long long` 必须用。而且 `(n-h+1)*(m-w+1)` 单次就达 $2.5 \times 10^7$（这个还安全），危险在**累加**。
- **变量类型只升级一半**：`int n, m;` 配 `long long cnt` —— 乘法仍按 `int` 算再转 `long long`，照样溢出。要么把 $n, m$ 声明成 `long long`，要么强转。
- **输出顺序**：题面先正方形后长方形，写反就是 WA。
- **把"长方形"理解成含正方形**：题面括号里明确"不包含正方形"。
- **枚举四个坐标**：$O(n^2m^2)$，思路对但规模错，属于"会做但拿不到分"。

## 常见变式

| 变式 | 差异 | 应对 |
| --- | --- | --- |
| 只求正方形个数 | 少一半工作 | $O(1)$ 闭式 $\sum_k (n-k+1)(m-k+1)$ |
| 求"至少含一个涂色格"的子矩形 | 需要补集 + 前缀和 | 反过来数不含涂色格的，再总减 |
| $n, m \le 10^9$ | $O(nm)$ 不够 | 必须用闭式，且注意 $\sim 10^{36}$ 需要高精度 |

## 小结

计数型模拟题的通用套路：**先按"尺寸/形态"分类，再乘上"能放几种位置"**，把 $O(n^2m^2)$ 压成 $O(nm)$；做完一定要拿最大值估算答案规模，决定要不要 `long long`。
