## 题目大意

$n$ 行 $m$ 列的雷区，`*` 是雷格，`?` 是空白格。要求输出整个雷区：雷格仍输出 `*`，空白格输出**它周围 8 格里的雷数**。

题面原话：**"一个格子的周围格子包括其上、下、左、右、左上、右上、左下、右下八个方向上与之直接相邻的格子。"** —— 是 8 个方向，不是 4 个。

数据范围（逐字）：对于 100% 的数据，$1 \le n \le 100$，$1 \le m \le 100$。

## 思路推导

### 1. 暴力就是正解

这题没有"更聪明的做法"必要：$100 \times 100 = 10^4$ 个格子，每个格子数 8 次邻居，总共 $8 \times 10^4$ 次操作，就算用 $O(nm \cdot 8)$ 的朴素写法也是瞬间完成。**这是"暴力模拟"最理想的教学样本：规模小、规则明确、边界情况才是考点。**

### 2. 关键观察：把 8 个方向写成两个偏移数组

手写 8 个 `if`（上、下、左、右、四个对角）既冗长又容易漏一个。标准做法：

```cpp
const int dx[8] = {-1, -1, 0, 1, 1, 1, 0, -1};
const int dy[8] = { 0,  1, 1, 1, 0,-1,-1, -1};
```

于是"数雷"变成一个 `for (d = 0..7)` 循环，越界检查也只需一行。

### 3. 算法设计

1. 按行读入字符串（**字符之间没有空格**，所以用 `cin >> grid[i]` 整行读，不能逐个 `cin >> char` 却期待跳过分隔符的差异）；
2. 逐格处理：`*` 直接输出 `*`；`?` 则枚举 8 个偏移，累计合法范围内的 `*` 个数，输出这个数字；
3. 每输出完一行打一个换行，行内**不加分隔符**（题面："相邻字符之间无分隔符"）。

### 4. 正确性说明

对任意非雷格 $(i,j)$，程序统计的集合恰是 $\{(i+dx[d],\,j+dy[d]) : d \in [0,8),\ 0 \le i+dx < n,\ 0 \le j+dy < m\}$ 中值为 `*` 的元素个数。$dx,dy$ 的 8 组取值两两不同且覆盖 $\{-1,0,1\}^2 \setminus \{(0,0)\}$，正是题面定义的"周围格子"；越界筛除保证只统计真实存在的格子。雷格分支跳过计数、原样输出 `*`，与输出格式要求一致。

### 5. 复杂度分析

$O(8nm)$ 时间、$O(nm)$ 空间，$n,m \le 100$ 时不超过 $10^5$ 次操作。

## 讲解代码

完整带注释版本见 `solution.cpp`。核心：

```cpp
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++) {
        if (grid[i][j] == '*') { cout << '*'; continue; }   // 雷格不数，原样输出
        int cnt = 0;
        for (int d = 0; d < 8; d++) {
            int x = i + dx[d], y = j + dy[d];
            if (x >= 0 && x < n && y >= 0 && y < m && grid[x][y] == '*') cnt++;
        }
        cout << cnt;
    }
```

## 易错点与坑

- **只数 4 个方向**：漏掉对角线，答案全部偏小。题面把 8 个方向写得很清楚。
- **忘了越界判断**：角上/边上的格子会读到数组外，可能 WA 也可能"看起来对"（读到零初始化的相邻内存），后者最危险。
- **雷格输出成数字**：`*` 的位置必须原样输出 `*`。
- **行内加了空格**：题面要求无分隔符，输出 `1 0` 和 `10` 是不同的。
- **`dx`/`dy` 手写成 8 个 `if`**：容易漏一项且难检查，用偏移数组更安全。
- **用 `gets`/`getline` 混着读**：先 `cin >> n >> m` 再 `getline` 会读到一个空行，必须整行读完换行才生效。用 `cin >> grid[i]` 最省事。

## 常见变式

| 变式 | 差异 | 应对 |
| --- | --- | --- |
| 输出到边界外一格（雷区外圈补 0） | 需要 $n+2$ 行 $m+2$ 列的"哨兵"数组 | 把数组开大一圈，从 1 开始用，省掉越界判断 |
| 统计"数字恰好为 $k$ 的格子数" | 只需计数不需输出 | 同上，累加一个答案变量 |
| 雷区 $2000 \times 2000$ | $O(8nm)$ 仍然够 | 无需改变，只是注意别用 `vector<vector<char>>` 频繁分配 |

## 小结

小规模模拟题的正确姿势是"暴力照抄规则"：把方向写成偏移数组、把越界判断集中成一行，剩下的是逐字对齐输出格式。
