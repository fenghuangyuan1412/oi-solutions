## 题目大意

第一象限里依次铺 $n$ 张矩形地毯，编号 $1 \sim n$，**后铺的压在先铺的上面**。第 $i$ 张给出左下角坐标 $(a, b)$ 和沿 $x$ 轴、$y$ 轴的长度 $g, k$。问点 $(x, y)$ 上**最上面**那张地毯的编号，没被覆盖输出 `-1`。

题面原话里有一句决定实现的细节：**"在矩形地毯边界和四个顶点上的点也算被地毯覆盖"** —— 所以判定用的是闭区间，等号必须取。

数据范围（逐字）：

- 对于 $30\%$ 的数据，有 $n \le 2$；
- 对于 $50\%$ 的数据，$0 \le a, b, g, k \le 100$；
- 对于 $100\%$ 的数据，有 $0 \le n \le 10^4$，$0 \le a, b, g, k \le 10^5$。

注意 $n$ 可以是 $0$，坐标可以到 $10^5$。

## 思路推导

### 1. 最直觉的暴力：真的去铺

开一个二维数组 `grid[X][Y]`，第 $i$ 张地毯铺上去时，把它覆盖的每个格子都写成 $i$，最后直接读 `grid[x][y]`。

想法完全正确，$n \le 2$ 那一档（$30\%$ 分）甚至能过。**但它死在数组大小上**：坐标上限 $10^5$，网格就是 $10^5 \times 10^5$ 个格子，按 `int` 存是 $4 \times 10^{10}$ 字节 ≈ **40 GB**，编译不报错、一运行就 MLE/RE。

这就是"暴力模拟"的第一课：**先算内存和时间的账，再决定能不能这么写**。

### 2. 关键观察：只要"最后一层"，就不要涂满整张图

题目问的只有一个点 $(x,y)$。要判断地毯 $i$ 是否盖住它，只需要四个不等式：

$$a_i \le x \le a_i + g_i \quad \text{且} \quad b_i \le y \le b_i + k_i$$

而"最上面" = 编号最大 = **最后铺的那张**。所以：

> 从 $i = n$ 倒着往 $1$ 枚举，第一个满足包含关系的 $i$ 就是答案，立刻 `break`。

顺序为什么重要？如果正着枚举 $1 \to n$，找到的是**最底下**那张，除非继续枚举到底并不断覆盖 `ans`，否则结果错。倒序 + `break` 一次到位，而且平均更快。

### 3. 算法设计

1. 读 $n$，把 $n$ 张地毯的四元组原样存进数组（**不能边读边判断**，因为查询点在最后才给）；
2. 读 $x, y$；
3. `for (int i = n; i >= 1; i--)`，第一个罩住 $(x,y)$ 的 $i$ 写进 `ans` 并 `break`；
4. 输出 `ans`，初值 $-1$ 天然处理"没被覆盖"。

### 4. 正确性说明

- **存在性**：若点被若干张地毯覆盖，设覆盖它的编号集合为 $S$，答案 $\max S$。倒序枚举第一次命中时的 $i$ 满足 $i \in S$ 且所有 $j > i$ 都不在 $S$ 中，故 $i = \max S$。
- **包含判定**：地毯 $i$ 覆盖的是 $[a_i, a_i+g_i] \times [b_i, b_i+k_i]$ 这个闭矩形（题面保证边界和顶点算覆盖），四个不等式恰好是该点属于此矩形的充要条件。
- **$n = 0$**：循环一次都不执行，`ans` 保持 $-1$，与"没有任何地毯"一致。

### 5. 复杂度分析

时间 $O(n)$，$n \le 10^4$ ⇒ 最多 $10^4$ 次四条件判断，微秒级。空间 $O(n)$，四个 `int` 数组共 $4 \times 10^4 \times 4\,\text{B} = 160\,\text{KB}$。

## 板书演示（不用可视化）

以官方样例 1 为例，$n = 3$，查询点 $(2,2)$：

| 地毯 | 左下角 | 长 $g$ | 长 $k$ | 覆盖矩形 | 罩住 $(2,2)$? |
| --- | --- | --- | --- | --- | --- |
| 1 | $(1,0)$ | 2 | 3 | $[1,3] \times [0,3]$ | 是 |
| 2 | $(0,2)$ | 3 | 3 | $[0,3] \times [2,5]$ | 是 |
| 3 | $(2,1)$ | 3 | 3 | $[2,5] \times [1,4]$ | 是 |

倒序枚举：先查 3 号 → 命中 → 输出 `3`。三张都罩住该点，答案就是编号最大的 3。

样例 2 把查询点换成 $(4,5)$：3 号 $[2,5]\times[1,4]$ 里 $y=5 > 4$ 不命中；2 号 $[0,3]\times[2,5]$ 里 $x=4 > 3$ 不命中；1 号 $[1,3]\times[0,3]$ 里 $x=4 > 3$ 不命中 → `ans` 保持 $-1$，输出 `-1`。

## 讲解代码

完整带注释版本见 `solution.cpp`。核心 6 行：

```cpp
int ans = -1;
for (int i = n; i >= 1; i--) {                        // 倒序：先碰到最上面的
    if (a[i] <= x && x <= a[i] + g[i] &&
        b[i] <= y && y <= b[i] + k[i]) {              // 闭区间，等号必须有
        ans = i;
        break;                                        // 第一个命中就是答案
    }
}
cout << ans << '\n';
```

| 检验项 | 结果 |
| --- | --- |
| 官方样例 1（`3` 组数据 + 查询 `2 2`） | 输出 `3` ✅ |

## 易错点与坑

- **忘了 `break`**：倒序找到之后继续往前扫，`ans` 会被更底下的地毯覆盖，答案变成最小编号那张。
- **区间写成开区间**：`a[i] < x` 会把边界点判成没覆盖，恰好卡在边界的测试点全 WA。
- **正序枚举当成倒序**：正着扫并取"最后一个命中"也是对的，但必须真的扫完；不少同学正序扫却写了 `break`，拿到最底层。
- **$n$ 可以为 $0$**：如果代码假设至少一张地毯（比如先读一张再循环）就会错位。
- **别去涂网格**：坐标 $10^5$ 这一档数据就是专门惩罚二维数组打表的。

## 常见变式

| 变式 | 差异 | 应对 |
| --- | --- | --- |
| 询问 $Q$ 个点 | 每个点都倒序扫一遍是 $O(nQ)$ | $Q$ 大时需要线段树/扫描线，本题只问一个点 |
| 后铺的在下面 | "最上面"变成最小编号 | 改成正序枚举 + `break` |
| 求被覆盖面积 | 单个点判定不够用 | 需要离散化 + 差分/扫描线 |

## 小结

只问"某一个点的最上层"时，不要模拟整个覆盖过程：把"最上面"翻译成"编号最大的覆盖者"，倒序枚举加 `break`，$O(n)$ 收工；坐标范围很大本身就是"不许开网格"的暗示。
