## 题目大意

给一个全是大写字母的字符串 $S$（$1 \le |S| \le 10^4$），数出里面有多少种字符为 `"AC"` 的**组合**。

- 输入：一行字符串 $S$
- 输出：组合数
- 样例：`ACCA` → `2`；`CA` → `0`；`CAAC` → `2`

**"组合"到底指什么？** 题面用两个例子把它定义清楚了，读题时必须把这两句翻成数学语言：

> 例如字符串 `ACCA` 有两种，其下标分别是 **1,2** 和 **1,3**。
> 注意：A 的下标在 C 的前面，倒过来的 `CA` 组合并不计数。

也就是：

$$\#\{(i, j) \mid 1 \le i < j \le |S|,\ S_i = \texttt{'A'},\ S_j = \texttt{'C'}\}$$

三个要点，每个都对应一个样例：

1. **不要求相邻** —— `ACCA` 的 `(1,3)` 中间隔着一个 `C`，照样算。所以这**不是**数子串 `"AC"`。
2. **顺序有向** —— `CA` 答案是 `0`。左边必须是 A。
3. **一个字符可以参与多对** —— `CAAC` 答案是 `2`，两对是 `(2,4)` 和 `(3,4)`，第 4 位那个 `C` **被用了两次**。

> 第 3 点是本题唯一的思维门槛：计数时我们数的是"**配对**"，不是"字符"，同一个字符出现在多对里完全合法。想通这一点，一遍扫描就自然出来了。

## 思路推导

### 1. 暴力想法与它的瓶颈

按定义直接翻译：外层枚举 $i$，内层枚举 $j>i$，检查 $S_i=\texttt{A}$ 且 $S_j=\texttt{C}$ 就 `ans++`。

$$\text{操作数} \approx \frac{n^2}{2} = \frac{10^8}{2} = 5\times10^7$$

$|S| = 10^4$ 时是 $5\times10^7$ 量级，C++ 勉强能过（1 秒左右），但只要出题把 $n$ 提到 $10^5$ 就当场爆炸。**能过不代表做法对** —— 这个暴力恰好挡住了我们看清题目的结构。

瓶颈在于：每换一个 $i$，都把"右边有多少个 C"重新数了一遍，做了大量重复工作。

### 2. 关键观察

#### 观察 1：把答案按"右端点"分类

任何一对 $(i,j)$ 都有**唯一**的右端点 $j$。所以可以按 $j$ 来分类计数：

$$ans = \sum_{j:\ S_j = \texttt{'C'}} \underbrace{\#\{i < j \mid S_i = \texttt{'A'}\}}_{j\ \text{左边 A 的个数}}$$

一句话：**每遇到一个 `C`，答案就加上"它左边 A 的个数"。**

分类计数要求**不重不漏**：右端点 $j$ 唯一 ⇒ 每对只被算一次（不重）；每对必有右端点且那个位置确实是 `C` ⇒ 都被算到了（不漏）。

#### 观察 2：「左边 A 的个数」可以边走边维护，不用回头数

从左往右扫，维护一个变量 `cntA` = 已经扫过的 A 的个数。扫到位置 $j$ 时，`cntA` 正好就是"$j$ 左边 A 的个数"—— 因为左边的字符都已经处理过了。

这就是**前缀和**：把"区间/前缀内有多少个 A"变成 $O(1)$ 的查询，代价是 $O(n)$ 预处理，而这里的预处理和查询在同一次扫描里顺手完成。

#### 观察 3（对偶视角，课上值得提一句）

也可以反过来按**左端点**分类：每遇到一个 `A`，答案加上"它右边 C 的个数"。两种做法都得 $O(n)$，只是要从右往左扫（或先预处理出后缀 C 数）。**同一个计数题，按左端点分类还是按右端点分类，是两种独立的想法**，本题按右端点更顺手，因为字符串天然从左往右读。

### 3. 算法设计

```
cntA = 0, ans = 0
从左到右扫每个字符 ch：
    ch == 'A'  →  cntA += 1        （这个 A 等着被后面的 C 配对）
    ch == 'C'  →  ans  += cntA     （这个 C 把左边所有 A 一次性配光）
    其他字母   →  什么都不做
输出 ans
```

### 4. 正确性说明

**不变式**：处理完前 $t$ 个字符后，`cntA` = $S[1..t]$ 中 A 的个数，`ans` = 满足 $i<j\le t$ 的合法对 $(i,j)$ 的个数。

*归纳证明*：$t=0$ 时两者都是 0，成立。设对 $t-1$ 成立，看第 $t$ 个字符：

- $S_t = \texttt{'A'}$：它不可能是任何合法对的**右端点**（右端点必须是 C），所以以 $j\le t$ 为右端点的对数 = 以 $j\le t-1$ 为右端点的对数，`ans` 不变是对的；A 的个数加 1，`cntA++` 对。
- $S_t = \texttt{'C'}$：新增的、右端点恰好是 $t$ 的对，就是所有满足 $i<t,\ S_i=\texttt A$ 的 $i$，共 `cntA` 个 ⇒ `ans += cntA` 对；A 的个数不变。
- 其他字母：既不是 A 也不能当右端点，两个量都不变。$\blacksquare$

扫完 $t=|S|$，`ans` 就是全部合法对数。

### 5. 复杂度分析

- 时间：一遍扫描，$O(n)$，$n=10^4$ 时约 $10^4$ 次操作，比暴力的 $5\times10^7$ 快四个数量级。
- 空间：两个变量，$O(1)$。
- **答案上界（顺便学一下估数）**：设 A 有 $a$ 个、C 有 $c$ 个，答案最多 $a\cdot c$，在 $a=c=n/2$ 时取到 $\dfrac{n^2}{4} = 2.5\times10^7$。实测 `5000 个 A + 5000 个 C` 输出 `25000000`，与估算一致。$2.5\times10^7 < 2^{31}-1$，`int` 够用；但**只要 $n$ 变成 $10^5$，$n^2/4 = 2.5\times10^9$ 就爆 `int`**，所以代码里统一用 `long long`。

## 板书演示（本题不需要动画，一张状态表就够）

### 样例 `ACCA` → 2

| 步 | 读入 | `cntA` 变化 | `ans` 变化 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | `A` | 0 → **1** | 0 | 记下这个 A，等着配对 |
| 2 | `C` | 1 | 0 → **1** | 左有 1 个 A ⇒ 成对 (1,2) |
| 3 | `C` | 1 | 1 → **2** | 左仍有 1 个 A ⇒ 成对 (1,3) |
| 4 | `A` | 1 → **2** | 2 | 末尾的 A 没有 C 来配，白等 |

输出 `2` ✅ —— 注意第 4 位那个 A **不产生任何对**，这正是"顺序有向"的体现。

### 样例 `CAAC` → 2

| 步 | 读入 | `cntA` | `ans` | 说明 |
| --- | --- | --- | --- | --- |
| 1 | `C` | 0 | 0 + 0 = 0 | 左边没 A，这个 C 配不成 ⇒ `CA` 答案为 0 的原因 |
| 2 | `A` | 1 | 0 | |
| 3 | `A` | 2 | 0 | |
| 4 | `C` | 2 | 0 + 2 = **2** | 左边有 2 个 A ⇒ 一次新增 2 对：(2,4)、(3,4) |

输出 `2` ✅，与题面"说明/提示"里给的 `(2,4) 和 (3,4)` 完全一致。

> 第 4 步是本题的"啊哈时刻"：一个 `C` 一口气贡献了 **2** 对，因为它左边的 2 个 A 各自都能和它配。数"对"而不是数"字符"，就是这里。

### 样例 `CA` → 0

扫到 `C` 时 `cntA = 0`，加 0；后面的 `A` 只增 `cntA` 不增 `ans` ⇒ 输出 `0` ✅。

## 讲解代码

完整逐段注释版见 [`solution.cpp`](solution.cpp)，核心 4 行：

```cpp
long long cntA = 0, ans = 0;
for (char ch : s) {
    if (ch == 'A')      ++cntA;    // 左端点：登记
    else if (ch == 'C') ans += cntA;  // 右端点：一次性配光左边的 A
}
```

## 易错点与坑

1. **当成子串数**：只数相邻的 `"AC"`，`ACCA` 会得 1（正解 2）。题面"下标 1,2 和 1,3"已经明确说不要求相邻。
2. **把 `CA` 也算进去**：`if (ch=='C') ans += cntA;` 里的 `cntA` 只统计**已经扫过**的 A，天然保证了 $i<j$。反过来先看到 C 再看到 A 就永远配不成 —— 样例 2 就是这个。
3. **`else ++cntA`**：写成 `if (ch=='A') ++cntA; else ...` 之外的分支时，别把 B、D、Z 这些字母也当成 A 计数。题面说"全为大写字母"，**没说只有 A 和 C**，样例 `CAAC` 里没有干扰字母，但 `ACB`、`B` 这类数据必须有 `else if (ch=='C')` 的精确判断（实测：`ACB` → 1，`B` → 0）。
4. **累加时机搞反**：`ans++` 而不是 `ans += cntA` —— 那是在数"有多少个 C 左边有 A"，`CAAC` 会得 1 而不是 2。
5. **数据类型**：本题 $n\le10^4$，`int` 恰好不溢出（上界 $2.5\times10^7$）；但这是"侥幸能过"，$n$ 一变就炸。习惯：计数题先估上界，再决定类型，估不出来就 `long long`。
6. **读入**：串里没有空格，`cin >> s` 即可；`s.length()` 是 `size_t`，本题不参与减法所以无风险（对比"相减越界"那个经典坑）。

## 常见变式

| 变式 | 差异 | 做法 |
| --- | --- | --- |
| 数 `"AB"`、`"AA"`、任意两字符 $x,y$ 的组合 | 把两个字符判断换掉即可；$x=y$ 时答案是 $\binom{\text{cnt}_x}{2}$ | 同一套一遍扫描 |
| `AC` 和 `CA` 都要数 | 无序对 | 直接 `cntA * cntC`（任意一个 A 与任意一个 C 都能配成一"种"） |
| 数子序列 `"ABC"` 的个数 | 长度 3，一遍扫描不够 | 维护 `cntA`、`cntAB`，遇 C 时 `ans += cntAB` —— 本题思想的自然推广（多阶段计数 DP） |
| 逆序对个数 | 判据是 $a_i > a_j$ 而非固定字符 | 需要树状数组/归并，洛谷 P1908；本题是"值域只有 26"的退化版，所以 $O(n)$ 就够 |
| 区间内 `AC` 对数（多组询问） | 静态串 + 多次查询 | 前缀和 + 前缀 A 的加权和：$pre[j]=\sum_{t\le j}[S_t=\texttt C]\cdot preA[t-1]$，区间答案要再减掉跨界部分 |

## 小结

> **数"对"不数"字符"：按右端点分类，左边的候选数边走边维护。** 一遍扫描里，`A` 只负责登记（`cntA++`），`C` 负责收账（`ans += cntA`），$O(n^2)$ 就降成了 $O(n)$。
