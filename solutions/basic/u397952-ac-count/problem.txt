U397952 L1-006 AC数

【题目描述】
给定一个字符串 S，其长度为 |S| (1 ≤ |S| ≤ 10^4)，已知该字符串全为大写字母，请你计算出字符串中存在多少种字符为 "AC" 的组合。例如字符串 ACCA 有两种，其下标分别是 1,2 和 1,3。
注意： A 的下标在 C 的前面，也就是说倒过来的 CA 组合并不计数。

【输入格式】
输入一个字符串 S，其长度为 |S| (1 ≤ |S| ≤ 10^4)。

【输出格式】
输出组合为 "AC" 的数量。

【输入输出样例】
输入 #1
ACCA
输出 #1
2

输入 #2
CA
输出 #2
0

输入 #3
CAAC
输出 #3
2

【说明/提示】
对于样例三，两种组合的下标分别为 2, 4 和 3, 4。
